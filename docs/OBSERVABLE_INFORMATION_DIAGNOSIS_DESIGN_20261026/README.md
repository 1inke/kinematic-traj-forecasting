## 要解决的具体问题

已有一次编辑oracle可在FIT变化组将396/977提高到489/501/498，lost0、运动学通过；但学习版S仅398/396/397，训练变化组约90.8%的已执行编辑无效。当前问题不能只叫泛化差，也不能只凭oracle就认定输入足以预测正确动作。

## 结果怎么汇总

|观察|支持什么|不支持什么|
|---|---|---|
|小集合仍拟合不好|当前训练/表示/容量/标签有未解决限制|未来信息不存在|
|同输入树模型在留出有效、MLP无效|至少这些输入存在可利用信息，当前学习方案不足|树模型就是最终轻量方法；唯一是优化器问题|
|完整token或邻居增量有效|当前压缩接口或观测通道可能不足|已证明全编码器唯一根因|
|几何基线就有效、context无增量|候选几何含可用信号|历史完全没有信息，因候选本身来自历史|
|多模型未发现信号，邻域动作冲突高|当前可辨识性受限的辅助证据|信息论不可能性、Bayes误差下界|
|识别有增益但质量/运动学/成本失败|局部诊断正信号|可部署、major成功或baseline升级|
