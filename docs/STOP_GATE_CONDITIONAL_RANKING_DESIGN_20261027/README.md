## 结果分支

|观察|后续判断|
|---|---|
|原分数能把好编辑排第一，但被STOP压住|存在分数竞争线索，仍须受控训练验证|

|D仍不能拟合/没有增益|停止本有限系列，不继续第四loss或门限扫描；输入无信息仍未证明|
