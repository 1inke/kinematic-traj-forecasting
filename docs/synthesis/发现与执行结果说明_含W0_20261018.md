## 6. 发现串起来（【推断】，供决策）

1. **解码结构**：显式积分 + 软限幅，相对直接位置是实打实的运动/误差改善；但单模撞不过原生覆盖天花板。  
2. **互补池**：原生与 KIN 不是替代关系；并集见证约 **+9pp**（K40）；GT-free 选回 K20 能拿走约一半（**+4.4pp**），并付 ADE/FDE 代价。  
3. **验证诚实性**：锁定重现后运动含 change 可通过；但仍是**覆盖—误差折中** + 探索性阳性，不是 major deploy。  
4. **旧安全修复（W0）**：6 可独立、7 需补偿 → 机制异质；启发「有时要护集合、有时单条够」，**不自动**开 P2 或扫参。  
5. **与 P1 关系**：P1 否定的是固定 2×2 配方，不是「一切保护/责任原理」；新线是另一架构故事，勿做单因素因果对照。
