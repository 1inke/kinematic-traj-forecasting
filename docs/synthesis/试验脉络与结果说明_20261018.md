## 5. 明确未解决 / 不该过度解读

1. **不要把 P1 的 43% 和 KIN 的 60% 直接比高低**（分母不同，见 §1.2）。  
2. **并集 +9.4pp 是 K=40**，不是单一 K20 模型赢了原生。  
3. **KIN+clamp 未过「覆盖≥native」**；加长训也未过。  
4. **残差锚定刚贴原生**，rescue≈lost，不是干净修复。  
5. **多模式 KIN 本版阴性**，不支持当主线。  
6. **选择器未到 STRETCH**；距满并集仍约 5pp。  
7. P1 阴性**否定本固定配方**，不自动否定一切保护/责任原理；协议禁止本轮借此扫参。  
8. 未声称 SOTA、心理意图或 whole-model 独立泛化；3 seed 为探索级证据。

## 6. 暂停时的建议下一问（不自动开跑）

若继续，需**新授权 + 新设计号**，建议优先问：

1. **选满并集**：更好的 listwise / embedding 排序或配额，目标逼近 STRETCH（距 union ≤2pp 或 +7pp），仍保持 GT-free 与 K=20。  
2. **生成×选择 jointly**：避免「先生成 40 再硬选」，减少冗余与排序误差。  
3. **failure-only 残差（辅线）**：在锚定残差上加大「只修失败、硬保成功」，检验能否把薄增益做干净。  
4. **不要**：同 P1 2×2 扫 λ；同 KIN+clamp 再堆 epoch；把 MODE_DIVERSE 当主线；把并集 K40 直接当部署 K20。
