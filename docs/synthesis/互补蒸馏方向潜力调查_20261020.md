## 3. 潜力评估

### 支持"有潜力"的证据（强于一般新方向）

- **上界稳定且来源明确**：oracle 三 seed 一致 +6.3~9.1pp，且 K0-C 与 native 交集 ~19.6/20——机会是"外科式少数替换"，不是重构集合，适合学进单模型。
- **瓶颈诊断清晰且支持换路线**：选择器误拒 82%、几何排序命中 0.65%——"生成后挑选"路线已被系统性证伪，"训练时学习互补、推理直接生成"是对失败根因的正面对应。
- **172A 负结果反向定位了必要成分**：事后无监督压缩必丢互补 → 训练期、GT 监督、集合级，三者缺一不可，文字的方案恰好三者都满足。
- **不增加推理成本的主张真实**：教师只在 FIT 训练期使用，部署为单次前向 K20，与 KIN 独立 trunk 的双模型方案相比有实质效率差异。

## 4. 结论

**有潜力，且文字的判断（"看到机会、未解决转化"）与仓库证据完全一致。** 该方向在仓库中已有最接近的载体是 DESIGN_AB.md 主线 B（草案），文字的真正增量是把监督信号**分解为保留与补全两类**并用五臂矩阵做机制归因——这一点 B 线没有，且是回答"机制成立"所必需的。

三条建议（按优先级）：

1. **不要另立系列**：把"保留/补全双信号 + A–E 五臂"并入 DESIGN_AB B 线预注册（E≈B2+保留信号分解，B≈B2，C/D 为新增消融臂），复用其证伪条件、护栏与判定口径，避免又一次平行设计。
2. **先过第一关再谈训练**：冻结 v1.1、在干净底座上重估 native∪KIN 的 oracle 互补机会。若机会消失或缩到 MDE 以下，按文字的停止条件直接终止，不投入蒸馏。
3. **先解决功效再跑五臂**：以 D-0 实测 MDE 复核 +4pp 目标；若 MDE 降不下来（68 track 所限），"单 seed 筛选"环节判读标准需预注册为"点估计方向 + 不违反护栏"，而非显著性，否则五臂结果不可解释。

**总体判断：值得做方向筛选（文字的五臂单 seed），但必须把 ①（干净机会）与 ②（功效）两个前置条件写进同一预注册，否则筛选结果无论正负都无法归因。**
