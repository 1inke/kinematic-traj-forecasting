# 当前 F16 / K20 底座与新实现边界

## 现行研究接口

固定原始8步观察、12步预测、dt=.4s、K=20；原 focal-local 缓存的预测原点为最后已观察点。完整候选 good 必须同一槽 ADE≤.20m 且 FDE≤.40m。Q-winner 为 argmin(ADE+.5FDE)，J-winner 为 argmin max(ADE/.2,FDE/.4)，两者可不同，不拼接两条路径的误差。

F16 底座包含历史/运动学特征编码、稀疏社会交互与20模式候选解码。当前使用的是旧训练完成的冻结缓存；本轮没有重新加载并冻结整个 native 网络，更没有以 newhead 25,304参数冒充整模大小。其实际训练来源已包含当前 outer，故目前研究的是后续适应/修正的 held-track 迁移，不是整个底座的独立未见评测。

P2 取旧 observed tokens 的96维表示，native每槽12×2为24维位置。历史 StandardRefiner 将两者组成120维，产生12步修正；它不是原 F16 decoder。D2 的 hidden-point 坐标旋转泄漏属于某个后续预训练管线；新增 `preprocessing.visible_local` 在切可见前缀后才计算平移/方向，并用扰动测试验证。旧缓存/旧训练代码未被原地重写，不能声称所有历史管线已自动修复。

## 新公共组件

- `src/f16/data.py`：sample ID—metadata连接、冻结SHA、四人口和 track 暴露报告；绝不把旧 CAL 缺失 track 标签填成真实一个行人。
- `src/f16/eval.py`：同候选覆盖/保留、Q-winner同路径误差、J/分段、GT-free complete-link、完整五 pooled motion；速度12/加速度11/jerk10，prepend观察原点，p95用线性分位。
- `src/f16/statistics.py`：先抽track再抽配对seed；窗口加权；Holm p调整与普通CI不混同。精确Holm区间约定仍待作者冻结。
- `src/f16/governance.py`：S0冻结门、outer一次使用账本、CAL仅S4且需人工签字。
- `audit/verify.py`：独立 NumPy/SciPy 实现，绑定冻结native/GT/groups ID与SHA，逐字段得出PASS/FAIL，不导入训练评价。
- `src/f16/checkpoint.py`：新运行完整模型/optimizer/所有RNG接口；已做CPU微型连续—中断测试，尚不是A/B真实GPU resume验收。
- `scene_prior.py` / `hybrid.py`：A/B可测试的基础组件，不是已完成A0或B训练器。

## A/B 未完成接口

A仍需世界坐标片段、保留区间 purge、SHUF/XSCENE、实际A0 NLL/机会门、native query注入。当前组件的midpoint字段尚未进入双端口先验。B仍需actual native/KIN共享编码器adapter、FIT-only teacher asset、B0–B3筛选器、整个模型参数核算。未实际实现/验证的内容均在草案配置显式列出。
