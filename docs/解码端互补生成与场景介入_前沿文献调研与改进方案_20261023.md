## 三、 四项关键技术问题的数学与工程澄清

### 1. `aWTA` 的停止梯度（Stop-Gradient）数学条件
在本地 `src/f16/hybrid.py` 的现有 `set_loss` 中，`weights = torch.softmax(-q / temperature, dim=1)` 未做 `.detach()`。
若直接对未停止梯度的 $L = \sum_{j=1}^K w_j Q_j$ 求关于第 $j$ 条候选误差 $Q_j$ 的偏导：
$$\frac{\partial L}{\partial Q_j} = w_j \left(1 + \frac{\sum_{k=1}^K w_k Q_k - Q_j}{\tau}\right)$$
**反例**：当某非最优候选误差较大，满足 $Q_j > \sum_k w_k Q_k + \tau$ 时（例如 $Q=[0, 1],\ \tau=0.25$，则 $w_2 \approx 0.0180$，但 $\frac{\partial L}{\partial Q_2} \approx -0.0527 < 0$），梯度下降反而会**增大** $Q_2$（将劣质候选进一步推离真值）！
因此，若测试 **aWTA (ICRA 2025)**，必须严格按照作者官方实现，**对责任权重执行 `.detach()`**：
```python
# 严格停止梯度的 aWTA 任务项（待验证假设，非现成已验证代码）
w = torch.softmax(-q / tau, dim=1).detach()
loss_awta = (w * q).sum(dim=1).mean()
```
此时，按单窗口任务项计算，反向传播导数为 $\partial L/\partial Q_j=w_j\ge0$；批次大小为 $B$ 的均值则为 $w_j/B$。这是停止梯度后的反向传播导数，不是每次重算权重后的数值函数总导数，也不保证共享参数更新会同时降低全部候选的误差。

### 2. 时间结构化基底与 `accel_mean` 的真实数学关系

令 $p_0$ 为最后观测位置（局部坐标为零），$\Delta t=0.4\text{ s}$。沿用当前代码和原科学门：

$$v_t=(p_t-p_{t-1})/\Delta t,\quad t=1,\ldots,12,$$
$$a_t=(v_{t+1}-v_t)/\Delta t,\quad t=1,\ldots,11,$$
$$\text{accel\_mean}=\frac{1}{11\Delta t}\sum_{t=1}^{11}\|v_{t+1}-v_t\|_2.$$

首项是 $(v_2-v_1)/\Delta t$。观测衔接另记为 $\text{velocity\_join}=\|v_1-v_{\rm obs}\|$（m/s）；即使除以 $\Delta t$ 转为边界加速度，也不得并入原 11 项或改变分母。来源：[现有运动学实现](../qoder_work/F16_CONTEXT_COMPLEMENTARITY_DESIGN_20261022/execution_20261022/posthoc_interpretation/recompute.py)、[D1 诊断实现](../qoder_work/F16_CONTEXT_TAIL_RETENTION_DESIGN_20261023/execution_20261023/saved_diagnostics.py)。

* **分段线性不保证安全**：以 $p_0=0$、第 4/8/12 步为节点的三段线性路径，内部速度变化集中在第 4、8 项差分；观测衔接是另一个量。节点转折或加减速幅度增大时，内部加速度均值仍可能超过 native 的 1.01 倍。
* **当前证据不能把首步衔接定为主因**：[D1 报告](../qoder_work/F16_CONTEXT_TAIL_RETENTION_DESIGN_20261023/execution_20261023/RESULT_ANALYSIS.md)中，inner-change 固定 J-slot 的 velocity_join 为 native **0.179465 m/s**，A 三 seed 为 **0.088834/0.078367/0.098329 m/s**，均更小。此结果不能推广到 ALL20，但与“衔接必然恶化”的解释不符。
* **总变差不等于无用摆动**：内部速度总变差不小于 $\|v_{12}-v_1\|$，严格大于可以来自合理转弯。需分别报告同一 J-slot 对 GT 的向量误差、时间分解及 ALL20 pooled 五项门，不能互相替代。

对拟议的 CV 加残差形式 $p_t=t\Delta t\,v_{\rm obs}+r_t$，设 $r_0=0$，则：

$$v_t=v_{\rm obs}+(r_t-r_{t-1})/\Delta t,$$
$$a_t=(r_{t+1}-2r_t+r_{t-1})/\Delta t^2.$$

CV 项在二阶差分中消失。内部加速度取决于残差基底及系数，而不是 CV 项本身。若要求所有系数下 $v_1=v_{\rm obs}$，须另有 $r_1=0$，例如所有 $\Psi_{m,1}=0$；这会限制首个 0.4 秒内的真实加速，不应默认加入。研究假设是“时间参数化可能改善速度变化分布与覆盖之间的折中”，而非预设边界衔接是根因或必然通过运动学门。

### 3. 整模参数预算（$349,167$ vs $305,000$）与逐层精确账本
* **当前实测状态（`execution_20261022/core.py`）**：
  * 冻结上游 F16 编码器：$267,159$ 参数；
  * `ContextK20` 学生解码器：$82,008$ 参数：
    * `trunk`: `Linear(210, 128)` ($27,008$) + `Linear(128, 128)` ($16,512$) = **$43,520$**
    * `queries`: `Parameter(20, 16)` = **$320$**
    * `fuse`: `Linear(144, 128)` ($18,560$) + `Linear(128, 128)` ($16,512$) = **$35,072$**
    * `head`: `Linear(128, 24)` ($3,096$) = **$3,096$**
    * **学生合计**：$43,520 + 320 + 35,072 + 3,096 = \mathbf{82,008}$ 参数。
  * **整模部署合计**：$267,159 + 82,008 = \mathbf{349,167}$ 参数（**已超出 `PROTOCOL.md` G5 的 $305,000$ 上限 $44,167$ 参数**）。
* **工程核算约束**：
  1. 参数量相同只能称**同名义参数预算**，不等于有效容量、优化几何或计算量相同。C2 两臂应使用同一扩展骨架与相同可训练参数集合；不得为凑旧 A 的 82,008 参数而只对一臂删主干或缩宽。与旧 A 的比较单列辅助参考；新模块参数、MAC、实测延迟和内存另报。
  2. 若要满足整模 $\le 305,000$ 的正式 G5 协议门，则解码器总参数必须控制在 $\le 37,841$ 以内，或者在端到端重训阶段同步压缩编码器。

### 4. `src/f16/scene_prior.py` 现有接口的实际行为边界
1. `Fragment` 数据类虽然定义了 `midpoint` 字段，但 `HistogramPrior.query()` **仅对 `r.endpoint` 构建了 2D 直方图**，`modes()` 也只返回 $m$ 个二维终点格心 `[m, 2]`。
2. 当局部 `(cell, heading)` 样本数 $\le 5$ 时，`query()` 依次回退到 `cell` $\to$ `scene_heading` $\to$ `global`；此时返回的 `answer['support']` 是**回退层级的样本数**，判断局部支持不足必须检查 `answer['level'] != 'cell_heading'`。
3. 场景探针参考 [DESIGN_AB.md §2.3](../DESIGN_AB.md) 的证伪思路，但本文不修改该文件或任何既有实验协议。新增执行协议须展开 static/causal 及各自负对照，绑定三道闸门的公式、阈值和来源，不能以“全套对照”代替实际分臂表。该旧设计有待预注册字段，不能视为全部已锁定。

## 四、 修订后的研究顺序与单因素设计合同

保留 A（时间参数化）、B（场景历史信息）、C（责任分配/集合通信）三个方向，但不将它们打包训练。**下述是设计合同及实施前清单，不是已完成的预注册。** 尚缺的数值或实现只能在读本轮新结果之前锁定；不能在结果出来后补填成“事前决定”。

### 共同评价与执行边界

- 保留原始实验全部结果和失败证据，不改 S1/T1 的科学门、源文件或 baseline；以同一条候选同时满足 ADE≤0.20 m、FDE≤0.40 m 定义覆盖。分别报告 minADE、minFDE、固定 J-slot 与 Q-slot，不能拼成不存在的好轨迹。
- 先同路径覆盖与 rescue/lost/retained，再完整 K20 的 GT-free complete-link（mean-path 0.10 m、endpoint 0.20 m）有效好簇，再讨论评分。五项 pooled 运动学仍按原 dt=0.4、全部候选与组别计算，不把逐窗门、J-slot 诊断或 GT 相似度替代原门，也不放宽 1.01×native 的运动学标准。
- FIT 用于训练与统计拟合；本轮先用 inner 开发，不新增 outer/CAL 评测或使用它们挑方案。inner 已被反复使用，上游 F16 也已见过旧池，结论属于探索。训练对照固定 seeds42/43/44、相同 split IDs、初值中可配对部分和数据顺序；不能把旧 A 的单次保存结果当成新训练对照。
- 主终点及比较对象须预注册：训练方向以 inner-change 的同路径覆盖差为开发主终点，同时保留原误差、成功保留和运动学联合门；B 是终点信息探针，不能直接判生成成功。按共同 track 与配对 seed 报区间、分 seed 反例和多重比较处理，不因点估计有利即晋级。
- 每个执行协议必须记录实际 source/split/statistics SHA、参数及计算量、初始化、优化器、损失、温度或基底常量、轮数、主终点、阶段门及停止规则。模型训练前完成实际数值/梯度/精确恢复/保存结果审计与资源预检。当前文档没有执行这些步骤。

### 方向 A：时间结构化输出参数化（检验内部运动分布与覆盖的折中）

**不再以“消除观测衔接错误”为既定动机。** 先进行一次有限的零训练基底筛查，再决定是否值得投入配对训练。

#### A-1. 参数化定义与必须固定的内容

$$\hat p_{k,t}=t\Delta t\,v_{\rm obs}+\sum_{m=1}^{M}\Psi_{m,t}c_{k,m},\qquad c_{k,m}\in\mathbb R^2,\quad t=1,\ldots,12.$$

$\Psi\in\mathbb R^{M\times12}$ 为无量纲时间基底，$c$ 为米制二维位置系数；另定义 $\Psi_{m,0}=0$ 以得到 $r_0=0$。不得混用“加速度系数”而仍按位置系数解释。

| 执行前字段 | 必须明确的内容 | 禁止的隐式变化 |
|---|---|---|
| M、Ψ | 一个固定维数、一种明确构造、全部采样值及 SHA；报告 rank/condition、DΨ/D²Ψ | 看 inner 后反复改节点、秩或基函数选最好 |
| 数据驱动基底 | 如使用 SVD/PCA，只用 FIT 拟合并冻结 | inner/outer/CAL 拟合或重新归一化 |
| 系数与量纲 | 无界线性或具体有界映射二选一；写出范围、归一化和反变换 | 事后截断或放大系数求过门 |
| 首步与末步边界 | 主筛查不默认强制 r₁=0；若采用须事前说明可达集合代价 | 把严格 v₁=vobs 当公式自动性质 |
| 零输出和对照 | 明确 CV 零系数输出与原 A 零坐标输出不同 | 宣称所有初始预测相同或纯衔接因果 |

上述具体基底仍须单独确定并锁定。本文不随意指定一个新 M 或系数界，再将其冒称已有证据支持。若训练同时改变低维输出头尺寸、初始路径和基底，必须称为**参数化方案对照**；若要隔离时间映射，应在两臂使用同样系数头，仅替换已登记的固定映射，并报告有效可达集合的差异。

#### A-2. 零训练筛查：区分重构、后处理与可达性

在同一显式 ID 集上，对 GT 残差 $y_t-t\Delta t\,v_{\rm obs}$ 及旧 A 每条路径残差分别做固定 L2 最小二乘投影；记录求解精度、系数、重构误差及是否满足拟议系数约束。无界投影不得当作有界模型的可达见证。

| 对象 | 可报告的证据 | 不能推出的结论 |
|---|---|---|
| GT 的投影 | oracle 单路径重构；满足全部指定约束的解是存在性见证 | 不合格不证明子空间没有其他可行系数；不等于 K20 部署收益 |
| A 的完整 K20 投影 | 固定后处理算子的覆盖保留、rescue/lost、五运动学及有效好簇变化 | 不等于重新训练该参数化的表现上限 |
| 另行按目标约束找出的可行解 | 经独立验证后支持指定窗口存在可行解 | 搜索失败不是不可行证书；有解不证明能从历史观测预测系数 |

最小化坐标平方误差不等于最小化 J，也不等于满足全部五运动学门。因此删去原“投影掉覆盖或不降 accel_mean 就证明基底不行”的规则。预算筛选可以预注册未通过即不训练，但结论只能写 **“本次固定低成本筛查不支持继续投入”**。启动筛查前必须固定允许的覆盖损失、目标运动改善及比较人口；本稿不凭空填入新阈值，也不以此替换原正式成功门。

筛查完整报告 overall/stable/transition/change、所有 seed、时间差分、边界衔接与反例；不得只留有利的 change 窗口。不升级为无止境 oracle 求解或扫秩。若未发现合理正向证据，暂停这一参数化方案，而非否定全部时间结构路线。

### 方向 B：场景历史先验零训练探针（原 DESIGN_AB 的 A0）

这里的“方向 B”对应旧 DESIGN_AB 的“主线 A”，不与本文方向 A 混淆。以现有 endpoint-only HistogramPrior 为起点，不在同一探针中新增 midpoint、RGB 或学习模块。

为消除原稿“五组”计数歧义，**建议的新执行合同明确为 8 个逻辑臂**：M0、M1、PRIOR-static、SHUF-static、XSCENE-static、PRIOR-causal、SHUF-causal、XSCENE-causal。这是对旧草案的显式展开，未修改旧协议，未声明已经执行。

- **M0/M1**：原 motion-only 残差分布与 heading-only 全局先验；只由合法 FIT 来源建立，冻结分辨率、平滑、范围外质量处理、并列与不足模式规则。须审计 causal 部署开始时这些离线信息确实可用。
- **static 组**：使用合法 FIT 历史片段，按 query 的真实 sequence+track 排除自身全部片段，核实别名、重复轨迹与时间重叠。它是信息存在性探针，不等于未见场景部署条件。
- **causal 组**：仅使用 query 时刻前已经完整结束且实际可获得的其他 track 片段；不能仅以“来自 FIT”代替时间核验。跨场景参考的预先可用时间也要登记；无法统一时间轴时使用部署前冻结银行，不挪用未来片段。
- **负对照**：static/causal 各自匹配置换与跨场景臂；固定置换种子与规则、heading、支持数/回退层级的比较口径。跨场景坐标须采用相同局部表示与预登记映射，不让量纲或坐标错误充当负对照效果。
- **资格与来源**：保存每次查询的来源 track、片段结束时间、level、support、模式数和冷启动状态；未知身份或时间不得假作已隔离，须单列不可验证人口，不能按质量剔除。

沿用旧 A0 的三项信息筛选意图：终点 NLL 改善、正确先验相对置换的额外优势、native 未覆盖窗口的 top-4 终点命中潜力。旧草案的 3%、二分之一、10% 是筛选阈值，不是显著性或完整轨迹成功门。新增协议必须锁定 NLL 的离散概率/密度口径、改善分母、零值/负值处理、比较基线与 static/causal 分开判定，不可只写百分比而缺公式。

**未过门只关闭这份固定历史先验方案，不否定全部场景信息路线。** 若数据身份/时间不可验证则是有效性阻塞，不归档为科学阴性。endpoint top-4 命中只说明终点潜力，不能称完整前12步覆盖，更不能按 GT 选终点部署。通过后才另设计条件路径生成实验。

### 方向 C：责任分配与跨槽通信分别验证

#### C1：hard-WTA 对 stopgrad-aWTA，架构完全不变

固定 ContextK20 82,008 参数及原 S1 的信息、统计、初始化与数据顺序，唯一替换任务项：

$$Q_k=\mathrm{ADE}_k+0.5\mathrm{FDE}_k,\quad L_{\rm hard}=\operatorname{mean}_i\min_k Q_{ik},$$
$$w_{ik}=\operatorname{stopgrad}\{\operatorname{softmax}_k(-Q_{ik}/\tau(s))\},\quad L_{\rm awta}=\operatorname{mean}_i\sum_k w_{ik}Q_{ik}.$$

保留原 190 对 endpoint 线性 hinge、margin0.3、权重0.05、clip5、AdamW(.001, weight_decay=.0001)、batch256、8epochs，不混入旧25轮/六pair平方hinge配方或 T1 相对保护项。完整数值以绑定的 S1 protocol/source 为准，存在冲突则先核对而非混用。

温度与 Q 同量纲。执行前固定 τ 起止值、按 step 的退火函数、是否切为 hard-WTA 及切换点，只允许一个预登记日程，不用 inner 扫温度。当前本文尚不指定已验证温度；主终点和其他门按共同合同固定。诊断记录槽位责任、熵、活动槽、并列、各子集误差与 rescue/lost；全部槽活跃不能单独证明有效互补。

#### C2：SetMix 对逐槽控制，损失完全不变

在同一扩展骨架上增加同形残差块，主比较只改变块接收的跨槽信息。例如设 $h_k\in\mathbb R^d$：

$$z_k^{\rm mix}=[h_k,\operatorname{mean}_{j}h_j,\operatorname{max}_{j}h_j],\quad z_k^{\rm iso}=[h_k,h_k,h_k],$$
$$h'_k=h_k+W_2\,\sigma(W_1z_k+b_1)+b_2.$$

两臂使用相同 $3d\to b\to d$ 层形、非线性、paired 初始化与同一输出头，末层零初始化使新增残差块初始为恒等映射。执行前锁定插入层、d/b、max 并列反传规则及 zero-last 分阶段梯度测试。两臂均使用原 hard-WTA 与 diversity，不叠加 C1。

该示例比较跨槽信息输入与逐槽信息输入，不等于证明等有效容量；逐槽重复输入也有不同的优化几何。主比较为 C2 两臂，相对旧 A 仅为辅助参考。参数和 MAC 精确核算；不为凑 82,008 而悄悄改主干。若整模超过305,000，只能标记超预算机制探索，不得声称轻量化部署达标。压缩应另开配对设计。

### 建议顺序与停止边界

先完成 A 的固定基底筛查合同与 B 的身份/时序/信息合同，再做低成本离线探针。训练方向只选有明确问题与对照的一项，不同时开 A+C1+C2。任一局部阳性均须继续通过原覆盖、误差、成功保留、五运动学和预算门才谈晋级；否定结果只限定到该次固定方案。所有未确定配置及实际预检仍属于下一执行协议工作，本次文档修订不构成自动训练授权。
