## 3. P0：受限、安全机会与监督多解审计（不训练）

### 3.1 两个有限动作集合

END49：二维偏移 `(0.1*i,0.1*j)m`，整数i,j∈[-4,4]且i²+j²≤16，准确49个，含identity。应用为 `p'_t=p_t+(t/12)*delta`。坐标使用既有局部坐标，不额外旋转至估计heading。它不保证历史末速度衔接。

TIME441：继承原弧长进度q4/q8/q12和前两段倍率网格0.75..1.25、间隔0.025；第三倍率由总进度1决定并检查同范围。原零段长/全静止不可严格单调时仅identity合法。精确公式见02。不是新平滑曲线、不是连续时间函数全局搜索。

每个候选分别进行GT-free过滤：有限值、动作定义合法、对应原候选五项运动学各≤1.01倍，以及历史末速度到未来首步的junction加速度≤1.01倍。**junction是本系列新增保守过滤条件，不追溯改写旧实验门。** 原值为0则按0比较，不添科学floor/epsilon；identity直接保留原数组精确通过。

标签只在合法动作中以 `J=max(ADE/0.2,FDE/0.4)` 取最小；identity在同最小值中优先，然后最小参数改动范数，再固定动作索引。由于identity合法，oracle逐候选J不增；其零lost是构造性质，不是训练成果。

保存每个候选：合法动作数、identity J、最优J、最优参数、最优/次优差、所有精确并列数、近并列诊断数（J差≤1e-6仅描述，不改变选择）、非identity比例。为防“唯一oracle参数”虚假精确，同时保存距最优J≤0.01的参数集合直径；该阈值只报告多解程度。

### 3.2 不无限制作大bank

逐窗/候选/动作有界分块计算；保存参数、动作mask、J矩阵与标签，不持久化N×20×441×12×2完整轨迹。源只读，无旧模型forward。生成GT-free masks及动作manifest后，再关联GT；分别记录SHA。

### 3.3 学习阶段准入门

每个分支独立要求：train change中，**安全oracle新增成功≥2个百分点**，即至少15/721窗，并分布在至少5个不同sequence|target轨迹。这是新方案的最低研究价值门，不是从结果搜索的阈值，也不是major成功标准。val结果完整报告，但不据此修改动作网格。

不通过则该分支标 `STOP_LOW_SAFE_OPPORTUNITY_IN_THIS_ACTION_CLASS`，本系列不训练该分支，不扩大0.4边界、网格或放宽物理门求通过。明确最先卡在无几何机会、内部motion或junction哪一步；只把归因称过滤统计，不称唯一物理根因。

P0也输出无过滤oracle作解释参照，但它不参与准入、训练或部署。两种oracle都受有限动作类限制；不能把未救回解释为不存在其他安全修正。

## 4. P1：端点修正是否可从观测预测

### 固定对照

- E-G：只看当前候选12×2局部坐标；历史输入通道标准化后置0。
- E-H：同一候选+8×2原始局部历史。
- 无训练参照：identity；train全部候选oracle参数的均值，经相同有限动作解码与安全过滤。均值基线不是新模型seed。

共同40→64→32→2 GELU MLP，4770参数，双输出tanh，参数均按02归一化。G/H配对全部初始参数，输入结构相同；历史分支有效容量不同必须披露。20个候选用一个共享网络，不给slot编号、ID、scene、group、logit、GT或oracle原因。初始末层0，预测参数对应identity。

监督为P0安全最小J动作的二维偏移/0.4。损失为每窗先平均20候选、再平均两参数的MSE；所有窗口/候选保留，不按GT挑失败、不加正例重权、不变成STOP BCE。历史与候选特征均为train float64统计，输出训练float32；标准差<1e-6置1。

G/H各seeds42/43/44，8固定epoch，batch32窗口（实际每批640候选），AdamW lr0.001、wd0.0001，clip_grad_norm=5，无scheduler、无early stopping。每epoch97个batch、776次更新/模型，末batch保留。无验证checkpoint选择；final8为唯一primary。

网络给连续参数，经最近有限END49动作解码；等距优先identity、再较小改动、再索引。对选定动作检查安全，失败就identity，**不再搜索第二个动作**。这种回归+量化明确不同于直接441-way排序；若量化或多解均值化失败，必须报告而非声称信息缺失。

### 必须保存的三个输出

1. 连续参数预测和参数误差：预测器本身的证据。
2. raw：有限动作解码后、尚未安全拒绝的K20，暴露模型原始运动代价。
3. guarded：按GT-free安全检查回退后的K20，作为唯一部署候选集参照。

每个slot最多替换自身一次，保持20槽，不混入GT选择，不把原20+新20当公平K20。全槽更新仍可能损害原成功，不能预设native保护。

## 5. P2：时间过程是否可从观测预测

T-G/T-H输入、模型、参数量、种子、批顺序、优化器、预算与P1相同；输出含义改为两倍率 `(a-1)/0.25,(b-1)/0.25`。独立fresh训练，不复用E权重。标签为P0的安全最小J TIME动作，不用旧最小ADE标签冒充。

解码时在当前候选的**几何合法TIME网格**中取归一化参数欧氏距离最近者，identity优先tie；只需倍率与q计算，不为部署枚举全部轨迹。实际只生成选中动作，安全失败回identity，不改选第二个动作。

固定终点；raw/guarded的每槽FDE必须与对应Native在既定算术容差内一致，质量阈值比较仍无epsilon。identity直接复用原数组；最终点直接赋原最终点，以避免无意义舍入。

必报：所有候选FDE>.4窗口上的理论不可救回比例；标签多解与identity比例；前中后速度、onset描述、内部motion与junction。不能以“学到了时间标签”代替同路径覆盖，也不能只评价原终点已合格的GT子集而隐藏全人口结果。

## 6. P3：有条件触发的固定输出联合，不再训练

仅E-H与T-H各自同时满足03中可预测性信号门和部署推进门才触发。任一只具有参数预测信号、却没有安全完整覆盖收益，不进入联合；G已能改善但H无增量时，也不把这次联合包装为历史增量机制。

采用同seed配对、四个端口：Native / E / T / E+T。联合不再次预测参数，也不把端点改变后的路径重新送进T（避免新增未训练分布）。以两个分支在原Native上选出的动作构造：

`p_joint(t) = TIME(p_native; a,b)(t) + (t/12)*delta`

这里的a,b,delta取各自guarded分支实际采用的参数（被拒绝则identity参数）。联合后重新检查内部五项和junction；不合格回退该槽完整Native，不在E/T中按GT择优。固定4端口全报；组合可能因相互作用被拒绝，不预设两种安全操作组合仍安全。

P3只是冻结输出的组合验证；它不证明一个联合训练模型可学，也不自动授权新loss、scorer或专家模块。组合无效但单分支有效时，保留单分支为后续候选路线，不强求联合。

## 7. 对照和停止解释

| 结果 | 本系列结论 | 后续边界 |
|---|---|---|
| P0机会不足 | 当前固定安全动作类缺乏值得学习的收益 | 停此分支，不改变门求PASS |
| 机会足够，训练拟合失败 | 优化/监督/表达仍有障碍 | 不讨论输入不可辨识，不直接延长训练 |
| tiny可拟合、全train拟合差 | tiny可实现不等全人口可学；多解/identity压制仍可解释 | 记录，不无穷加宽/加权 |
| train改善、hold无增量 | 缺少当前方案跨轨迹迁移证据 | 不上联合；不说信息论不可能 |
| H不优于G，但G优于identity | 候选中已有可利用几何信息，显式历史未增益 | 不宣传新增历史理解能力 |
| H参数更准，覆盖无增益 | 可预测目标与候选集合效用脱节 | 停部署推进，诊断量化/多解/候选冗余 |
| 覆盖增益但lost/motion失败 | 有可预测修正，但整合/安全未解决 | 不发布模型成功、不训练scorer掩盖 |
| 两个H各自安全覆盖成立 | 有限可学习空间与时间分支证据 | 才进行P3冻结组合 |

最多此两种学习分支，不自动第四局部变体。新大方向需要基于本系列结果另立协议。
