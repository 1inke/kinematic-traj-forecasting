## 相对旧实验的实质差别

- 旧GT END≤0.4是“直接命中GT终点，超界保持原候选”；新END49是**固定、可部署的有限偏移集合**，不是同一个oracle，不能照搬旧120个救回数。
- 旧TIME逐槽选择最小ADE，未以运动安全筛选；新TIME在固定同一网格上先做GT-free合法性/运动/衔接筛选，再以同路径J生成训练监督。旧60个救回不能当作新标签机会数。
- 不把原生候选当无信息基线：Native已经含有历史信息。G/H只测**额外显式历史输入**的增量，不测历史全部信息量。
- 用低维参数预测绕开再次训练大动作集合的STOP二分类；但参数回归可能因多解均值化而失败，失败不等于输入无信息。
- GT oracle的成功保留是选择规则的性质；部署版本必须独立统计lost，不能使用GT回退。
