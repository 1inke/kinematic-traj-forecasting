# 实验设计：一次性集合编辑能否实现安全的互补覆盖？

日期：2026-10-25。**仅设计，未实施。**

## 1. 先说明这次为什么值得做，又不是什么

本轮不以“还有一组超参没试”为理由。依据是两项不应混淆的证据：

1. **好集合在某些固定池中确实存在。** 旧native20＋KIN20实验的GT oracle K0-C在outer变化组把110/253提升到126/133/127，原成功lost0，完整运动学门通过；但这是多步、知道GT的见证，不能直接当一次替换的能力或可部署结果。
2. **当前学习规则没有稳定找到它。** 旧K1-S平均替换约2.5条，成功oracle只约0.395条；去门后替换约18条反而更差。误拒与误接受并存，不能解释成单纯“太保守”。

最新更新仲裁G0又显示：当前两组均值的一阶约束只在5/48批动作；84.54%的损害量在不动作批次，当前规则的理想总降幅上限仅15.46%。这支持结束这一具体优化分支，**不证明所有共享干扰不存在**。

据此，本轮把问题从“连续改网络参数，期待保留所有成功”转到：

> 固定已有候选坐标，只决定一次是否值得改变集合；把多个等价有效动作当正确答案，并明确允许不改。

这是对**有限动作的条件辨识与集合决策**的测试。它不等于心理意图理解、不新增未来信息、不证明泛化已解决，也不直接生成新的轨迹坐标。

## 2. 科学假设与单因素对照

H：在一次编辑空间中，使用相同可观测信息和相同“可接受动作集合”标签，直接学习集合内的选择次序，可能比逐动作独立分类更能区分“该换入哪一条”和“应该保持不动”。

正式比较只改变监督方式：

- **I（Independent）**：相同网络，对每个动作作逐动作二分类。
- **S（Set-ranking）**：相同网络，要求本窗口最好的正动作分数高于最高负动作。

两者均使用多正例标签、同STOP、同完整400动作、同特征、同物理准入、同初始化/训练顺序、同推理argmax。**不再用“回归 vs 分类＋新结构＋新门”作混杂对照。** 旧连续收益回归只作历史参照。

E1只能识别这一监督差异。相对旧K1的改进若出现，还混合了动作空间简化、特征与模型变化，不能称纯监督因果。

## 3. 冻结输入、候选及数据分区

### 3.1 候选来源

每seed42/43/44固定既有native20与对应KIN20，T12、dt=0.4；不重训、不温启动生成器，不把新A/SetMix池替换进来。通过显式sample ID连接当前target-track FIT18,909及inner1,856。

KIN缓存候选来源：

`UNION_SELECTOR_K40_TO_K20_20261018/results/cache_pred/kin_FIT_seed{42,43,44}.npy`

该缓存的“FIT”行空间不应默认等于18,909行；实施时必须按原loader、split索引、身份元数据及checkpoint/cache SHA建立可审计映射。仅形状相符不是身份正确。任何seed映射/原生基准/坐标不兼容即STOP，不按行号猜配对、不换池补洞。

旧选取模型和旧K0 oracle索引不作为新模型输入、训练标签或warmstart。新标签从固定候选坐标与**当前训练分区GT**重新计算，不读取旧outer/original_CAL的oracle答案。

### 3.2 新编辑器的数据分工

在现有FIT18,909内部，以`sequence + target_track`为单位划分：

- `FIT_hold`：每sequence将全部track按`SHA256("single-edit-hold-v1|"+track_key)`排序，前ceil(20%×track数)条整track。
- `FIT_opt_pool`：其余track。
- `FIT_opt`：从pool全部窗口按`SHA256("single-edit-train-v1|"+decimal_sample_id)`排序取前4,096个；三seed相同ID，不按质量/行为挑样本。
- `inner`：原1,856不变，只作固定终态最终评价；不选checkpoint、标签定义、阈值或特征。

FIT其余窗口保留ID登记，但本轮不拟合；不能把未用窗口描述为无效/不可预测。

最低身份/规模门：opt_pool≥4,096，hold≥1,000窗且至少20个change-containing tracks；inner身份有效、change497及至少20条track。任一失败停止，不改hash、比例或并轨迹凑数。

**隔离仅针对新编辑器。** 冻结KIN和F16可能已见FIT_hold甚至旧inner相关数据，不能称整个预测系统真正未见泛化。target隔离也不等于上下文/时间邻居隔离。旧outer及original_CAL本轮不评，以免扩大已反复使用的开发范围。

## 4. 动作空间：最多一次替换，或者STOP

记原生集合为N，补充池为L。

`a=(r,l)`：移除native物理槽r∈0…19，把KIN槽l∈0…19放入同一输出槽。恰好400个动作；其余19条native逐值不变。

`a=STOP`：输出原native20逐值不变。

每窗口只决策一次，禁止将输出再输入编辑器、追加第二次交换、失败后寻找另一个门或反复放宽条件。最终严格K20，slot是物理索引而不是固定运动语义。

候选重复也不人工删掉：完全重复替换可作无收益动作；记录distinct及cluster，不能通过重复路径凑有效覆盖。

### GT-free准入

400个替换各自重构完整K20，其**逐窗口、全部候选**五运动量均需literal≤对应native窗口的1.01倍；否则屏蔽该动作。STOP永远可用。

五项为speed p95、accel mean/p95、jerk mean/p95，dt0.4，linear quantile，坐标先float64再差分。零基准按原不等式处理，不加floor或epsilon。

这只是动作准入，**不保证最终跨窗口pooled p95合格**。后者必须再独立评价；前者失败不证明所有安全集合不可达。不能用GT、分组、场景、ID或原logit进行准入。

## 5. 正标签不是一个oracle槽位，而是全部可接受动作

对集合C定义：

- `A(C)=min_k ADE_k`；`F(C)=min_k FDE_k`，二者可来自不同slot。
- `J(C)=min_k max(ADE_k/.2,FDE_k/.4)`；`good(C)=1[J(C)≤1]`，此处必须同一完整候选。

一个动作只有同时满足以下条件才进入正集合B：

1. 已通过GT-free物理准入；
2. A、F、J均不高于native；
3. native good时结果仍good；
4. A/F/J至少一项严格变好。

这里的“严格”不加结果筛选epsilon；逐项原始margin和近零改进数量必须保存。good由J决定但仍显式核验，防止代码拼接两个不同slot的最小值。

若B非空，正确动作集合T=B；若B为空，T={STOP}。其余未屏蔽动作均为负例。STOP在B非空时是未抓住机会的负例，不称其伤害原生；负例须区分**有害、无效、保守STOP**，不能都叫不安全。

标签GT只用于FIT_opt监督、hold/inner事后评价；模型在部署时不知道B或T。原生成器、任何oracle从不参与forward选动作。

## 6. E0：一次编辑机会是否足够？先不训练

### 6.1 固定工作量

仅FIT_opt4,096窗×三池seed×400动作＝4,915,200个非STOP动作；无模型前向、无新求解器、无训练。STOP/native作为各窗口参照另外保存。

这是有限枚举，不需要先重新运行旧多步K0。每窗口一次oracle选择仅供筛查：在B中按J、A、F、r、l依次升序，B空则STOP。该规则在读取结果前冻结；不为最终pooled motion临时改排序。

### 6.2 进入E1门（工程机会门，不是部署成功）

三seed每个都必须：

- 至少5%的opt窗口B非空，且正窗口涉及≥50个不同target tracks。
- opt change至少300窗/30 tracks；一次oracle的change覆盖相对native增加≥2.0pp，且全组native成功lost=0。
- oracle在opt的overall/stable/transition/change全部五项**pooled**运动量通过native1.01门。
- 完整动作、标签、ID和保存审核通过。

这是在当前固定有限空间里判断是否值得学习，未要求它已经达原major的5%误差门。必须同时报告一次oracle所有指标，以及旧多步见证仅作历史背景，不能把两个数据分区直接配对。

E0失败：停止本有限系列；不可增加swap次数、换KIN、改标签容差/阈值、增训练样本或删低速窗凑门。枚举只否定本动作空间/筛查规则，不否定所有K20联合可达性。若B有足够动作但固定oracle组合pooled失败，结论应是“该选择规则未给出全人口安全见证”，不是所有B组合均不可行。

## 7. E1：两个同容量编辑器，六个新拟合

### 7.1 网络与优化

每动作324维GT-free输入，具体通道见实施合同。共享MLP：`324→32→32→1`，GELU，最后线性层无bias，参数11,488；输入含是否STOP，不含label、GT、track/scene/ID、原logit或oracle排名。去掉最后bias是为了避免S中对所有动作共同平移、解析抵消的无效参数，两臂均如此。

I/S逐seed配对初始化、FIT-only统计、batch顺序、数据、训练步数。每个窗口的全部未屏蔽动作与STOP一起处理，不采样oracle正例、不丢负窗口。

- seed42/43/44分别对应同seed固定KIN池；不能把池seed当完全独立新数据。
- AdamW lr.001、weight_decay.0001，clip5；8epoch，窗口batch32，无drop_last，固定epoch8。
- 4,096窗每epoch128 steps；每模型1,024 steps，六模型共6,144 steps、48个epoch记录。
- 所有epoch可保存恢复状态；hold/inner只评价固定终态，不early-stop、不选最优epoch。

I：每窗口正负各自均值的平衡BCE，权重各0.5。

S：`softplus(1 + max_negative_score − max_positive_score)`，margin固定1；并列按STOP优先、然后r/l固定顺序。该式只要求至少一个有效动作排到负例之前，不要求全部正例高分。

只有STOP可用时，两臂该窗口loss=0，仍保留在全窗口分母与输出中。没有负例的其他异常同样显式记录；不得改变统计分母。两臂正标签完全相同；结构及推理流程完全相同。训练softplus/BCE值与分数都不是经校准的未来概率。

S仍有hard max与责任集中风险；本轮不声称解决全部credit assignment。若失败，不自动换softmax温度、负例采样或margin。

### 7.2 推理规则

在所有未屏蔽动作＋STOP中直接argmax；并列先STOP再r/l。只输出一次编辑后的K20。无GT、无额外阈值拟合、无“选错再退回”的GT纠错。

因此本轮不存在accept阈值扫描。FIT_hold用于检查迁移与错误类型，但不调阈值或选择两个臂中的赢家。两臂全部完成后，解锁一次inner评价。

## 8. E2：必须同时看机会利用、误编辑与最终轨迹

### 8.1 主要比较

主检验仅**S−I在inner change的同路径覆盖**。进入后续机制研究要求：

- 三seed差值均>0，平均≥2pp。
- 同track配对、三seed配对重抽的20,000次探索bootstrap 95%CI下界>0；固定三seed、只抽track敏感性同样下界>0。
- S相对native各seed覆盖不降，平均至少+2pp；否则不能靠退化I制造胜利。

一个主要比较，不按多个指标中最显著者换主终点。样本再多也不能把401动作当401个独立窗口。

### 8.2 决策证据

在FIT_opt、FIT_hold、inner分别报告：

- B非空窗口比例、可接受动作数分布、物理准入率。
- 所选动作∈B的比例；在B非空窗口中的机会利用率；B空窗口的STOP率。
- 已执行非STOP中的有害率、无效率、有效率；单独报告STOP遗漏机会，不把“没换”当失败预测。
- 实际覆盖rescue/lost/retained，原成功lost分母使用native成功数；与oracle精确槽位一致率仅作附录，不当动作正确率。
- 所有分组与每seed，不仅change；正动作收益按绝对值和分布报告，不能用大量近零连续改善掩盖零覆盖收益。

### 8.3 联合质量与部署门仍然独立

最终所有split、所有seed/group五pooled motion≤1.01native；native成功lost≤1%；protected overall/stable/transition误差≤1%害；change ADE及FDE各≥5%改善、三seed一致和项目原联合CI等major门不变。同路径coverage、J、完整GT-free聚簇及有效good簇完整保留，不能只报top1或被换入路径。

perwindow物理准入不替代pooled门；最多一次编辑不保证最多1%lost。一条被删路径可能承担某窗口唯一成功，必须直接检查。

主比较通过而以上任何门失败：标为**LOCAL_DECISION_SIGNAL / NOT_DEPLOYABLE**。整模成本超预算同样不可部署。主比较失败但S/I均有改善：只说明本新动作空间有描述性信号，不能归因于集合排序；不事后改主终点。

### 8.4 统计单位与边界

主单位sequence+target_track，全inner共同抽样后按change mask统计；window-weighted再seed等权，三臂/参照使用完全相同draws，RNG20261025。至少20条change-containing tracks；零分母draw>5%停止CI推断，不补轨迹或挑窗。

hold不是新的整体系统未见数据，inner也是反复开发集，只有三seed；CI仅支持探索。没有original_CAL track补接与新泛化数据，不称跨场景确认。

本系列不会证明“必须蒸馏”，也不自动训练新的坐标生成器。多解可接受标签来自训练GT，是普通训练监督；部署不接触GT。若未来压缩成直接生成器，必须另设不依赖oracle部署的对照，不能把本次训练标签当测试信息。

## 10. 轻量化与风险审查

11,488只是新增编辑器参数。真实总成本还包括F16原encoder/decoder、KIN生成器、400动作的特征/物理检查与数据搬运；内部K40不是等生成预算。必须计唯一参数不重复共享模块、CPU1thread/GPU实测、预热50/测量500，以及缓存命中和真正端到端两种口径。成本测量可进行经过冻结审核的旧模型推理；保存结果的独立算术审核则不作模型前向。无法运行真实端到端时，成本项标BLOCKED，不以缓存速度替代。

305,000整模参数预算不因新头小而自动通过；若已知超预算仍可将本轮定位有限机制探索，但不能进入“轻量部署成功”分支。不能在看结果后偷偷减少动作/关闭门省成本。

本次按ARS研究架构与同助手反证组织，不是外审：

- DA1：有oracle不代表GT-free可学；故E0只是机会门，E1/E2必须独立。拒绝把旧“过保守”说法当已确证。
- DA2：两臂需同标签同架构，原连续回归改为历史背景；防止把多因素改动归给排序损失。单次替换限制可能排除协同解，应如实停止。
- DA3：主门不能掩盖motion和成本；只学候选组合不能直接称新运动理解。当前设计已明确这些限制，实际结果阶段必须重新审查，不能预填PASS。
