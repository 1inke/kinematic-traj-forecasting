# 固定K20的一次性互补编辑：下一有限实验系列

日期：2026-10-25。状态：**DESIGN_ONLY / NOT_IMPLEMENTED / NOT_STARTED**。

本轮只交付设计，未训练模型、运行预检、重放旧模型、恢复归档数组或启动后台任务。本目录不是旧K1、G0或任何暂停任务的自动续跑指令。

## 核心问题

**既有候选池已出现联合可行的好集合；能否只凭观测与候选几何，在“保持原生20条”与“一次有效替换”之间做出可靠决定？**

这次不继续梯度投影，不再盲加候选，也不重新训练生成器。研究对象是候选生成后的**集合组合机制**，不是输出一条路径的top1 scorer，也不是新的坐标生成器。

主张要有限：固定最终K20不等于等计算成本。机制需要native20＋KIN20，内部40条路径与最多400个替换检查，必须单列真实成本，不能直接当作已完成的轻量化创新。
