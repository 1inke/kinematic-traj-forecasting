# EXP-SET-CALIB-DIAG 结果

**综合结论：`RANGE_OK_PLACEMENT_BAD`。** B0 等权终点散布的平均 β 为 1.000，5/5 个 seed 与均值分档一致，判定为 `RESPONSIVE`。低、高散布箱的平均 R/S 分别为 0.752 和 0.874。触发的附加判定为 EASY_TOO_WIDE、MISALLOCATED_EASY。

综合结论按设计表生成。β<1 时，拟合关系中的 R/S 随 S 增加而下降。容易组、困难组的范围方向需依据下表的覆盖率与经验散布确认。
