## 其余实现约定（先固定，后看结果）

- 仅C0 fit21719/dev4753；B0 E1C_E64_s42的固定最终EMA全部冻结。唯一模型前向用于各split一次构建缓存（无增强），不读取ETH/其他测试集。本次无端到端训练或B阶段。
- 单路GPU可用时用于缓存和小模块训练，CPU NumPy/SciPy用于完整集合指标；只加载小模块/缓存，不在训练循环运行编码器。FP32，AdamW lr.001/wd.0001、默认betas/eps、foreach=False，20轮、batch256含最后不足batch、不加EMA/早停/增强/未指定的梯度裁剪。按update从lr.001余弦衰减至0，无warmup，最终epoch20评价。
- 各seed跨臂使用同一完整初始化state（包括未使用的bias MLP）与同一每轮数据顺序。只有mask/关系偏置开关/再分配开关不同，注册参数量完全相同，另报实际有梯度参数量。
- sparse图按固定pass1终点米制距离选4个其他候选+self；关系为j−i的纵/横差、距离和基础logit差。图/关系只用固定候选和基础分数，无真值。距离并列按原候选索引稳定打破。全连接/对角臂保留同一bias参数但不使用。
- 再分配基于当前修正后预测/分数的detach副本：赢家按ADE+.25FDE；赢家FDE>.4才启用；非赢家r中选择与某个严格更高分j最近者。无严格更高分可比较时禁用该项。严格分数并列不视为更高。r的距离/分数排序不直接读取未来，但剔除赢家这一操作依赖训练真值，不声称整个r选择独立于真值。
- 附加SmoothL1是r全12步/2坐标平均，乘.5、对全batch平均（不活跃窗贡献0）；选择及门detach，附加项只对r轨迹回传，不通过离散选择对分数回传。B0原损失原样保留。
- D0/指标的未覆盖率按minFDE>.4；另报再分配实际门winner_FDE>.4，两者不混称相等。有效候选数采用终点距离.2m的complete-link聚类，避免链式桥接把跨度很大的候选合成一条；严格近对数量用距离<.2。纵向指标仅在B0三步总位移>.03m的方向有效窗口计算，另报n，不把低速默认朝向当物理方向。
- 槽位极少获胜定义fit/dev各自频率<.1%，仅描述，不作门槛。D0按all/stable/transition/change/decel_stop报告，不以诊断删选训练窗口。
