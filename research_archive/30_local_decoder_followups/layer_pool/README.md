# EXP-LAYER-POOL

EXP-REFINE-PRED 的三个确认折均未支持减速组普遍受损或纵向收缩的解释。本实验筛查另一种机会。同一冻结解码器的第 0 层与第 3 层是否覆盖了不同的未来，以及固定输出 20 条时能保留多少互补候选。

使用 REFINE-PRED 已复核的五折、34 个 E0/QFL 检查点和匿名行人轨迹簇。两层来自同一次前向，权重来自本机缓存。ETH 的五个种子和其余折的三个种子先在每窗平均，再按轨迹聚类做 4,000 次重抽样。E0 主报，QFL 检查趋势。

| 对照 | 输出 | 选择方式 |
| --- | --- | --- |
| 末层基线 | 20 | 末层全部 |
| 初层诊断 | 20 | 初层全部 |
| 4/8 条初层，置信度 | 20 | 保留 16/12 条末层最高置信度，按初层内部置信度补 4/8 条 |
| 4/8 条初层，覆盖选择 | 20 | 同样保留 16/12 条末层，以贪心方式补 4/8 条初层候选，每步选能最大降低 40 个预测终点到已选集合的平均最近距离的候选 |
| 两层候选池上限 | 40 | 使用真值评估整个并集的覆盖上限 |

选择阶段只用模型预测。池中各候选等权，分数只用于层内排序。所有混合组保留末层 Top-1 并沿用其输出，比较关注候选集合覆盖。主要报告逐折 minFDE、minADE、同一候选 ADE ≤ 0.2 m 且 FDE ≤ 0.4 m 的覆盖、救回和丢失比例，并按未来转向/转向且变速、减速、匀速作诊断。未来标签只供评价。

机会筛查以覆盖选择 16+4 为主要对照。至少三个折 minFDE 改善 ≥ 2%，且 ETH 的恶化不超过 1%，记录为固定预算机会。40 条池的上限和两个预算的分折结果均保留，供判断候选压缩瓶颈。结果属于已查看过的五折上的探索。

预检逐窗对齐 REFINE-PRED 的初层与末层 minFDE、minADE 和末层 Top-1 FDE，并确认没有重复槽位、候选预算准确。输出仅含逐窗派生量和汇总。
