这次实验是在现有 B0 模型上，完成一套五折、三个随机种子的基准评测。核心目标是测清楚：B0 的精度是多少、不同场景的表现如何、随机初始化带来的波动有多大，并保存以后分析所需的逐窗口预测。

整体流程是：**数据审核 → 训练预算比较 → 确定统一轮数 → 五折三种子正式训练与测试 → 汇总结果**。

| 阶段 | 具体工作 | 正式训练次数 | 主要产物 |
|---|---|---:|---|
| F0 数据审核 | 检查数组、坐标、训练与测试来源，以及验证集划分 | 0 | 数据审核报告及文件校验值 |
| F1 预算比较 | 五折分别训练64轮和128轮，统一使用seed42 | 10 | 10份验证结果 |
| F2 决定预算 | 按事先固定的规则，统一选择64或128轮 | 0 | 已确定的训练轮数及决定记录 |
| F3 最终评测 | 五折分别用seed42、43、44训练，再测试 | 15 | 每次运行的模型、预测和指标 |
| F4 汇总 | 计算逐折表现、五折平均和种子间标准差 | 0 | 最终结果表及完整性记录 |

一共25次正式训练，全部使用同一种B0结构。当前F0～F2已经完成，采用128轮，正在执行F3。

**数据如何组织。** 五折名称为eth、hotel、univ、zara01、zara02，每一折都有项目预先生成的训练和测试数组。这是沿用既有ETH/UCY协议的五折评测，并非把全部窗口随机平均分成五份。

| 折 | 完整训练集窗口数 | 测试集窗口数 |
|---|---:|---:|
| eth | 30,307 | 364 |
| hotel | 29,676 | 1,197 |
| univ | 9,874 | 24,334 |
| zara01 | 28,577 | 2,356 |
| zara02 | 26,076 | 5,910 |

每个窗口包含目标行人及其邻居，最多9人。输入是8帧观测坐标，预测目标行人未来12帧；采样间隔0.4秒，按实验协议对应3.2秒观测和4.8秒预测。邻居用于提供交互信息，正式指标只计算目标行人。模型前向只接收观测，未来轨迹用于训练监督与评价。

数据协议有一项已确认的修订：部分录制被预处理映射到相同scene编号，原先要求编号完全不交叉的检查不能直接适用。按你的选择，保留原数组，逐窗口核验原始录制来源。158,671个窗口均能唯一匹配回来源，审核未发现训练与测试来自同一录制的情况；不同录制仍可能在同一物理地点，因此不能称为物理地点完全隔离。

**模型如何产生预测。** 当前B0的总参数量固定为295,474，主体是F16编码器和h3锚点解码器。

F16先提取行人自身的运动信息，包括短期和较长时间范围的速度、运动变化等，再通过时间和行人之间的注意力结合邻居的观测历史，形成运动与交互表示。数据进入模型前会按目标行人的观测位置与朝向转换坐标，预测完成后再还原到世界坐标。

h3为20种候选运动分别生成未来第4、8、12步的三个可学习锚点，即未来1.6、3.2、4.8秒的位置，再通过分段线性插值得到每条候选的完整12步轨迹。模型同时为每条候选输出一个分数。因此，一个窗口最终得到20条轨迹，每条含12个二维位置，以及20个候选分数。

**训练配方保持一致。**

| 项目 | 实际设置 |
|---|---|
| 优化器 | AdamW |
| 初始学习率 | 0.00025 |
| 权重衰减 | 0.0005 |
| batch size | 64 |
| 学习率变化 | 1轮预热，随后按总预算进行余弦衰减 |
| 损失 | 原有ModeQueryLoss，另加权重0.20的软覆盖项 |
| 数据增强 | 反射、0.9～1.1倍速度缩放 |
| 评价权重 | 最后一轮的EMA权重，衰减系数0.995 |

EMA是训练权重的指数滑动平均，可以减小参数更新带来的短期波动。本实验固定使用最后一轮EMA；验证集负责决定统一的总轮数。

**为什么先做10次预算实验。** 每折从训练数组中按scene编号分组，在各组现有样本顺序的末尾取约5%作为验证集，其余约95%训练。每折用seed42独立训练一个64轮模型、一个128轮模型，共5×2=10次。

64轮和128轮两次训练都从初始化开始，各自按对应总预算设置学习率曲线。128轮实验不是把64轮训练简单接着跑64轮。

选择规则事先固定：先计算每折64→128的验证minADE相对改善，再对五折等权平均；如果平均改善至少1%，且五折平均minFDE不变差，就选择128轮，否则选择64轮。所有折统一使用同一个选择结果。

本次平均相对ADE改善为2.2169%，平均FDE变化为−0.0080米，因此确定采用128轮。这些是验证集结果。F0完整性审核读取过测试数组，但预算选择没有使用模型测试指标。

**15次最终训练如何安排。** 确定128轮后，每一折分别使用seed42、43、44，构成5×3=15次独立训练。每次重新使用该折100%的训练集，包括预算阶段留出的约5%验证窗口；从初始化开始，训练到128轮，用最终EMA在对应测试集上评价。

这15次不会继承预算模型的权重。正式运行中途暂停时，恢复的是同一次最终训练的完整状态。三个seed分别产生三组结果，用来观察训练随机性的影响；它们不会合并成一个集成模型，也不会把候选合成60条。

**指标如何计算。** 主指标是minADE20和minFDE20，单位均为米，越低越好。ADE衡量整条预测轨迹12个时间点的平均位置误差，FDE衡量第12步终点误差。对每个窗口，分别从20条候选中选择ADE最小值和FDE最小值，两者可以来自不同候选。

为区分“候选中有好轨迹”和“模型能选出好轨迹”，还会计算模型打分最高候选的Top1 ADE/FDE、按分数保留前3/5/10条候选后的误差，以及ADE最优候选自身的终点误差。

项目覆盖率要求同一条候选同时满足ADE≤0.2米、FDE≤0.4米。结果还会按stable、transition、change三组统计；这些组根据真实运动变化在评价时划分。另有匀速外推参照，以及NLL、Brier、ECE等打分校准描述指标，为后续分析保留依据。

**五折和三个seed如何汇总。** 先在每一个seed内部，对五折指标等权平均，每折占20%；再对三个seed的五折平均值计算均值和样本标准差，形成“均值±标准差”。ETH只有364个测试窗，univ有24,334个，但在主汇总中权重相同。还会提供逐折结果和去掉ETH后的四折平均，帮助观察差异来自哪里。

种子标准差反映训练随机性，不是置信区间，也不能单独证明方法间存在统计显著差异。

**并行与暂停属于执行方式。** 当前同一块GPU最多同时运行两个独立任务，一个任务对应某一折和某个seed。任务完成后自动补入下一个，直至完成15次最终运行及汇总。并行不改变模型、轮数或训练数据，也不会把两个模型的梯度合并。

Windows后台任务负责调度，退出GPT后可以继续运行，电脑需要保持开机和登录。每完成一轮，保存模型、EMA、优化器、学习率调度器和随机状态；暂停后从最近完整轮次恢复，中断当轮重新计算。已完成任务在校验后跳过。状态文件增加了唯一临时文件、写入重试和备用记录，关键结果文件持续写入失败仍会停止并记录故障。

**最终会保留什么。** 每次运行保存数据和代码来源校验值、训练轮数、随机种子、完整轨迹预测、候选分数、窗口ID、分组信息和逐窗口指标，最后形成SUMMARY.json与SUMMARY.md，并核验输出完整性。这样后续能分析哪些场景、哪些窗口失败，以及候选生成和打分分别有什么问题。

EXP-156、EXP-133可以提供历史量级参考，但它们的随机种子数量、训练安排和checkpoint选择方式不同，因此本次差异不能直接归因于某个组件。当前实验提供后续结构改造所需的基准数据，最终结果完成后再据此判断下一步方向。
