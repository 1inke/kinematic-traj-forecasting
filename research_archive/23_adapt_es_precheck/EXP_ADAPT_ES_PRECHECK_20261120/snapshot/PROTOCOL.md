# P1 / P2 执行口径

原设计见 [DESIGN.md](DESIGN.md)。P1 和 P2 使用 C0 保存预测及既有参照，计算部分在 CPU 上执行。唯一模型前向是设计所需的 200 窗口缩放等价性预检。P3 文献任务在原文中另有分工。

- P1 对五个 B0 seed 分别在 fit 上选择每组倍数。并列时取 grid 中较小值，各向异性并列按先纵后横的顺序选较小值。L2 在 fit 按已知未来动作选择，L3 是 dev 逐窗选择的理想上限。剔除 zara02 只改变 dev 评价样本，沿用主分析的 fit 倍数。区间按录制序列与行人编号聚类重抽样 2,000 次，变化量配对。散布用中位数，其余指标用均值。
- HPD90 使用 archive 20 对应 B0 seed 的等权全局核宽、A/B 分半及 1,000 个样本固定随机数。宽度干预不重新拟合核宽，也不更新候选分数。基线的 HPD90 布尔结果和 minADE/minFDE 逐窗与 archive 20 核对。
- P2 的主 ES 是米为单位的 24 维轨迹和原 softmax 概率，另做等权及终点敏感性。R 系列使用保存的局部坐标和封存的局部真值，距离度量对共同旋转和平移不变。K-means 沿用观测分箱及聚类超参，簇内计数用作权重。CV 单候选单列 K=1。
- E1 以模型族均值作为判定口径，同时报告全部实例的 Spearman。排序反向比例用可比较模型族对，精确并列另计。E2 用模型族均值及 B0 的样本标准差。A1、A2 达到原全 dev 门槛并要求剔除 zara02 后的变化方向仍改善。A3 主判定按 4/5 通过，同时给出排除场景的结果。E4 以五个配对 seed 相对变化的均值判定并报告逐 seed 情况。门槛不作为显著性检验。
