# S1结果解释补充：覆盖收益、未覆盖样例与运动学时间结构

本补充只读已有inner的native和三个seed路径及sample_metrics，使用NumPy重新计算逐slot ADE/FDE、同路径成功和11项加速度。无Torch、训练、模型前向、旧PID/任务查询或阈值修改。不是重复全套源SHA/聚簇/统计审计，也不是独立外审。原最终报告及锁定产物不改。

## 1. 本轮应如何定性

新A在同K20预算下，inner整体成功932→982/1021/1021，变化组166→186/191/192。属于有覆盖收益但尚不合格的候选生成器；BASELINE_NOT_READY正确，不等于完全没有学到有效路径。未执行B/E_bal，不能判断互补蒸馏/重加权效果。

旧history-only学生与新A同时改变输入和参数量，不能把差异全部归因于上下文。上游F16已见全部FIT/inner，不构成独立全模型泛化验证。覆盖提升为描述性结果，不能冒充预注册显著性结论。

## 2. 平均误差恶化主要来自哪里

所有ID、GT、native逐数组对应一致；重算三个seed完整inner逐slot ADE/FDE与保存sample_metrics EXACT。

以同一个candidate同时ADE≤.2且FDE≤.4划分共同成功、救回、丢失、共同失败。每类对全组平均误差变化的贡献为该类误差变化之和除以全组N。minADE和minFDE分别报告，不将它们拼成成功判定。

以下为inner变化组N=497、三个seed等权平均，单位m；正值是恶化，负值是改善：

|子集|对全组平均minADE变化的贡献|对全组平均minFDE变化的贡献|
|---|---:|---:|
|共同成功|−0.001643|−0.002836|
|救回|−0.009367|−0.025286|
|丢失|+0.007553|+0.020811|
|共同失败|+0.036911|+0.084388|
|总变化|+0.033455|+0.077077|

共同失败数量为278/269/268；其ADE贡献分别+.048945/+.025838/+.035952，FDE贡献+.120869/+.068073/+.064220，三个seed都是最大的正向项。共同失败是结果定义的事后子集，不是部署可知标签，更不能直接称为少量极端异常值或全部不可预测。

因此只保护原有成功还不够：需要同时控制原本未覆盖样例的连续误差退化。这是描述性算术归因，不证明具体结构或损失是唯一原因。

## 3. 加速度均值失败不等于高频抖动更重

采用原dt=.4，补最后观测原点→12速度→11加速度。inner变化组native的11项时刻均值，只有第4和第8项明显非零，分别约.806735和.180844m/s²，其余约2.6e−7至2.2e−6。这里第4项是v5−v4，第8项是v9−v8，不是直接把未来坐标第4/8点当加速度。

新A在全部11项上分布更广：第1项约.258–.323，第4项.118–.140，第8项.049–.078。原来的集中变化被减弱，但其他时刻增加了加速度。这解释了本样本中accel_mean升高而accel_p95、jerk_mean和jerk_p95降低的并存；不说明新变化在语义上正确，也不证明新模型更安全。

原先五运动学≤1.01native是已注册非劣约束，本轮不能删改来宣布通过。但相对native幅度不是现实运动真实性的充分标准。下一诊断应比较同路径质量及与GT运动变化的时间一致性，区分合理分布式转向/变速与无用弯曲；GT只事后分析，不进入部署或选例。

## 4. 建议和反方检查

1. 保留新A作为有收益的研究对象，但不升级正式baseline，不绕过S1自动跑B/E_bal。
2. 优先定位共同失败样例的方向/终点/速度误差以及上述分布式加速度是否匹配真实变化；不要直接加平滑项或扫描权重。
3. 如需证明上下文贡献，应另做相同82008参数、相同训练与容量的匹配信息消融，而非拿旧57432参数模型作纯因果对照。
4. 若后续训练，先固定一种针对已定位退化的保护因素，与本A配对比较，避免同时改变输入、结构、蒸馏和物理损失。需另立设计，不属于本次分析执行。

ARS同助手核验：范围检查保留上游暴露与容量混杂；分析检查同时保留覆盖收益和误差/保留负例；结论检查不将时间结构差异解释成理解运动或解除原门。不是外部评审。
