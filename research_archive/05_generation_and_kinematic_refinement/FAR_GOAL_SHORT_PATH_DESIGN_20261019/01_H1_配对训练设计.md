# H1：goal12 vs goal20，原12步输出不变

## 一、单因素与控制

六个fresh runs：A(H=12)、B(H=20) × seeds42/43/44。只改变远目标辅助监督的物理时间位置；相同架构、初始参数、统计、输入、训练IDs、m20、batch顺序、优化器和评价程序。每个seed成对初始化，不从失败head或已训G2/M2 warm-start。

旧F16/encoder/decoder/scorer不更新；只读immutable P2缓存。生成**20条新路径**，主比较为new K20对native K20，不将native20+new20的K40并集当等预算收益。不继承bottom4替换政策，不同时研究scorer。

## 二、目标和路径的明确关系

所有坐标相对原最后观测点。dt=.4，原12步总时长T=4.8；v0=(past[-1]−past[-2])/.4。

使用“12步等效位移”z表达目标，避免H=20仅因数值尺度更大造成损失加权变化：

```
z_k = T*v0 + center12_k + goal_head(h, query_k)
g_H,k = (H/12) * z_k
target_z_H = (12/H) * y_H
```

A预测g12，B预测g20；正常forward都只得到预测z，而不是GT。归一化不等于两种标签分布相同，目标难度变化仍须报告。

输入与模块固定：

- P2 96维以FIT18909的float64 mean/std统计，转float32使用，std<1e-6替1。
- context：96→128→64，GELU；query：20×16，可训练，N(0,.02)，两臂paired。
- goal_head：(context64+query16)→64→2，GELU，末层全零。
- process_head：(context64+query16+标准化预测z2+标准化v0 2)→64→6，GELU，末层全零；输出a,b,c三个二维系数。
- v0统计、z归一化统计均只用FIT原12步标签/观测，一套数值供两臂共用。z统计取原12步位移，避免B独有远标签标准化构成额外因素。
- center12：FIT的(y12−T*v0)聚类20中心，KMeans++、n_init=1、random_state=20261019、max_iter=100、tol=1e-4、Lloyd；保存中心和IDs。按(center_x,center_y,原cluster序号)确定共同slot顺序，不按outer效果排序。

路径采用同一固定低阶时间耦合形式，t=1..12、s=t/12：

```
p_k(t) = t*dt*v0
       + s^2 * (z_k - T*v0 + a_k)
       + s^2*(1-s) * b_k
       + s^2*(1-s)*(2*s-1) * c_k
```

它保留连续延拓在起点的v0，允许弯曲和改变短期终点；但离散第一步速度不必恰等于v0，**不提供任何物理安全保证**。p12=z+a，不强制p12=g20，也不强制p12=(12/20)g20。两臂初始z、系数和全部前12步路径应bitwise相同；它们不必等于native20，不能虚称nativezeroidentity。

这是一种**远目标条件的短期生成器**，不是已经生成并保证第20步到达目标的完整20步轨迹。目标与短期终点可以不同，H2必须检查process是否利用目标、是否学会完全抵消目标。若将来研究完整20步动力学一致性，应单独设计，不在此轮追加。

## 三、损失与责任绑定

对每个window、每个slot的完整12步路径：

```
A_k = mean_t ||p_k(t)-y_t||
F_k = ||p_k(12)-y_12||
Q_k = A_k + 0.5*F_k
j = argmin_k Q_k                       # exact ties: lowest slot
L_path = mean_i Q_i,j
L_goal = mean_i [m20_i * ||z_i,j - (12/H)*y_i,H||]
L_div = mean_i mean_{k<l} relu(.3 - mean_t||p_i,k-p_i,l||)^2
L = L_path + 0.5*L_goal + 0.05*L_div
```

目标系数0.5事前固定，两臂相同；不是依据效果选择。L_goal按整个batch N分母而非有效标签数，空mask为0。winner由短期Q决定；goal loss绑定同一slot j，不能分别取最小目标误差slot与最小路径误差slot再拼成一条好候选。argmin不反传，selected path和预测goal均按正常计算图传梯度；路径损失也可经z回传goal_head。GT不得teacher-force到process输入。

这保留hard winner机制以隔离时间尺度，不代表hard winner已经正确解决所有候选责任问题。记录slot占用/熵/并列率/死slot、两臂责任切换、L_path/L_goal/L_div和梯度范数，避免把仅辅助损失降低当短期收益。

## 四、固定训练协议

AdamW lr=.001、weight_decay=.0001、betas=(.9,.999)、eps=1e-8、foreach=False，batch256、shuffle、drop_last=False、25epoch，无scheduler、无early stop、无grad clip；固定epoch25 primary。所有旧模型冻结。forward头为float32，几何路径与距离计算float64，精确dtype写入manifest；统计结果不得混用不同后端产生的静默默认值。

先做真实subset 2epoch恢复预检，再启动正式6runs。允许先执行seed42以核查工程流程，但不能查看其outer效果后改变H、loss、basis、epoch或取消不利seed；只有预注册科学/资源/来源失败可中止并报告INCOMPLETE。

两个比较层次必须分开：

1. B对A：远目标时间尺度是否有额外价值。
2. B对native：该生成器是否达到实际改善与安全门。

B优于较差的A不自动代表模型进步；两者都优于native而B不优于A，也不能证明远期监督必要。
