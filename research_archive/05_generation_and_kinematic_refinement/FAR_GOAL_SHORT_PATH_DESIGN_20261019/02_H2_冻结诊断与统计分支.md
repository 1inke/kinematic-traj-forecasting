# H2：评价原12步，并检查模型是否真的使用目标

## 1. 主评价：不换问题、不拼oracle

H1全部6个末epoch模型均保存FIT、outer、inner、original_CAL的预测。FIT是训练内诊断，outer ALL为主评价，其余为次评价。每套输出保存原sample_id、真实track/scene/group、m20和完整K20×12×2路径，不能只保存minADE/minFDE。

对每个窗口：

- `minADE=min_k ADE_k`、`minFDE=min_k FDE_k`分别是传统oracle误差，二者可能对应不同路径，不能据此声称存在完整好候选。
- `J=min_k max(ADE_k/.2,FDE_k/.4)`；覆盖必须同一条完整路径满足ADE≤.2且FDE≤.4。
- native→A、native→B、A→B分别统计retained/rescue/lost/neither及净覆盖；lost/native_good为原成功丢失率，不能用lost/rescued代替。
- 早中晚误差用同一个最小J slot，不能逐段换slot拼接。并报告这个slot与Q winner、minADE、minFDE slot的区别。
- GT-free complete-link聚簇：`D=max(mean_path_distance/.10, endpoint_distance/.20)`，cut=1，全K20参与；报告distinct和含good的有效簇，更多簇不自动更好。
- 原0.3/0.5只能固定敏感性，不替换0.2/0.4主标准。

所有split按overall/stable/transition/change逐seed报告完整分母；另按scene描述。原生数组同ID相同，不重复计算出的native误差不得被算作独立replicate。

## 2. 运动学与安全门

全部候选参与五项pooled population指标：speed p95、acceleration mean/p95、jerk mean/p95，dt=.4。严格沿用G2/M2的原口径：在12个相对预测点前附加最后观测原点0，得到12个速度、11个加速度、10个jerk；group内所有window×K×时间项直接pool后计算，p95用NumPy linear quantile。已核对`G2_frozen_goal_process_20261014/metrics.py:motion`，不能改成只在预测点内部差分，也不能先算每window p95再平均。额外观测速度接缝分析单列，不能替代原门。

在每个split/每seed/每原运动组，每项必须literal≤1.01×native。native为零时直接按绝对不等式判，不加epsilon/floor以求通过；百分比记undefined。保存算术允许报告浮点重构误差，但不得把重构容差变成科学门容差。

原major不放宽：change ADE、FDE各至少5%改善；overall/stable/transition误差最多1%害；三seed一致、原生对比联合证据、完整候选覆盖/成功保留和全部五motion门通过。另明确本系列实用门：outer change覆盖至少+2pp（253个时至少净增6个/seed），各组native-good lost≤1%，protected coverage不降低。需同时报告置信区间，不能仅通过点估计就宣布突破。

## 3. 统计预注册

主family16 = {B−A, B−native} × {outer overall, outer change} × {coverage, minADE, minFDE, J}。

- paired target-track与model-seed交叉bootstrap 20000次，PCG64 seed=20261019。一次抽完整outer tracks并保留其全部窗口，同一draw、同一seed索引用于所有方法/指标；再按group筛选，不能各方法各抽样。
- point estimate为三seed各自窗口均值再平均。native固定值与每seed配对，不能当三套独立模型。
- 报原95%区间，以及Bonferroni family16区间分位数[.0015625,.9984375]。这是探索性聚簇bootstrap，不是可靠的三scene总体推断。
- 某draw子组为空则记无效并公开；不足19000有效draw、实际有效change tracks<20，则该family相关结论为INSUFFICIENT，不更换抽样方法取得显著。
- 同时报告每seed结果和等track权重敏感性；敏感性不能覆盖主结果。m20子集与H2只报描述/未经主family校正的探索区间，不能冒充主检验。
- FIT好outer差、CAL差等应比较实际效果差异；不能以“一组显著、另一组不显著”替代组间差异检验。

远期方向信号要求：B−A change覆盖校正区间>0、ADE/FDE/J区间<0，三seed覆盖不下降，且安全门通过。未满足只标未建立；不自动判远期信息无用。

## 4. H2冻结干预：区分目标预测与目标使用

H2只在outer/inner/original_CAL固定模型上执行，不训练，不挑最有利样例。每臂每seed保存以下四种条件，每种仍K20和相同12步评价：

| 条件 | 对process输入z的操作 | 能回答与不能回答 |
|---|---|---|
| 正常 | 原预测z | 正常性能 |
| CV目标 | 全slot置为4.8*v0，其他context/query不变 | 是否依赖超出当前恒速方向的预测目标；可能是OOD，不是严格因果必要性 |
| 跨track目标 | split内按SHA256(tag+track+sample_id)顺序，对每窗选循环向后第一个不同track窗，复制其整组20个z；不按GT/表现匹配 | 错配目标是否改变路径与覆盖；同时破坏目标和context一致性，不等于目标的独立因果效应 |
| GT目标诊断 | 仅m20=true窗口，全部slot置为(12/H)*真实y_H，其他context/query不变 | 当前process在理想目标输入下的局部响应；非部署、不是真正最优上界，且可能压缩多样性 |

无不同track伙伴则标记unavailable，不能改成同track；GT诊断两臂使用同m20 cohort。所有条件同时保存原正常输出，不能从干预结果选部署目标。

直接报告：目标同slot欧氏误差（米及归一化z误差分开）、目标minK误差、J-closest路径所绑定的目标误差、slot占用；process系数a/b/c、`p12−z=a`抵消幅度；目标替换引起的平均路径位移/终点位移；完整覆盖/保留/五motion变化。不同H的物理目标误差不能直接比较数值大小后宣称谁更准。

严格区别：**目标预测更准、process对目标敏感、前12步完整候选更好是三个不同结果。** oracle干预负结果不证明“即使知道目标也无用”，因为输入分布与多样性均变了。

## 5. 结果之后只选择一个大分支

| 结果模式 | 合理结论 | 后续建议（本轮不自动实施） |
|---|---|---|
| B稳定优A且优native，覆盖/保留/全部motion过门 | 远期监督在这个冻结表示和生成器中有价值 | 再做真正独立身份/recording验证；之后才考虑升级或整合 |
| B优A但仍差于native，或motion失败 | 时间尺度有相对信号，尚无可用候选生成 | 先定位过程表示/成功保留，不能以相对胜出升级baseline |
| FIT强、outer/CAL弱，目标误差也恶化 | 目标预测或条件映射迁移不足的证据 | 回到表示与分布迁移；不盲调步长或scorer |
| 预测目标差，但GT目标诊断明显改善 | 更好的目标可能有价值，当前目标预测是候选瓶颈 | 独立设计目标可预测性/多模态目标研究；不是用GT部署 |
| 目标改动很大、路径几乎不变；a抵消z | process可能绕过目标条件 | 研究条件使用机制，而非继续拉远目标 |
| 目标使用明显但短期覆盖不改善 | 远期位置可能不足以约束短期路径，或过程表达不足 | 研究运动状态/路径拓扑条件；不能断言所有远目标无效 |
| A/B均弱或区间太宽 | 本参数化/证据不足 | 有限结束并报告；不自动扫H、loss权重、basis阶数 |

近期重复探索、F16已见旧pool、target-disjoint不等于context-disjoint、旧CAL已反复阅读、三seed和少scene限制全部保留。即便成功，只能论证候选生成证据，不是“模型真正理解行人意图”的最终证明。
