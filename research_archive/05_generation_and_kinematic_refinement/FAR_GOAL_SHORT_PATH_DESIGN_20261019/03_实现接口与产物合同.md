# 实现接口、核心伪代码与产物合同

本文件是实现说明，**不是可直接运行的已验证代码**。当前目录不含launcher/训练器，也没有预检PASS声明。

## 1. 建议模块

```
execution_<date>/
  data_contract.py       # ID/原坐标/未来20标签/mask/跨区间归属
  shared_statistics.py   # FIT-only 统计、共同center12
  model.py               # 同一GoalConditionedShortPath，H不改变forward图
  objective.py           # 同一Q winner，H仅决定aux target
  train_paired.py        # 6 fresh runs，固定25epoch
  evaluate_saved.py      # 完整路径/coverage/聚簇/运动学
  diagnose_goals.py      # H2显式干预，无正常路径GT接口
  preflight.py           # 数值、ID、梯度与真实恢复
  audit_saved.py         # 独立CPU保存算术/来源/统计复核
  protocol.json / source_manifest.json / runtime_state.json
```

不要继承旧runner的顶层写入和固定6GiB guard。读取旧类时用隔离shim或直接实现最小独立模块，所有新增仅新执行目录。每run路径包含arm、seed、protocolSHA；不同source的结果不能因文件已存在而skip。

## 2. 输入与forward合同

```
ModelInput:
    p2: float32[B,96]      # frozen observed-only token content
    v0: float32[B,2]       # raw past最后两点/.4
ModelOutput:
    z: float32[B,20,2]     # 12步等效目标，未scale到H
    path: float64[B,20,12,2]
    process_coeff: float32[B,20,3,2]
Labels:                   # 独立对象，不传入正常forward
    y12: float64[B,12,2]
    y20: float64[B,2]
    m20: bool[B]
```

H只用于解释`g_H=H/12*z`及辅助target，不作为额外可学习输入。A/B完全同构；记录精确parameter count而不预估后冒充实测。H2 `decode_with_z(context, query, v0, z_override)`单独入口，必须标`diagnostic=True`且不用于训练/正常evaluate。

伪代码：

```python
h = context(standardize_p2(p2))
hq = concatenate(broadcast(h, K=20), queries)
z = 4.8 * v0[:, None, :] + centers12 + goal_head(hq)
abc = process_head(concatenate(hq, standardize_z(z),
                               broadcast(standardize_v(v0), K=20)))
a, b, c = abc.reshape(B, 20, 3, 2).unbind(dim=2)
s = arange(1, 13, dtype=float64) / 12
# 以下提升到float64，保持梯度，不detach z或abc。
path = (4.8*s)*v0 + s**2*(z - 4.8*v0 + a) \
       + s**2*(1-s)*b + s**2*(1-s)*(2*s-1)*c
```

广播必须显式为[B,20,12,2]，不能依靠恰好同维的隐式broadcast；输出0点不保存为第1预测点。

## 3. 目标掩码与责任伪代码

```python
distance = norm(path - y12[:, None, :, :], dim=-1)
ade = distance.mean(dim=-1)
fde = distance[:, :, -1]
q = ade + 0.5*fde
j = q.argmin(dim=1)                        # lowest slot on exact ties
selected_z = gather_slot(z, j)

# 先选有效行，再算目标误差，避免0*NaN仍为NaN。
if m20.any():
    physical_target = y12[m20, -1] if H == 12 else y20[m20]
    goal_sum = norm(selected_z[m20] - (12/H)*physical_target,
                    dim=-1).sum()
    goal_loss = goal_sum / B               # 不是 / m20.sum()
else:
    goal_loss = selected_z.sum() * 0

loss = gather_slot(q, j).mean() + .5*goal_loss + .05*diversity(path)
```

m20=false的y20允许NaN作为缺失标识，但不得送入正常forward或无掩码的损失计算。每batch断言两臂mask/ID相同；改变y20仅能改变B辅助损失，不能直接改变相同参数下的forward输出。改变H同时同步manifest标签，不允许复用A的checkpoint名假装B。

## 4. 必存内容

每run至少：

- `checkpoint.pt`：全部newhead参数和buffers、optimizer、epoch/global step、CPU/CUDA/loader/Python/NumPy RNG，绑定source/split/stats/protocol SHA。
- `run_manifest.json`：H、seed、实际训练ID/m20 SHA、FIT统计SHA、KMeans实现版本与结果、所有参数初始化SHA、损失/优化器/dtype/25epoch和来源依赖。
- `history.jsonl`：25行完整epoch；损失分项、mask数量、winner/ties/slot频率、梯度诊断、时间和资源，不含被用于挑checkpoint的outer评价。
- `metrics.json`、`assignment_stats.json`、各split显式ID的完整saved NPZ及done SHA。
- 输出z、物理g_H、a/b/c和path；native缓存引用及SHA、y12/长标签/m20/track/group映射用于独立审核。
- H2每种干预保存input override及donor ID/真实track、missing原因、所有输出，不能只存改善案例。

全量保存大小先测算，允许chunk压缩和流式审核，不因为磁盘压力删困难ID或只保存best slot。

## 5. 实施与恢复顺序

H0 → 锁定数据/科学protocol → 数值与GPU预检 → 两臂真实513 FIT + 12 inner子集2epoch连续/中断对照 → 实测吞吐与资源 → 最终source锁 → 唯一正式执行 → saved独立审核 → H2 → 总报告。

真实恢复必须比较全部params/buffers、optimizer和所有RNG、history/assignment诊断EXACT，不只比较最终loss。subset 2epoch不是完整FIT两轮，也不是“所有旧模型重放”。完成run须核对source/model/output SHA才能skip；未完成run只有完整checkpoint恢复合同满足才resume，不重训旧完成run。

资源按实测需求E/1.3E动态预算、主机余量、磁盘峰值决定，记录Windows peak private/RSS，不能用最后一次RSS代替峰值。训练/保存聚簇/CI/终SHA全部计入ETA；预检只测吞吐，不保存benchmark模型或依据其科学效果选方案。

最终`RESULT_ANALYSIS.md/json`须分别给出H0事实、H1执行状态、16个主区间、每seed反例、H2诊断和分支；所有未执行/缺标签/不充分项明写。执行成功不等于major通过，不自动改baseline/historycycle11或恢复旧自动任务。
