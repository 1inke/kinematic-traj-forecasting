# 远期目标条件能否改善原12步候选：新实验系列

状态：**DESIGN_ONLY，2026-10-19**。本轮只交付设计，没有训练、模型推理、标签全量连接或资源预检。本文中的门槛是事前规定，不是已通过的结果。

## 1. 要回答什么

保持原8步观测、同一预测起点和原未来12步评价不变，比较：

> 预测第12步目标 → 条件生成原12步路径；
> 预测第20步目标 → 条件生成原12步路径。

间隔仍为0.4秒，原评价范围4.8秒，远期目标8秒。**不是多看8步未来、推迟预测起点、缩短评价区间，或把20步位移在12步内走完。**

当前假设：远期目标监督可能使模型从“追随短期位置”转向“利用较长时间尺度的运动方向”，从而改善前12步。但远期目的地不能唯一决定绕行、停止和动态交互；正结果也不是心理意图或完整运动理解的证明。

## 3. 有限路线，不扩成无尽调参

| 阶段 | 工作 | 训练数 | 进入下一步条件 |
|---|---|---:|---|
| H0 | 原ID、分区、长标签、未来选择和重复内容审计 | 0 | 身份、时间、坐标及可辨识规模门满足 |
| H1 | 同架构goal12 vs goal20；3个paired seeds；固定25epoch | 6 | 工程预检通过后按完整预注册运行，不按outer表现删seed |
| H2 | H1冻结模型的目标替换、跨轨迹目标打乱、GT目标局部诊断 | 0 | 保存明确干预语义；缺标签保留为未测，不补假GT |
| 总结 | 原12步覆盖、保留、运动学、目标使用与泛化联合判断 | 0 | 完整审核；不自动启动下一结构或scorer |

H1是一次“**相同结构下目标监督时间尺度**”比较，不是目标模型 vs 无目标模型。两个目标的难度和标签分布不同，梯度方向自然不同；不能将其解释为纯粹的心理意图干预。三组seed共6个新小head，旧F16、encoder、decoder、scorer均冻结。
