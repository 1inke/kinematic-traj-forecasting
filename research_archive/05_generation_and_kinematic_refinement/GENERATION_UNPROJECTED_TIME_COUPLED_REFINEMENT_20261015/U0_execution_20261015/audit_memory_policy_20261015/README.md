启动前：可用物理内存和可用commit均≥预计本任务总峰值×1.3。
运行中：物理余量≥max(预计总峰值−当前本进程RSS,0)×1.3；commit余量≥max(预计总峰值−当前本进程private,0)×1.3。已占用部分不能与“剩余可用”重复比较。

1.3是唯一安全系数，不新增隐藏固定6GiB底线。此配置针对剩余保存审核，不将训练内存再计一次；未来不同任务要重新估计，不把本数值当永久阈值。
