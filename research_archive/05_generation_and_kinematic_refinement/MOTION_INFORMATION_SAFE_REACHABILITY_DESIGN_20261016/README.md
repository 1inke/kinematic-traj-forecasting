# 下一系列：安全可达性与运动信息的分离验证

初稿：2026-10-16；完成修订：2026-10-17（日本标准时间，保留初稿目录名）。状态：**DESIGN_ONLY，未实现、未预检、未训练、未启动自动跟进。**

## 为什么转向这个系列

T1/T2已经结束，不再启动原D/T3。现阶段不应继续扫keep系数、位置/速度坐标、head宽度或scorer，而应分开回答两个更大的问题：

1. 在原来的小幅时间耦合修正域内，是否能找到**完整覆盖增加且运动学达标**的轨迹集合？
2. 排除best-of候选责任分配和小幅输出域的限制后，观测历史能否提供**在outer上可读出的修正信息**？

这里的“运动信息”指可测的未来轨迹预测信息，不等于心理意图或真正理解运动。“未找到”也不等于“不存在”。

每个阶段均以真实预检预测的**计算、保存、完整审计总时间≤30分钟**为启动条件；这是预算上限，不是现在给出的ETA。预算不够则列未执行原因，不偷偷减数据/epoch、放松容差或开长任务。
