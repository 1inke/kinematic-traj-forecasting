## 建议图注

**图1 运动相关稀疏交互与轻量化预测框架。** 根据目标行人及邻居的可观测历史，编码位置、速度和加速度等运动状态，构建有向交互关系，在有限邻居预算内聚合时空信息。共享运动表征驱动固定20个模式查询，非自回归地产生未来12点的完整候选轨迹。右侧列示信息效率、输出效率和实际部署成本的验证维度。该图展示已有架构基础与拟开展的稀疏组织及集合感知生成研究，不预设精度或加速收益。

**图2 固定候选预算的集合感知互补非自回归生成。** 模式查询读取共享上下文，拟通过轻量集合信息交换协调候选特征，再并行输出完整预测时域。候选间通信不引入逐未来时间步自回归。互补性通过同一完整候选的质量、新增覆盖、既有成功保留及运动学联合检验；真实未来仅用于训练监督及事后评价。SetMix 为概念设计，其实现与收益仍待逐因素实验验证，蒸馏不作为必要条件。

## 编辑与复现

- `build_figures.py` 是两个成品的共同绘图源；使用已有 `<PYTHON_ENV_ROOT>/python.exe` 运行，无安装新依赖。
- `.drawio` 为离线、未压缩 XML，文字、节点、曲线和箭头可单独编辑；不是嵌入 PNG。
- `.spec.yaml` 和 `.arch.json` 是共同生成器的精确 primitive 布局 sidecar。YAML 使用 JSON 兼容写法，**不是**通用 Draw.io CLI 的 nodes/edges schema；请用本目录 Python 源重建，不向通用 CLI 声称通过该 schema 验证。
- SVG文字保留；图中仅画少量轨迹/节点代表 K20，不能把图形条数当作实际候选数量。
