# 有限计算与候选预算下的轻量化行人轨迹预测：开题技术路线与研究证据

日期：2026-10-20。范围：项目现有模型、代表性实验链与最新协议审计；本轮没有训练、启动任务或修改历史科学产物。

本次修订：将集合感知互补非自回归生成正式纳入**拟创新点**，与运动相关稀疏交互共同构成主线。这里“纳入”是研究计划定位，不是宣布该机制已实验成功；蒸馏不再被视为必要技术路线。

## 先给结论

建议把当前方法组织为一个完整研究点：

> **轻量化行人轨迹预测，如何在有限计算量和有限候选数量下，保留关键运动信息，并生成有效覆盖不同未来的轨迹？**

建议题目：**面向有限计算与候选预算的轻量化行人轨迹预测方法研究**。

拟创新点一是**面向有限交互预算的运动相关稀疏交互建模**；拟创新点二是**面向固定候选预算的集合感知互补非自回归生成**。编码端研究关键动态信息的高效处理，解码端研究有限候选的有效覆盖；非自回归提供并行生成框架，不作为一个单独的首创声明。

模型负责回答“输入经过什么模块得到预测”；创新点负责回答“针对什么未解决问题，提出了什么不同于已有方法的机制，并用什么证据证明值得采用”。两者不能一一按模块数量机械对应。

目前最可靠的基础是：已有可运行的 F16 编码—并行解码框架；历史统一协议实验支持其预测能力；已识别候选覆盖、成功保留、迁移与实际执行成本之间的矛盾。**尚未获得一个同时满足新协议、独立泛化、固定 K20 覆盖改善与运动学要求的新模型。**

不要把开题写成“不断修补原生轨迹”，也不要承诺已经实现心理意义上的运动理解。应写成：**在轻量化约束下，学习能够区分运动状态和交互条件、产生有效互补未来的预测模型。**

## 阅读与证据约定

- “已有”不等于“论文级独立验证完成”；“拟”不等于已经有效。
- 同一候选必须同时满足 ADE≤0.2m、FDE≤0.4m，才计完整好轨迹覆盖。文献常用分别取最小值的 minADE/minFDE 另列，不能互换。
- native20 是冻结候选参照，不是恒速 CV；其行为偏直线也不等于代码就是恒速外推。
- 参数量分清整模、可训练部分、新 head。历史正式 F16 为 355,048 参数；新协议 305,000 是待实现预算，不是现有成绩。
- “运动理解”在本文中仅指可检验的运动信息利用、条件响应和未见样本预测能力，不是意图识别或人类心理理解。
- 本轮核对报告、部分原始汇总 JSON/CSV 与最新来源审计；未重放全项目模型、全部路径、所有置信区间，也不替历史作者做完整训练来源认证。
- 采用研究证据整理与学术方法写作框架，将事实、推断、待验证方案分层；反方检查由同一助手完成，不是外部同行评审。
- 本次更新依学术写作流程区分模型结构、设计理由和有效性证据；沿用已核对文献，不将本次改稿冒称新增系统文献检索。具体新增解码器仍需实验预注册，文档修改不授权或启动训练。
