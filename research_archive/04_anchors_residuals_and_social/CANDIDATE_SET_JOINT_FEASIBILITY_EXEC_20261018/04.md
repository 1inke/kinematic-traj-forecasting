# 04 实现、验收、资源与最终分支

本文是实施合同，不是已经存在的代码。所有列出的模块都须在新执行目录实现、检查、锁源；本次只交付Markdown。

## 1. 建议模块边界

| 模块 | 接口/职责 | 禁止混入 |
|---|---|---|
| `freeze_inputs` | 读取已有pool、IDs、split、旧model/source；输出新manifest | 改写旧cache或伪造历史锁源 |
| `metrics_independent` | saved paths→同路径质量、聚簇、完整五motion | 模型前向或训练 |
| `oracle_instance` | pool+GT+group→K0-A及R/S数学实例 | 可部署预测代码 |
| `oracle_verify` | indices→实际路径、真实门、证书/松弛核验 | 用solver内部成本替代真实指标 |
| `action_geometry` | pool+current indices→动作、特征、GT-free运动过滤 | GT/ID/group/scene/logit |
| `fit_labels` | 仅FIT_train的pool+GT→I/S标签 | outer/inner/CAL真值、oracle teacher |
| `fit_regressors` | 固定行与超参→新I/S模型 | generator/旧scorer更新 |
| `select_set` | pool+past+新模型→20indices及轨迹 | GT、真值组和oracle动作 |
| `review_saved` | 全输出复算/CI/源SHA→review | 静默修阈值或换策略 |

部署核心接口应能表示为：

```text
select_set(native_paths, kin_paths, observed_past, predictor, fixed_policy)
    -> selected_pool_indices, action_trace
```

函数签名与运行时对象都不能携带隐藏future、GT-derived group或样本身份。输出路径只由pool gather；采用统一pool-index升序作为保存顺序，另存原生/新族及物理slot映射。没有新top1评分器，旧native logits不能按新排序直接解释为新候选概率。

## 2. 必需的小规模测试

### 索引与质量

- 样本ID重排后显式映射仍正确；重复ID/未知ID/錯split/缺seed拒绝。
- 相同长度但ID不匹配必须失败。
- K20没有重复pool index；20条值与pool gather EXACT，池原值不变。
- 构造minADE和minFDE来自不同slot的样例，joint coverage不能误算成功。
- K0-A最多3个quality witness就能匹配union；并列、重复路径、native已全好均覆盖。
- 真正lost必须使用最终集合覆盖，与“原生good路径被删但已被KIN救回”区分。

### p95与优化

- 小型合成池穷举所有指定K子集，与R必要条件、S充分条件和真实linear quantile逐个比较；验证`feasible_true ⇒ R`及`S ⇒ feasible_true`，**不能**要求R⇔S。
- 单独构造下阶≤τ但插值p95>τ的例子，确保R解仍会被真实审核拒绝。
- γ=0、native零运动、重复值、τ边界、某一项失败、空组处理。
- 均值分母和counts随K/T/group人数匹配，speed12/accel11/jerk10不能混。
- 优化器超时、有incumbent无bound、bound不足、numeric infeasible无证书均有独立状态。
- 必须验证连续松弛/整数容差不会把分数x当真实20条输出。

### 模型与动作

- 两臂训练行、特征dtype/顺序、状态与超参完全配对；唯一不同是登记的监督定义。
- 113维特征逐列来源清单；GT/group/ID修改不影响`action_geometry`和`select_set`。
- 替换冗余差候选时，individual标签可以有收益而集合标签为0；删除唯一支持时集合损害必须显现。
- 单步和累计动作均不重复使用native/KIN，最多20次；0次、20次、全被拒、预测并列全部有测试。
- 每次重新计算真实窗口物理门，不把线性均值预算误用于p95。
- 序列化加载预测EXACT、完成job SHA/source兼容跳过、坏源/坏输出拒绝。
- K2遮罩保留`to_mean`和其他纯几何，所有past交叉列以及其集合统计同时遮罩。

### 独立审核

实际保存128个按ID哈希选择的FIT fixture，独立实现重算quality、聚簇、motion、indices、动作轨迹和保护判定；不得按效果挑fixture。

solver方案需检查整数解的实际路径，不把solver返回SUCCESS等同科学PASS。HGB不声称GPU梯度或2epoch optimizer/RNG恢复；若阶段只读保存数据，不虚构训练恢复。

## 3. 工程预算与执行流程

当前用户只要求文档，不启动任何阶段。以后明确开始实施时：

1. 新执行子目录保存科学协议及本目录文档SHA；预检完成后锁源。科学源锁定后不能静默修代码/换digest，修复需保留失败版本并新建恢复目录。
2. 实测输入读取、特征、组合实例、训练及保存审核成本；分开给出compute、IO和审计ETA。最终full clusters/CI/源SHA不能漏出估时。
3. 资源按真实任务和保留进程树的E及1.3E、系统可用物理/commit、磁盘峰值实施；复用项目最新规则，不复活已撤销的固定6GiB、30min或2s禁令。若本研究另定计算预算，明确是本次预注册预算，不是旧限制复活。
4. 393216×113动作特征按批次/内存映射构造；不缓存所有窗口×20步骤×400动作的高维数组。CI按track充分统计量计算，保留与直接重抽小fixture的一致性测试。
5. 独立后台运行只在真实需要时采用唯一worker/按需零trigger/byte-lock；只一次startup、一次预计50%耗时检查、一次完成节点。快于半程完成就立即分析；慢于节点按真实阶段修正，不重启、不高频poll。
6. 不查、恢复或重训旧已完成/明确暂停的任务，不改OS/pagefile、不终止用户程序。没有实际启动就没有生产PID、运行状态或可信完成ETA。
7. 求解器中途恢复能力与HGB中途恢复能力各按真实实现声明。无精确恢复能力时不得用“恢复”名义静默重做全job；保留partial和来源，按当前任务权限处理。

## 4. 输出与完成定义

每阶段至少：

```text
README.md / DESIGN.md / protocol.json
input_manifest.json / source_manifest.json
runtime_state.json / PREFLIGHT.json
models/ 或 solver_instances/（按阶段）
predictions/（sample_id, track, group, pool indices, paths）
action_traces/ / metrics.json / bootstrap.json
ARITHMETIC_AUDIT.json / PRESERVATION.json / RESOURCE.json
RESULT_ANALYSIS.md / RESULT_ANALYSIS.json
```

K0的oracle目录不能加入K1训练白名单。K1保存五输出目标版本与训练行，不仅保存树参数。任何新输出出现dtype转换都须同时保存原计算dtype与再加载审核，SHA不能把float64计算数组与float32保存数组混为同一字节内容。

worker+exit双SUCCESS与saved audit全通过只代表执行完成；科学门另判。缺original_CAL等项目明确列NOT_DONE/BLOCKED，不能把可执行部分结束写成整套全部成功。

完整报告至少含：

- 所有seed/split/group及真实分母，不只最优seed/overall。
- 各类候选的覆盖、错误尾部、原生成功保留、有效好簇与五运动学。
- 原生→池→oracle→固定策略→学习策略每层的差距；不把GT oracle当部署基线。
- 数据版本、训练/校准是否被generator见过、outer既往选择历史、三seed和相关窗口限制。
- 时间、峰值资源、输出/源SHA、失败与恢复、原协议偏离。
- 同助手反方2/3和最终分支结论，不称外部独立评审。

## 5. 最终分支：不无限追加局部变体

### A. 当前池有联合机会，策略/学习也能保留

若K1达全门，K2解释显式条件信息；全系列总结后才考虑真正未参与方法选择的数据确认。当前不擅自引入新fold/test/外部数据，也不据重复outer宣布SOTA或升级baseline。

### B. 当前池有机会，固定策略未达到

只报告操作路径、窗口物理限制、单调门或贪心顺序可能挡住见证。已知有限K0-C失败不证明所有策略都失败。下一设计可以只改变其中一个策略因素，但必须先指出哪一类见证被原规则排除；不同时训练更强generator。

### C. 策略oracle成功，学习器失败

优先分析GT-free动作预测的假阳性/假阴性和训练/部署状态偏移；不把“oracle成功但模型没学到”直接写成唯一共享映射根因。结束本次I/S对照，不继续换树深、更多状态、更多标签权重凑PASS。

### D. 某项联合目标被有效上界/证书否定

仅此时才能说“当前冻结池在当前要求下不足”。指出是质量上界、运动约束还是二者联合导致。

后续生成方向应围绕该具体缺口重新设计：例如在保留native稀有精度支撑的前提下，产生能填补change coverage hole且不抬高速度尾部的路径。不能先决定某个MoE/扩散/Transformer，再反过来给失败找理由。本目录不提供未经证据选择的第三generator配方，也不授权自动启动它。

### E. 无见证也无证书

结论为UNKNOWN_WITHIN_BUDGET，附当前上下界和资源。允许结束一次没有确定答案的实验，不因此无限搜索或把数值失败改写成科学不可行。

## 6. 本系列刻意不做

不重训旧KIN/F16/decoder；不混入W0 oracle teacher、P1 λ扫描、集合协同head或P2；不继续11/9…14/6配额扫描；不改原good/motion标准；不按outer挑配置；不把生成40再选20称相同计算成本。

W0给出的“安全且保护目标有利的候选特异修复存在”保留为机制证据，但不是本系列前置任务。若另起W0学习性研究，必须另登记参数可达性/优化/条件迁移的区别，不能与本轮选择器结果混合归因。
