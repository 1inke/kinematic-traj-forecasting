    # selected: 20 distinct physical indices; native [0,20), KIN [20,40)
    return [(r, l) for r in sorted(selected) if r < 20
            for l in range(20, 40) if l not in selected]

def observe_state(pool40, past, selected, frozen_models):
    # Forbidden inputs: GT, group, scene, track, sample ID, oracle action.
    # Features must equal the original 113-channel contract.
    pairs = enumerate_legal(selected)
    pred = predict_all_pairs(pool40, past, selected, pairs, frozen_models)
    motion = exact_window_motion_for_all_pairs(pool40, selected, pairs)
    old_gate = ((clip(pred.L, 0, 1) <= .01)
                & (pred.dA >= 0) & (pred.dF >= 0)
                & ((clip(pred.dC, -1, 1) > 0) | (pred.dJ > 0)))
    feasible = motion.all_five_pass_relative_to_immutable_native
    ranked = lexicographic_order(pred.dC_clipped, pred.dJ,
                                 pred.dA + .5 * pred.dF,
                                 remove_slot_ascending, add_slot_ascending)
    original_action = first_or_STOP(ranked, feasible & old_gate)
    rank_only_action = first_or_STOP(ranked, feasible)

## 3. 计算与资源：先测量，不承诺几分钟

本次不用Torch、GPU、生成器前向或训练；但“冻结诊断”不等于零开销。完整动作枚举、物理quantile和weighted AP bootstrap都要计入实际ETA。

- 默认CPU线程2，按当前环境可用性确认；不调整OS/pagefile、不关闭其他用户程序、不查询旧worker。
- 单次只加载一个seed的5个S回归器；候选缓存只保留当前cohort所需窗口。特征按state流式生成，不留全2.45M×113矩阵。
- 动作物理计算以32对为上限分块；可以预计算pool40的速度/加速度/jerk范数，再按完整集合取样本求quantile；不得把p95线性相加。
- 每个state的五输出和最小可重构数据落盘；是否保存113向量按预检磁盘估算决定。若不存X，必须锁定池、past、113构造源码、selected和pair，复算X的fixture EXACT。
- 预检固定16个C_seen hash窗口（不按正负结果挑），每seed前8窗口用于吞吐；另100次bootstrap试运行，记录wall/RSS/private、峰值、磁盘与总动作量。资源按现行任务及保留进程树实测E/1.3E预算，不套旧固定6GiB或旧30min禁令。
- 估算上界含12个cohort×seed工作单元、最多6144状态、2,457,600动作、保存/独立复算、10kbootstrap。预检实际state数可给合理范围，但不能只报模型predict耗时。
- 若资源/预计成本与用户短预算偏好明显冲突，先报告瓶颈与缩减的科学影响，不启动长任务，也不擅自减少动作、种子、cohort或统计draw。当前文档没有声称任何实测ETA。

实现的stat效率建议：预先固定同分score组和track→窗口映射，bootstrap只更新track/seed权重并重算累积TP/FP，不在每个draw重新排序特征或调用模型。优化必须与小fixture直接实现一致。

## 4. 必需预检

1. **身份与污染**：FIT_train/FIT_cal recipe、sample_id、KIN行序、全部cohortID；C_same不在实际训练ID内，C_cal tracks与FIT_train不交；场景/运动组只posthoc。
2. **真实冻结模型**：15个模型完整SHA、输出名、feature count、参数；记录Python/NumPy/scikit-learn/joblib版本。加载版本不兼容或predict非有限即STOP，不偷偷重训。
3. **当前策略重放**：从原已有FIT_cal保存索引中固定hash16窗口/seed，重放原完整策略到最终状态，与原保存indices逐元素EXACT；不读GT调规则。该预检只验证冻结推理和数据连接，不证明原训练来源已追溯完毕。失败保留来源并STOP，不以另一个近似规则冒充旧S。
4. **GT隔离**：同pool/past/models下换GT或删除GT输入，state/prediction/选择必须bitwise相同；GT、group、scene、track、ID不进入特征或模型。
5. **动作集合**：S0应400对；换入k个KIN后合法动作数(20−k)^2；没有重复/越界/移除已插KIN；STOP后不再推进。
6. **标签fixtures**：同candidate联合质量；minADE与minFDE来自不同slot时不能误判覆盖；删除唯一good、删除冗余good、新增救回、中性动作、持续旧loss、从旧loss恢复分别核对。B/H/N在物理PASS内互斥且穷尽。
7. **运动fixtures**：native全0、边界1.01、windowquantile与pooledquantile不同的反例；不加epsilon使PASS；原点/.4/12-11-10时间长度一致。
8. **统计fixtures**：ties整组AP、常量q的AP等于基率、无正例NA、重复track抽样计权、不同seed同ID不当独立window、STOP风险与增量分开。
9. **续跑**：故意改一份fixture源hash/模型hash/状态片段输出hash，skip必须拒绝；合法重载预测EXACT。不伪造训练optimizer/RNG恢复，因为本阶段没有训练。

预检输出真实fixture数据、差异和失败原因，而不是只把常数写进`ARITHMETIC_AUDIT.json`。

## 6. 独立保存审核与完成定义

审核脚本不再调用学习器，使用保存模型输出/动作记录与固定原路径：

- 全量重构每state/动作的∆A/F/J/C、L、B/H/N；全量重算窗口运动门；复核原门与词典序选中动作。
- 原predict重放一致性已在预检固定fixture验证，不能把saved算术审核冒称全模型第二次推理。
- 对AP/共享draw先独立小fixture直接算法，再对保存主统计确定性重算；保留point、分母、有效draw数与NA原因。
- old/model/input/sourceSHA前后保持；每state推进链条、数量上界、文件完整性一致；所有审核结果落盘。

`Q0_COMPLETE`要求12个cohort×seed单元完成或明确规模BLOCKED、保存重算无未解释差异、无输入变动、报告所有结果。若某cohort规模不足，整个诊断可以结束并交付`COMPLETE_WITH_INSUFFICIENT_EVIDENCE`，但不得判某个科学分支通过。

Q0没有“重大突破”门。无论是否发现排序信号，都不改baseline、不记成新generator训练成功、不自动启动校准/新probe/K2。

## 7. 三轮设计反方检查（同助手，非外审）

### Checkpoint 1：问题是否被预设答案绑架？

发现：若直接做阈值校准，会把82%正例误拒偷换为“校准是根因”。已修正：全动作同时评价B/H/N、机会捕获和STOP；排序与门分别记录。剩余限制：仅测现有冻结模型，不证明全特征不可学习。

### Checkpoint 2：样本与状态选择是否夸大迁移？

发现：实际S1–S3只存在于策略愿意行动的窗口；跨cohort组成也不同。已修正：S0独立主分析、深状态条件分母、四cohort按ID/track固定选、不把组间差异直接归因为track。剩余限制：F16/KIN历史暴露与反复研究不可消除。

### Checkpoint 3：样本量和工程能否支撑结论？

发现：百万动作不等于百万独立例；zero harm bootstrap可能给虚假的零上界；文件存在不等于兼容。已修正：track权重/重抽样、最低正track数、零事件不认证安全、model/source/output SHA合同与真正saved重算。剩余限制：128窗口/cohort是短预算探索，证据不足时结束而非调样本直到显著。

交付审查结论：设计逻辑已做上述修订；**不是实际代码/数据/GPU/资源预检PASS**。最强反方意见仍是“历史与场景条件可能不足，任何校准都无法挽救不可辨识动作”，因此本次保留无辨识信号及不可判定分支，不预先保证能训练成功。
