# K0：联合可达性与策略上限（不训练）

## 1. 假设与输出

问题不是“union40里有没有更好的轨迹”，而是固定K20能否达到共同合同的W目标，以及拟用的GT-free操作空间是否允许达到它。

固定三seed，outer为主；inner、FIT_cal为完整副验证，original_CAL依数据合同单独完成或明确BLOCKED。每个seed/split都保存全部窗口，不按GT筛选困难子集后冒称总体。

本阶段仅读取冻结路径与标签，可运行有限组合搜索；不运行generator训练，不将oracle结果作为训练teacher。

## 2. K0-A：质量上界及实现自检

每窗口从40池保留argmin ADE、argmin FDE、argmin J的并集（并列取最小pool index），最多3条，再按native优先、pool index升序补足20条。

该集合必然匹配union40的minADE、minFDE、minJ及覆盖。这是简单构造事实，**不是科学成功门**。它用于检查索引、同路径定义、union上界与实际K20输出是否正确。

必须评价它的真实五运动学、全组质量与lost；不能因质量匹配union就称部署可达。若union40本身已不能达到change误差/覆盖要求，那么任何它的K20子集也不能达到该项质量要求。这是有效质量上界否定，不必花时间求解更多组合。

## 3. K0-B：联合约束的有限可行性检查

### 3.1 变量与质量约束

对每窗口i和40候选j建立二元`x_ij`，`sum_j x_ij=20`。不改变轨迹，不允许连续凸混合或复制。

预先计算A/F/J/g。coverage二元`c_i`满足：

- `c_i <= sum_j g_ij*x_ij`；
- 对每个`g_ij=1`，`c_i >= x_ij`。

原生成功的lost是`n_i*(1-c_i)`，n_i为固定native覆盖；对各组累加并按1%原生成功数限制。

为每项M∈{A,F,J}建立选中见证变量`y^M_ij`：二元、`y<=x`、`sum_j y=1`，对应误差`e^M_i=sum_j M_ij*y^M_ij`。按共同合同施加组平均误差上限。由于实际minM不高于所选见证的M，满足这些上限必然满足真实minM上限；反之若真实集合满足，取其argmin即可构造y。因此这部分对误差上限的可行性表达是等价的。

最后必须重新从所选路径求真实min值，而不是直接把未最小化的y成本写进结果。

### 3.2 均值运动学可以线性精确表达

候选轨迹固定，所以每条路径的速度/加速度/jerk标量序列均为常数。

例如组G的accel mean：

`sum_{i∈G,j} x_ij * sum_t ||a_ijt|| / (|G|*20*11)`。

jerk mean同理，分母`|G|*20*10`。用原native均值×1.01作上限，0基值不用floor。它们不等于每路径p95的平均。

### 3.3 p95采用必要/充分约束夹逼，不伪造等价

对某组、某个p95指标，所选标量数M固定（speed为`|G|*20*12`，accel为`...*11`，jerk为`...*10`）。

设`h=.95*(M-1)`，`k=floor(h)`，`γ=h-k`，原生阈值`τ=1.01*q95_native`。真实linear分位数是`(1-γ)*z_(k)+γ*z_(k+1)`，这里z使用零基排序。

每个候选预先计算`b_ij(τ)=该路径相应标量<=τ的个数`。

- **必要条件R：**`sum x*b >= k+1`。若真实p95≤τ，则下侧顺序统计量一定≤τ。
- **充分条件S：**当γ>0，要求`sum x*b >= k+2`；γ=0时要求`>=k+1`。此时上侧顺序统计量也≤τ，真实p95必通过。

将所有组/三项p95一起加入：R是实际可行域的外部松弛，S是内部充分子集。二者通常只差一个标量计数，但仍不能说相同。

由此：

1. R求得的整数解**仍须实际路径复核**；若真实门全部通过，即有效见证。
2. R未给出通过解时，允许再尝试一次S。S得到解后也必须独立复算，防止浮点容差或建模错误。
3. S不可行不证明真实问题不可行。
4. 只有R被有效证书确认不可行，或R的可验证最优上界低于目标，才可否定对应真实目标。

不通过添加评价epsilon、改变quantile方法或把p95按候选相加来“修复”求解。

### 3.4 搜索目标与预算

保留W其余约束，以最大化change好窗口数为第一目标；达到W所需整数数目且独立审核通过即可停止，不为更漂亮数值继续搜。可用原生集合及K0-A构造作warm-start参考，但不把违反约束的起点当可行解。

优先级固定：R一次→必要时S一次。每个seed/split最多这两次模型求解，不换候选池、目标、哈希、阈值、solver random seed重试。

实施时先在不按GT选取的64个FIT_train窗口上做模型构造/吞吐/内存预检，测出完整规模估计，再在**正式outer求解前**登记每job的确定节点上限、总wall安全上限及求解器配置。时间上限是停止机制，不是不可行证据。不得看outer进度后翻倍追加预算。预检不是科学结果。

后端可用已有整数优化求解器；后端不可用时明确`BLOCKED_SOLVER_BACKEND`。若确需新依赖，应使用独立环境并遵守当时权限，不修改旧环境。本文不一边要求求解器一边禁止必要依赖，也不假定SOCP能直接代替0/1选集求解。不要为准备文档安装任何依赖。

保存实例、目标上界、incumbent、gap、termination reason、容差、日志及可重检证据。普通浮点solver返回`infeasible`，但没有足够证据核验时标`NUMERIC_INFEASIBILITY_UNVERIFIED`，不能直接作“生成器必须换”的依据。

## 4. K0-C：拟部署操作空间的oracle对照

这一步区分“池足够”与“操作规则太紧”。其动作空间必须与K1完全一致：

- 从native20开始。
- 每次只移除一个仍保留的原生候选、插入一个尚未使用的KIN候选。
- 已插入KIN不再删除，已移除native不恢复；最多20步，可提前停止，最终仍为20条。
- 每次替换后，完整窗口五运动学必须literal≤原native窗口1.01；若拒绝，继续检查其他动作，不强行替换。
- 每步精确计算当前集合的∆coverage、∆minJ、∆minADE、∆minFDE以及相对native的lost；要求原生成功不丢失、∆minADE/∆minFDE均非负，且∆coverage或∆minJ至少一项正。该额外单调策略只是K1操作空间，不是项目科学门。
- 按∆coverage、∆minJ、∆minADE+.5∆minFDE依次降序，最后按removed native slot、added KIN slot升序选唯一动作。

这是**一个固定贪心策略的GT上限参照，不是所有动作序列的全局最优上限**。它的成功是此策略族中存在可达见证；失败可能是贪心顺序/单调路径/窗口门造成，不能说所有同类选择器都不可能。

完整生成后再算各组pooled运动学及W，不以窗口门替代pooled门。保存全动作轨迹、所有拒绝原因和最终indices。

## 5. K0状态与触发

每split/seed同时给出三个不同字段：`pool_joint_witness`、`policy_oracle_witness`、`relaxation_certificate_status`。不得合并成模糊PASS。

| 结果 | 下一动作 |
|---|---|
| outer三seed都有实际W见证，且固定K0-C也三seed达到W | 可进入K1；所有副split完整报告，记录池/策略的迁移限制 |
| K0-C已达到W，但优化器未决 | K0-C本身就是池的阳性见证，可进入K1；不必为了solver完结无限等待 |
| 池有W见证，但K0-C未达到 | 停在策略限制分支；不训当前K1，不说generator失败；先单独设计必要的策略改动 |
| R有可验证否定证据或union质量上界不足 | 只否定该池在该split/seed上的W目标；整理物理/质量瓶颈后建议新生成设计，不自动训练 |
| 无见证、无有效否定证据、预算到期 | `UNKNOWN_WITHIN_BUDGET`；结束本次搜索，不选取有利子集、不增加轮次 |
| 来源/身份/数值审计失败 | BLOCKED并保留全部证据 |

副split若出现未决/不可达，不能说泛化已解决。K1即使获准作为机制试验继续，也不得绕开最终副split安全与误差报告，更不能据outer单独升级baseline。
