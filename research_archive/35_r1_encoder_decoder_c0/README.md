# Research 1: 编码端 C1/C2 与解码端级联+覆盖序判别（C0 筛选，仅 ETH/UCY）

本目录归档了研究一（纯轨迹、固定 20 候选推理预算）在锁定 `B0`（`F16 + H3`，`token_dim=96`）上的两套端到端独立/联合实验，范围严格限定于 **ETH/UCY `C0`（不运行 SDD）**。两个实验均于 Kaggle `Tesla T4 × 2` 离线运行完成，共评估 **45 组**（编码端 21 组 + 解码/联合端 24 组，均使用种子 `42–44`、`64` 轮训练、最终 EMA 权重，配对采样顺序与初始化）。

- **关系令牌效应（`E0 vs E1`）**：恢复关系令牌带来统计显著的 `minFDE` 改善 **`+1.28%`**（95% CI `[+0.10%, +2.42%]`，3/3 seed 全正，LORO `7/7`，`without_zara02 = +1.64%`），但低于预设 `>=1.5%` 门限（`G1 = false`）。`E2` 未击败双臂，因此 **`G3_keep_temporal_cross = true`** 保留时间交叉注意力。

- **指标倒挂对照（`E5 / E6`）**：扩展支撑集或换为距离近邻使 `minFDE`（`-0.72% / -1.13%`）与 `Top1_FDE`（`-1.57% / -1.75%`）均退步，但 `J_cov` 在 3/3 seed 上一致上升（`+0.46 / +0.76 pp`）。
- **`V2` 稀疏算子扩展性（Kaggle Tesla T4, `B=64`）**：`N=128` 时 `masked_dense_E0` 耗时 `390.45 ms`（`7295 MB`），而 `fixed_k_sparse` 仅 `56.33 ms`（`1015 MB`，提速 **6.93×**）、`edge_list_sparse` 仅 `56.92 ms`（`700.3 MB`，显存降至 **1/10.4**）；`N=256` 时稠密实现均触发 `OOM`，两种稀疏实现均正常 `OK`（`113.17 ms` / `115.69 ms`）。

- **相对 `M0 (B0)` 总表现与代价**：全部多层臂大幅超越基线，`M4` 使 `J_cov` 提升 **`+5.37 pp`**（3/3 seed 全正）、`minFDE@20` 降 **`5.51%`**（CI `[+3.30%, +7.64%]`）、`cov_sel@3` 降 **`5.96%`**、`cov_sel@5` 降 **`5.09%`**、`fast (v>1.3 m/s)` 子群 `J_cov` 提升 **`+12.18 pp`**（`JM4` 达 **`+14.29 pp`**），且 `jerk_mean` 下降约 `7–9%`；**明确代价**是 **`Top1_FDE` 退化 `-4.66%`** 与 **`brier` 退化 `-2.17%`**。
- **内部消融门控（`DECODER_STAGE1_PASS = false`，暂未进入五折）**：
  - **`G4 = true`（冗余特征因果有效）**：`M4` 较屏蔽冗余特征的 `M5` 使 `cov_sel@3` 改善 **`+1.28%`**（CI `[+0.09%, +2.51%]`）、`cov_sel@5` 改善 **`+1.85%`**（CI `[+0.61%, +3.02%]`, 3/3 seed 全正）。
  - **`G6 = true`**（`M4 380,944`、`JM4 381,024 <= 400k`），`MC-b/c/d` 全通过，`MC-a` 中正样本均数增至 `2.375` 但 `C0_dev` 匹配率 `0.877 < 0.90`、`eth_fast` `0.080 < 0.20`。
  - **`G1 / G2 / G3 / G5 = false`**：`M2` 虽将 `Top1_FDE` 拉回 **`+2.96%`**（CI `[+1.83%, +4.11%]`）但 `@20` 未优于 `M1`（`-0.78%`）；`M3` 未提 `Top1`（`-2.24%`）；`M4 vs M3` 虽改善 `cov_sel@5` **`+1.29%`**（CI `[+0.15%, +2.41%]`）与 `@20 +0.73%`，但距 `1.5%` 门差 `0.21 pp` 且 `Top1_FDE` 降 `-1.58%` 越过护栏；`M4 vs M6` `cov_sel@5 +1.98%`（CI `[+0.69%, +3.26%]`）而 `@20 +0.83%` 未达 `1.0%` 门。`JM4 vs M4` 全量持平（`-0.23%`），仅 `fast` 略高。
- **V0 预演反例记录**：[v0/V0_REPORT.json](v0/V0_REPORT.json) 记录了解码端零训练预演：`cov_arg` 在全部 11 项中与 `riskp` 偏差均在 `[-0.52%, +0.41%]`，`@3` 全优 `conf`，但在 `hotel @5`（`tau=1.0`）上 `riskp` 与 `cov_arg` 均略逊于 `conf`，已如实标记 `strict_design_6_2_all_folds_k3_k5_pass = false`。
