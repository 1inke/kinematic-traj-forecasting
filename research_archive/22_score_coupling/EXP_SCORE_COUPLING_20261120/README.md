# 打分头对候选轨迹的作用

两阶段均已完成。阶段一的五个 B0 seed 均通过 K1。阶段二完成三个训练臂、各三个 seed、每组 64 轮，只有 S0 达标。

**切断打分头几何输入的梯度后，转向难组的 J 覆盖率下降。** 三个配对 seed 分别下降 1.13、3.00、0.38 个百分点，平均从 24.14% 降到 22.64%，降幅超过 0.50 个百分点的预设门槛。J 覆盖要求同一条候选同时满足 ADE ≤ 0.2 m 和 FDE ≤ 0.4 m。阶段二的结果适用于本次冻结编码器、无数据增强的 C0 设置。

## 阶段一的梯度和漏覆盖位置

在转向及转向且变速窗口中，排名第 2–6 的候选所受分类梯度范数之和，是五个非分类项的梯度向量和范数之和的 1.74–2.05 倍。五个 seed 的分类梯度下降方向对真值的平均投影均为正，轨迹重抽样区间均在零以上。K2 的“平均推离真值”门槛未达到。

dev 难组每个 seed 共漏覆盖 407–425 个窗口。范围错占 32.6%–38.0%，形状错占 19.0%–22.5%，纯方向错占 6.8%–8.6%。原分类表还有一批未能归入四类的窗口。它们在方向扇区内已有径向距离相近的候选，占 23.2%–27.4%，在结果中单列。

## 阶段二的配对比较

| 判定 | 结果 |
| --- | --- |
| S0 | R-couple 的总体 minFDE 比历史 B0 seed42 高 0.91%–2.31%，三个 seed 都在 ±5% 门槛内。 |
| S1 | R-detach 的难组 J 覆盖率下降 1.50 个百分点，难组 minFDE 平均升 0.0042 m。总体 minFDE 基本持平。 |
| S2 | 切断直接梯度后，总体 Top1 FDE 平均升 0.0022 m，训练赢家负对数概率平均升 0.0127。两项均未达到预设信号。 |
| S3 | 在 R-detach 的基础上把打分头的几何输入置零，Top1 FDE 平均升 0.0068 m，赢家负对数概率平均降 0.0087。两项均未达到预设信号。 |
| S4 | R-detach 的近静止组散布中位数平均减少 0.092 m，第三个 seed 增加 0.040 m。三个 seed 的近静止组都小于同模型稳定移动组，配对变化未达到信号门槛。 |

R-detach 三个最终模型的分类项对锚点的直接梯度均为零。分类仍可经共享的 mode 表征影响几何。难组 HPD90 的变化平均为 −0.44 个百分点，三个 seed 方向混合。覆盖率下降的结果对应 J 判据。补充的配对轨迹重抽样对同一组 88 条难组轨迹计算三个配对 seed 的平均差，95% 区间为 −3.23 至 +0.24 个百分点。该区间包含零。原有打分头保留为比较基准，范围与形状仍是漏覆盖的主要待核对因素。
