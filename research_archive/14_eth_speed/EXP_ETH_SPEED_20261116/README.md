## 两种复核范围

发布前在本机核验456项旧源、99项输入合同引用、40项诊断输出、73项增强输出和71项原 B0 完成输出；13组保存预测对真实目标重算逐窗/分层指标，另核对原 B0 验证集；全部64轮批次顺序散列与原 B0 一致。`LOCAL_RECOMPUTE_RECEIPT.json` 保存本机重算范围。

公开 CPU 工具可从所含误差和派生标签重建所有汇总、速度阈值/缩放比例、机动与交叉组、覆盖交换、尾部分位数、派生过冲均值、原诊断/增强判定和逐轮顺序证据。**缺少原始目标与预测坐标时，它不能重新计算坐标误差、重新生成机动标签或重建终点几何**，不把已有误差的复算冒称原坐标重算。

```bash
python -m pip install -r requirements-analysis.txt
python -B tools/reanalyze.py
```

仅需 Python 3.10+ 和 NumPy，无需 GPU、PyTorch、原数据或网络。复核不会启动训练，也不会修改原阈值或升级 baseline。
