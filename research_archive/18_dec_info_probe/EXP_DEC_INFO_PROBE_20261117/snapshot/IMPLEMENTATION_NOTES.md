# EXP-DEC-INFO-PROBE：运行前固定的实现

原设计保留在 design_original。本轮只运行冻结缓存探索，进入端到端验证需要另立实验；不自动加跑、选新 baseline 或同步外部仓库。

- 只使用原 C0 fit 21,719 / dev 4,753 与原 B0@64 seed42 最终 EMA，不加载测试集。沿用上一轮缓存的 FP32 mode/锚点/尺度/logit/评价目标，并以同一底座重新前向核验这四个预测字段和世界坐标预测。新缓存额外保存 h3 实际接收的 [9,8,96] 编码器 token 中的目标全部8步、邻居最后1步（均 FP16 存储，FP32 投影），以及有效遮罩、目标坐标系邻居位置/速度和目标末步速度；不修改上一轮缓存。
- 原点为目标最后观测点；朝向用末3步位移，范数≤0.03 m 时 B0 按世界 +x 处理，不把静止窗口的实际运动说成 +x。邻居速度用末步位移×2.5；C2/C4 的相对速度是邻居减目标。只用观测构建特征，不把未来传入编码器或修正模块。D0 的社交标签和选邻只用预测及观测；stable/transition/change/decel_stop 标签仅用于分组评价。
- C3 用修正前路径 t=1…12（0.4–4.8 s）与邻居匀速外推，最短距离并列取最早步，关系为 DCA、TTC/4.8、d0、最短距离时邻居相对候选的 x/y。沿用本地 `ttc_dca_graph` 风险公式系数及 DCA<3.0 m，但不复制该编码器变体中连续直线求 TTC、保护近期邻居的规则。本次 B0 用的是 F16；该风险公式取自同系列另一变体。风险/距离并列按邻居槽位顺序。
- 用户已确认 C4 按当前距离取最多3个，窗口内各候选共用。C3 按 DCA 过滤后最多3个，所以两臂**上限相同而实际数可不同**。D0 另报实际计数、数量相等比例与选中集合相等比例。C3/C4 比较包括筛选、有效数量和关系特征差异，不能单独归因于排序。
- A1 逐候选块原样复用（包括未启用的参数）；A1L 只将其 FFN 中间宽度48改为220，保留原48单元和公共层的初始化。C1–C4 先用同一个逐候选块，再用24宽、4头交叉注意力和48宽FFN；时间步学习偏置 [8,4]，关系 MLP 5→16→4，未使用参数也注册并另报实际获得非零梯度的参数（各轮末批观测并集）。C1只看目标 token；C2看全部有效邻居；C3和C4只读各自选中的有效邻居。C1的目标 token 已经过编码器社交混合，不能把增益专门归为无社交的自身历史。新增关系偏置和输出头零初始化；轨迹初值须逐位一致，因分数头按新批量布局复算允许1e-4浮点误差，不声称 logits 逐位相同。
- 三个模块seed 0/1/2，A1、A1L、C1、C2、C3、C4 依次各3次，20轮×85更新=1700更新/次。只用原 B0 损失；训练参数与上一轮 A1 相同，不加增强、EMA、早停或损失。FP32 确定性训练，一路 GPU。CPU 耗时单线程、batch=1、固定各邻居数量首个 dev 窗循环，预热50次计时200次，同 seed 中位数差取平均做 C3 成本门，含 C3 近距扫描和选邻，不含编码器；另报带冻结 score_head 与插值的时间。
- P0 先跑 A1 三个 seed，minFDE 改善≥0.8%，与文档1.29%相差≤0.3个百分点，minADE满足统一下限；否则停止其余15次。σ为三 seed 相对 minFDE 改善的样本SD。R 先按平均 dev minFDE 选 A1/A1L，完全相同选 A1；后续按 seed 配对，minADE 限制为改善≥−0.2%。Q5及分组只按既定口径报告。
- 邻居置乱为固定 seed=20261117 的一次同邻居计数分桶无自配的置换，整体替换邻居 token/位置/速度/遮罩，保留目标输入、目标真值和原社交分组。零邻居无需置乱；若正计数单例无法置换则标记，并不认定机制通过。机制里用 C1 作参照，以隔离额外的邻居输入：社交窗改善的绝对 minFDE 总量须为正并大于非社交窗总量（两组各≥20窗）；社交组 C3 对 C1 的相对 minFDE 改善在置乱后须回落至少 thr 且至少原改善的一半。这是对“主要”和“明显回落”的运行前操作定义，不作检验的置信度声明。
- 先按数值与机制条件判档，再单列保护失败，遵守原设计最后的报告约定。DESIGN_PROMISING 检查 C3；INFO_YES_DESIGN_NO 检查达到1.5%和ADE下限的C1/C2/C3；INFO_SMALL 检查满足小收益档的C臂。若五档规则没有覆盖组合（例如各设计对照与机制通过却没到全局3%，或 FDE 达标但 ADE 不合格而无其他适用档），标记 `UNCLASSIFIED_RULE_GAP`，报告逐门结果及不推进，不增设一档实质结论。无论结果都不自动推进。
- 每轮保存模型/优化器/调度器/RNG/训练顺序与散列；中断从最近完整轮次继续。真实缓存预检须核对原 A1 有限更新逐位一致、C3 跨轮恢复逐位一致，以及预测、分数和选邻对未来置乱不变。研究输出均在本机。

## 与已有方法的区别

代码实现前查阅了两篇原文：[NaviAIS / NaviLane](https://arxiv.org/html/2607.18887v1) 第 III-B/C 节把候选与邻居预测的风险用于修正后的排序；[LGCMT](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0347049) 式 (14) 已用候选模式作为查询读邻居，说明“候选条件化”本身不是新点。这里测试的是用未修正候选与匀速邻居算离散最近接近风险，筛掉低风险邻居后再修正。两篇对照用于厘清实验问题，不构成系统检索或首创声明。
