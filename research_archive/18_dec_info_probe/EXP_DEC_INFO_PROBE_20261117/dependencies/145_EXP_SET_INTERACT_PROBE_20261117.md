## 1. 为什么这样设计：先看已有的证据

候选间交互在仓库里已经用不同方式试过四次：

| 已做实验 | 交互发生在哪里 | 结果 |
|---|---|---|
| D-Gate / D-DiffGate | 生成几何之前，在 mode embedding 上 | 与 B0 相差 ±0.5%，没有信号 |
| DGeo | 带几何特征的 mode 协调器，仍在锚点生成之前 | 整体 +2pp，主要来自 stable 组，change 组下降 |
| 【已完成】E3（11-14） | 生成之后，在候选几何上，用一层小注意力 | **只看自己的 self 臂（对角 mask）提升最多**：minADE −2.3%，minFDE −2.2%；全连接的 set 臂相对 self 没有稳定增益；几何偏置相对无偏置为 −0.45pp |
| 【已完成】Group Query 训练分组（11-02） | 训练期多组 Query | 有一致方向的点估计收益，但未过预设门槛，按规则停止 |

结论：**到目前为止，"让候选彼此看见"从没有带来超过"每条候选各自修正"的增益。** 把编码器的 RBF 关系偏置搬到候选上（E3_set 的几何偏置）也没有效果。

所以本实验先不比"哪种注意力更精巧"，而是先问一个更前面的问题：**为什么交互没用？**

## 2. 核心假设：交互没用，是因为训练信号不要求它有用

B0 的损失以 WTA 为核心：每个窗口只有离真值最近的那条候选得到主要的梯度。

候选间交互真正能带来的价值，是让一条"多余"的候选（和另一条更好的候选几乎重合）知道自己多余，然后挪去覆盖还没被覆盖的地方。

但在 WTA 下：
- 多余的候选永远不是赢家，几乎拿不到梯度；
- B0 损失里的软覆盖项（权重 0.2，τ = 0.1）只给非赢家很弱的信号；
- 于是交互模块即使"看见了"重合，也没有动力去学"挪开"。E3 恰好只用了 B0 原损失。

**假设 H：只有当训练目标给"多余候选"一个集合层面的学习信号时，候选间交互才会产生超过自我修正的增益。**

如果 H 成立，创新点就不是"用注意力做候选交互"，而是**一个交互结构和一个训练分配规则配套的机制**：
1. 交互结构：每条候选只看和它最重合的几个邻居，并且知道谁比自己得分高。这样它能判断"多余的是不是我"。
2. 训练分配规则：在没被覆盖的窗口里，把最多余的那条候选分配去覆盖真值。

两者缺一不可，所以要用 2×2 设计来检验。这正好回应"创新应体现在具体机制设计上"：要证明的是**这个配套设计比通用注意力有效**，而不是"交互本身有效"。

## 3. 设置

### 3.1 底座和数据

- 底座：NEXT_PHASE 的 B0@64、seed 42，C0 协议下的检查点。**全部冻结。**
- 训练：C0 fit，21,719 个窗口；评价：C0 dev，4,753 个窗口。与 E3 相同，可以直接对照 E3 端到端的结果。
- 不碰 ETH 测试集，也不看任何测试集。dev 已经被反复用过，所以这是探索性实验。
- **缓存**：对 fit 和 dev 各做一次 B0 前向，保存每个窗口的：
  - mode 特征 [20, 64]；
  - 第一遍锚点 relative [20, 3, 2]；
  - 尺度 scale [2]；
  - 基础 logits [20]；
  - 真值和分组标签。
- 之后所有训练只在缓存上进行，不再跑编码器。
- 缓存上不做数据增强，这和 B0 的训练配方不同，是已知的偏差，见第 8 节。

### 3.2 修正模块（所有臂结构相同，只有 mask、关系特征、损失不同）

- 沿用 E3 的 GeoSetRefiner：输入 token 由 mode 特征和归一化几何构成，宽度 24，4 个头，一层注意力加 FFN。
- 输出：有界的锚点修正（MAX_SHIFT = 0.30 × 尺度）和得分修正，全部零初始化，所以初始时与 B0 完全一致。
- 修正后的锚点用 B0 的线性插值还原为轨迹，得分用冻结的 B0 score_head 在新几何上重新计算，再加上得分修正。
- 各臂参数量相差不超过 ±10%。

### 3.3 六个训练臂和一个基准

| 臂 | 注意力 | 损失 | 回答什么 |
|---|---|---|---|
| A0 | 无（冻结 B0） | — | 基准 |
| A1 | 只看自己（对角） | B0 原损失 | 在冻结底座上复现 E3_self：第二遍修正本身值多少 |
| A2 | 全连接，无偏置（通用注意力） | B0 原损失 | 通用交互，对应 E3_set_nobias |
| A3 | **冗余稀疏图 + 关系偏置**（本实验的设计） | B0 原损失 | 具体设计在原损失下有没有用 |
| A4 | 只看自己（对角） | B0 + 再分配 | 只改损失、不交互，有没有用 |
| A5 | **冗余稀疏图 + 关系偏置** | B0 + 再分配 | 完整设计 |
| A6 | 全连接，无偏置 | B0 + 再分配 | 新损失下，通用注意力 vs 具体设计 |

**A3 / A5 的冗余稀疏图**
- 每条候选 i 只关注终点距离最近的 k = 4 条候选，再加上它自己，其余位置被 mask 掉。
- 每对 (i, j) 的关系特征：
  - 沿朝向的终点差 Δs，有符号，单位米；
  - 横向终点差 Δl；
  - 终点距离；
  - 得分差（j 的基础 logit 减 i 的基础 logit）。
- 关系特征经一个小 MLP 变成每个头的注意力偏置，最后一层零初始化。
- 设计意图：Δs 对应主要误差"走多远"；得分差让候选知道"重合的那条是不是比我好"，即"多余的是不是我"。

**再分配损失（只在训练期，推理零成本）**
1. 用 B0 规则选出赢家 w：ADE + 0.25 × FDE 最小的那条。
2. 只在"未覆盖"的窗口生效，即赢家 FDE > 0.4 m（与覆盖率的 FDE 门槛一致）。
3. 在除赢家外的候选里，挑"最多余"的那条 r：终点离某条得分更高的候选最近。只用候选和得分来挑，不看真值。
4. 加一项 λ × SmoothL1(候选 r 的轨迹, 真值)，λ = 0.5，只对 r 回传梯度。
5. 所有常数运行前固定，不调。

### 3.4 训练

- 每臂 3 个修正模块 seed（0、1、2），每次 20 轮。
- AdamW 学习率 1e-3，wd 1e-4，batch 256，cosine 衰减，不早停，取最后一轮。
- 一共 6 臂 × 3 seed = 18 次。

## 4. 零训练前置诊断 D0（描述用，不设门槛）

在 A0 的 dev 预测上先算出下面几项，用来理解"集合层面还有多少可修的空间"：

- **冗余度**：每个窗口终点距离 < 0.2 m 的候选对数量；按 0.2 m 合并后的有效候选数。
- **纵向缺口**：
  - 真值终点的沿朝向距离 s_gt 落在 20 条候选 s 值范围之外的比例（太短或太长）；
  - 范围之内、但离最近一条候选在 s 上的距离超过 0.4 m 的比例。
- **未覆盖率**：minFDE > 0.4 m 的窗口比例，也就是再分配损失会生效的窗口有多少。
- **槽位使用**：每个槽位当赢家的频率，看有多少条候选几乎从来不赢。

D0 按 stable / transition / change 和 decel_stop 分组报告。如果冗余候选很少、未覆盖率也很低，说明集合层面能修的空间本来就小，结论要相应弱化。

## 5. 指标

- **主指标**：dev minADE20、minFDE20，3 个 seed 平均，各臂与 A0 按 seed 配对比较。
- 集合指标：冗余度、有效候选数、纵向缺口率、未覆盖率。用来看机制是否真的按设想工作：A5 应该降低冗余和缺口，而不只是整体平移。
- 保护指标：Top1 FDE；stable、change、decel_stop 三组的 minFDE；平均修正幅度。
- 成本：修正模块参数量；CPU batch-1 下修正模块的耗时。

## 6. 预注册判定（运行前固定）

噪声标尺 σ：A1 三个 seed 与 A0 配对差值的标准差。"有效"门槛 thr = max(0.5%, 2σ)，按 minFDE 计算，同时要求 minADE 不变差（≥ −0.2%）。

| 问题 | 比较 | 解读 |
|---|---|---|
| Q1 代理有效性 | A1 − A0 | 应该为正，复现 E3_self。若 ≤ 0，说明冻结底座这种代理不适合本问题，**停止并报告**，不解读其他臂 |
| Q2 原损失下的交互 | A3 − A1，A2 − A1 | 假设 H 预测两者都接近 0，复现 E3 |
| Q3 新损失下的交互 | A5 − A4 | 假设 H 的核心：应 ≥ thr |
| Q4 具体设计 vs 通用 | A5 − A6 | 应 ≥ thr，才能说"创新在机制设计" |
| Q5 损失单独的作用 | A4 − A1 | 用来区分"收益来自损失"还是"来自交互" |

**结论分四档：**
- **H_SUPPORTED**：Q3 和 Q4 都通过，且保护指标没有变差。说明交互加再分配的配套设计有依据，进入 B 阶段。
- **GENERIC_ONLY**：Q3 通过，Q4 不通过。交互加新损失有用，但具体结构没有优势。创新点要放在训练分配规则上，而不是注意力设计。
- **LOSS_ONLY**：Q5 通过，Q3 不通过。收益来自损失，交互没有必要。候选间交互这条线到此为止，可以考虑转成训练目标方面的创新。
- **NO_SET_GAIN**：以上都不成立。方向 B 的"集合修正"形式不成立，回到讨论。

**保护门**：任何被判为"有效"的臂，Top1 FDE 变差不能超过 2%；stable 组和 decel_stop 组的 minFDE 变差不能超过 1%。否则降一档。

## 8. 局限

1. **冻结底座是代理。** 端到端训练时，底座会和修正模块一起变化，效果可能不同。Q1 和 E3 端到端的结果可以帮助判断代理是否可信：E3_self 端到端是 −2.2% minFDE。
2. 缓存上没有数据增强，修正模块看到的分布比 B0 训练时更窄。
3. 修正幅度有界（0.30 × 尺度），所以"挪开"只能在局部进行，补不了离得很远的缺口。纵向缺口里"超出范围"的部分可能修不了，D0 会告诉我们这部分有多大。
4. dev 已被反复使用，结论只用于方向选择，不能写进论文实验章节。
5. 只用了一个底座 seed（42），底座之间的差异没有覆盖到。如果结论是 H_SUPPORTED，B 阶段必须用多个 seed。
6. 再分配损失和已有的退火软 WTA（T1，已失败）、aWTA 等"给非赢家信号"的方法相关。区别在于：这里只给"最多余"的那一条，并且只在未覆盖窗口生效。是否真有区别，要看 A4 和 T1 的表现，也需要文献核查。
