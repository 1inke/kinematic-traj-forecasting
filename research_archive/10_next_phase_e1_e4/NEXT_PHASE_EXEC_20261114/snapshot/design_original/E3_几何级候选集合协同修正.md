# E3：几何级候选集合协同修正

## 问题与定位

h3 的 20 条候选彼此独立生成，打分头也只看自身的 mode 特征和锚点。此前的候选交互实验都没有在“已生成的几何”上做交互：

| 已有尝试 | 交互发生在哪里 | 结果 |
|---|---|---|
| D-Gate / D-DiffGate | 几何生成**之前**的 mode embedding 上 | 与 B0 差距在 ±0.5%，单 seed 无信号 |
| DGeo | 带几何特征的 mode 坐标器，仍在锚点生成之前 | 总体 +2pp，主要来自 stable，change 下降 |
| 10-27 协同细化 B1/B2 | 冻结 native 缓存上的后处理，另设 keep/set 损失 | B1 训练进程崩溃，**没有任何结果** |

E3 做的是：先用原 h3 生成 K20（第一遍），再让 20 条候选**基于各自的几何**在一层小注意力里互相看一次，输出一个有界的锚点修正和一个打分修正（第二遍）。端到端训练，只用 B0 原损失作用于最终输出，不加任何新损失项。所以 E3 的单一因素是“结构”。

## 结构（`code/set_refine_decoder.py`）

每条候选 k 的 token（输入 77 维 → 宽度 24）：
- mode 特征 m_k（64 维）；
- 按样本尺度归一化的锚点（6 维）；
- 相对集合均值的归一化锚点（6 维）；
- 终点到集合中心的距离（1 维）。

注意力：4 头、每头 6 维。注意力 logit 加一个两两几何偏置 b_kl = MLP([|Δa4|, |Δa8|, |Δa12|])（米制），最后一层零初始化。这与编码器中“RBF 运动学边偏置”的思路一致，只是作用对象从“行人之间”换成“候选之间”，论文叙述上可以前后呼应。之后接 LayerNorm、FFN（24→48→24）和 LayerNorm。

输出：
- 锚点修正 Δa_k = 0.30·scale·tanh(W_a·h_k)，W_a 零初始化，修正量以该行人的 proposal 尺度为单位、按轴有界；
- 打分修正 Δs_k = W_s·h_k，零初始化。

最终锚点为 a_k + Δa_k，插值方式默认是 linear；组合阶段可换成 E2 胜出的方式。打分头读取最终几何，再加上 Δs_k。初始化时整个模块输出为零，模型与 B0 逐位相同。

**参数**：+7,003，整模约 302.5k，在 305k 目标之内。计算量：每个行人 20×20 注意力和 400 次两两距离，相对编码器可忽略；仍需实测。

## 三臂（参数张量完全相同，只有开关不同）

| 臂 | 注意力 | 几何偏置 | 用途 |
|---|---|---|---|
| self | 只允许对角（每条候选只看自己） | 不用 | 控制“第二遍 + 额外容量”的作用 |
| set | 20×20 全连接 | 用 | **主方法** |
| set_nobias | 20×20 全连接 | 模块保留但不用 | 隔离几何偏置的作用 |

self 臂中 q/k 和偏置模块的梯度恒为零，这是结构使然，不是故障。

**对比**：
- **set − self：集合交互的作用（主对比）。** 两者容量完全相同。
- self − B0：第二遍修正本身的作用。
- set − set_nobias：几何偏置的作用。

新训练 9 次（三臂 × seed 42/43/44），B0 复用 E1。

## 预检
1. 同一 seed 下，三臂初始化时的输出与 B0 逐位相同（refiner 在 fork 的 RNG 内用固定种子构造，不扰动全局 RNG）。
2. self 臂对候选的任意置换等变；set 臂在 mode embedding 随之置换时等变（mode embedding 让槽位可区分，所以不是纯集合函数，这一点明确写出）。
3. 第 2 步之后，`anchor_out`、`score_out` 及前层梯度非零；set 臂的 q/k/bias 梯度非零；self 臂的 q/k/bias 梯度为零。
4. 实测 refiner 参数量和整模参数量，与 7,003 / 302,477 核对。

## 假设与指标

| 编号 | 假设 | 主/次 | 指标 |
|---|---|---|---|
| H3a | 集合交互改善机动样本的覆盖 | **主** | set − self 的 change 组覆盖率 |
| H3b | 集合交互减少冗余候选、增加有效好簇 | 次 | effective-good；候选最近邻距离分布；同簇候选对比例 |
| H3c | 集合感知的打分修正提高 Top1 | 次 | 共同覆盖窗上的 top1 条件召回（固定共同分母） |
| H3d | 几何偏置有用 | 次 | set − set_nobias（H3a 指标） |

## 同模型内的第一遍→第二遍交换（E3 特有，不受训练噪声影响）

导出时同时保存第一遍路径（`last_pass1_relative` 经同一插值矩阵得到）。同一个模型内，比较第一遍和最终输出：
- 第二遍把多少窗从“无好候选”变成“有”（内部救回），又把多少窗从“有”变成“无”（内部丢失）；
- 修正量 |Δa| 的分布：按组、按候选是否为 J-winner；
- 修正前后，候选最近邻距离的变化（是在拉开，还是在聚拢）。

这种交换来自同一个模型，没有跨 seed 噪声，最直接地回答“协同修正到底在做什么”，也是论文里讨论“保留旧成功”更干净的口径。

## 注意力机制检查（只作描述，不当作语义）
- 非对角注意力质量（set 臂）；注意力权重与两两终点距离的相关性。
- 几何偏置学到的形状：把 b_kl 按 |Δa12| 分箱画出，检查是“排斥近邻”还是“聚合近邻”。

## E3 的成功定义（预先固定）
set 臂若在 H3a 上相对 self 有信号，且没有任何 E2E_V2 伤害，即成为 E3 胜出者。若 set 与 self 均优于 B0、但两者之间无差别，结论写成“第二遍修正有效，集合交互未证实”，并且之后只把 self 带入组合阶段。

## 以后视情况再做（本轮不做）
两次迭代共享权重的细化；对第一遍几何做 stop-gradient；对第一遍输出加辅助损失；更大宽度。只有 E3 主对比出现信号后才考虑，每次只改一个因素。
