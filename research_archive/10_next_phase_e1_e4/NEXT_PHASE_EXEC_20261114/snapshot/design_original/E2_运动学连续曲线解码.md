# E2：运动学连续的曲线解码

## 问题

h3 在第 4/8/12 步放三个学习锚点，相邻锚点之间用直线连接。由此带来两个结构性后果：

1. **接续不连续**：第一段速度等于 a4/4，与观测末速度无关。dev 全 K20 的接续加速度均值为 0.68 m/s²，GT 为 0.15–0.17。
2. **内部过度平滑**：每段内速度恒定，速度变化全部集中在 4→5、8→9 两个折点。内部加速度均值 0.071，fit-GT 为 0.170。

模型输出的运动“像”分段匀速，而不是像行人。这也会影响论文中“理解行人运动”的叙述。

## 设计原则：只换连接方式，不碰锚点

DGeo-V2 的 KinTaylor 把锚点残差压缩到很小的米制界内，而且仍是分段线性，结果 change 组明显变差。说明缩小可达集代价很大。E2 保留**完全相同的锚点生成**（context、mode embedding、模板、proposal_scale、0.75·tanh delta、score head、loss 全部不变），锚点的可达集合也不变，只改变三点之间如何连成 12 步路径。

三种连接方式都对锚点（以及观测速度）是线性的，所以各自是一个固定矩阵（`code/spline_basis.py`）：

```
rel[t] = Σ_j W[t,j]·a_j + w_v[t]·v0,   t = 1..12
```

| 臂 | 连接方式 | 新增参数 |
|---|---|---:|
| linear（=B0） | 原分段线性 | 0 |
| natural | 过 (0, a4, a8, a12) 的三次样条，S''(0)=S''(12)=0，不读速度 | 0 |
| clamped | 同一样条，起点切线 S'(0)=v_obs（末步观测位移，m/step），S''(12)=0 | 0 |
| clamped_launch | clamped，且每条候选可学一个有界起步偏移：S'(0)=v_obs+dv_k，dv_k=0.20·tanh(W·m_k)，W 零初始化 | 130 |

- 0.20 m/step 来自 C0 封存的 fit-GT 接续加速度 p99（1.25 m/s² × 0.4 s ≈ 0.5 m/s ≈ 0.20 m/step），不在 dev 上调。
- 三次样条必然经过锚点，所以锚点的语义和 4/8/12 步的位置误差构成不变。
- 已验证的性质（`test_numpy_parts.py`）：样条与 SciPy `CubicSpline` 一致到 1e-12；clamped 的起点导数恰为 v0；锚点落在匀速线上时，clamped 精确复现匀速路径；linear 矩阵与 h3 的 `interpolation_weights` 相同。

**三组对比**：
- natural − linear：平滑连接本身的效果。
- clamped − natural：观测速度连续性的效果。
- clamped_launch − clamped：硬连续与软连续的区别（例如急停、转向起始）。

## E2-0 零训练诊断（先做，几分钟）

h3 路径经过锚点，所以可以从已保存的 B0 路径中读回锚点（第 4/8/12 步），换成样条连接，logits 保持不变：
```
python -I code/respline_saved.py --data C0/dev.npz --pred B0_s42_dev.npz --outdir E2_0/
python -I code/exchange_null.py --data C0/dev.npz --ref B0_s42_dev.npz \
   --method natural E2_0/respline_natural.npz --method clamped E2_0/respline_clamped.npz \
   --motion-ref C0/MOTION_REFERENCE.json --out E2_0/E2_0_RESULT.json
```
脚本会先检查保存的路径确实能由线性基逐点复原（误差 > 1e-4 即拒绝）。

这里得到的是“锚点不动、只换连接”的效果，丢失全部来自表示变化，同模型内对比没有训练噪声。锚点原本是为直线连接训练的，所以这是训练后效果的**下界**。E2-0 只作诊断，不作 E2-1 是否开展的门。

## E2-1 训练（E\* 预算，seed 42/43/44）

新训练 9 次：natural、clamped、clamped_launch 各 3 seed。linear 复用 E1 的 B0。

接入方式：`model, cfg = make_model(device, seed); attach_curve_decoder(model, arm)`。

### 预检（训练前必须通过）
1. 同一权重下，`linear` 包装器与原 h3 的输出逐位相同。
2. 各臂的路径在第 4/8/12 步与锚点一致（float32 容差 1e-5）。
3. 初始化时 clamped_launch 的输出与 clamped 逐位相同；`launch` 参数在第 2 步后梯度非零（零初始化下第 1 步为零属预期）。
4. 同 seed 各臂共享参数的初值逐张量相同；batch 顺序 ID 相同。
5. 真实 GPU 两个小 batch 的前向/反向有限；断点恢复沿用现有检查。

### 假设与指标

| 编号 | 假设 | 主/次 | 指标 |
|---|---|---|---|
| H2a | clamped / clamped_launch 显著降低接续加速度，使其接近 GT | **主（运动）** | 全 K20 接续加速度均值的 \|log(模型/fit-GT)\| |
| H2b | 样条臂的内部加速度、jerk 更接近 GT | 次 | J-oracle 候选对自身 GT 的 \|log 比值\|；全 K20 对 fit-GT |
| H2c | clamped 改善前段误差 | 次 | J-oracle 第 1–4 步误差；Q-winner 分段误差 |
| H2d | change 覆盖率：不预设方向（双侧） | **主（精度）** | change 组同槽覆盖率 |
| — | 其余 | 报告 | 各组覆盖率、minADE、minFDE、top1 条件召回、effective-good、超额丢失、尾部超阈率、旧门 |

### E2 的成功定义（预先固定）
某一样条臂若同时满足以下三条，则成为 E2 胜出者，进入 E3/E4 之后的组合阶段：
- H2a 有信号（3 seed 同向，且超过 2×跨 seed 标准差）；
- 无任何 E2E_V2 伤害；
- 任一组覆盖率均无负向信号，且 overall minADE 不劣于 B0 超过 1%。

**也就是说，精度持平而运动更像行人，就算成功。** 这在论文中可以直接表述为：在不损失多模态精度、不增加参数的条件下，消除了接续不连续，使运动统计量接近真实分布。若多个臂达标，取 change 覆盖率最好的；若 change 覆盖率有正向信号，作为额外收益单独报告。

## 机制检查（只作描述）
- 按观测速度分层（静止/慢/正常/快）看接续加速度和覆盖率，检查低速时 v_obs 噪声是否被放大成错误起步。
- clamped_launch 的 |dv| 分布：按 change 与 stable 分组；按观测末两步是否已在转向分组。
- 样条过冲：最大横向偏离锚点连线的距离分布，与 GT 对比。

## 成本
样条臂只是把 h3 的插值矩阵换成另一个固定矩阵；clamped 额外每条候选多一次 12×2 乘加。参数分别为 +0 / +0 / +130。延迟仍按现有 50 次预热 + 500 次测量的整管线方式实测。

## 已知风险
- 观测末步的跟踪噪声会直接进入 v0，影响低速和静止行人。只在 launch 臂中由模型自行补偿；不另加平滑，避免引入第二个因素。
- 自然边界条件下，三次样条在锚点间距变化很大时会有轻微过冲，由机制检查报告。
