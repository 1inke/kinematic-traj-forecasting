## 3. 共同设置

### 3.1 数据与训练

- **数据：** C0 fit（21,719 窗）训练，dev（4,753 窗）评估。哈希与 archive 10 `contract.json` 一致，由 PF1 检查。
- **训练配置：** 完全沿用 E1C_E64（B0）【已核实：archive 10 `train_core.py`、`contract.json`】：
  - batch 64，64 轮，梯度裁剪 5；
  - 优化器和学习率调度与 B0 相同；
  - EMA 衰减 0.995，取最终 EMA 权重；
  - 训练时的数据增强与 B0 相同；
  - 所有臂使用同一 seed 对应的数据顺序。
- **seed：** 42、43、44。

### 3.2 编码器记忆（交叉注意力用）

每个目标智能体的记忆由两部分组成：它自己的 8 个时间步 token，加上场景中所有智能体最后一个时间步的 token（96 维，由一个线性层投影到 64 维）。无效的智能体用模型现有的 `num_valid` 生成 key padding mask。这种结构与 archive 18 缓存的 [9, 8, 96] 一致。

### 3.3 指标

| 类别 | 指标 |
|---|---|
| 主指标（方向一、三） | minADE@20、minFDE@20 |
| 主指标（方向二） | **Top-1 FDE**、**brier-minFDE**（= minFDE + (1 − p̂)²，p̂ 是 FDE 最小那条候选的 softmax 概率） |
| 其他 | Top-1 ADE；J 覆盖率（同一条候选同时满足 ADE ≤ 0.2 m、FDE ≤ 0.4 m）；"最优候选"的平均概率名次；概率加权轨迹 ES（archive 23 的实现） |
| 分组 | 观测分组（stationary / steady / other）；**转向难组**（未来动作为 turn 或 turn_and_speed，只用于分析）；去掉 zara02 |
| 成本 | 参数量；CPU 单样本延迟（与 archive 10 的成本测量相同）；L4 上每轮训练耗时 |

### 3.4 统计方式

- 每个臂与**同一 seed 的 B0** 配对。
- 相对变化取 3 个 seed 的均值。
- **区间：**先把每个窗口在 3 个 seed 上的差值取平均，再按轨迹做聚类 bootstrap（2,000 次），报告 95% 区间。
- 报告每个分组的轨迹数和前 10 条轨迹的占比。

## 4. 共用模块（三个方向都会用到）

**ModeCrossLayer(d = 64，4 头)**，依次是：

1. 可选的模式间自注意力：不用 / 全连接 / 因果掩码；
2. 对 3.2 节记忆的交叉注意力；
3. FFN：64 → 128 → 64，GELU；

每一步都带残差和 LayerNorm（Pre-LN）。

**有界修正：** offset = 0.30 × scale × tanh(W_o·h)，其中 scale 是 B0 的每窗口尺度，W_o 零初始化。上限与 E3 相同，便于比较。修正加在 3 个锚点（第 4、8、12 步）上，再用 B0 的插值矩阵得到完整轨迹。

**第二层打分：** logits2 = logits1 + score_head2(cat(h, 修正后的相对锚点))，score_head2 最后一层零初始化。

**几何输入：** q = mode + W_g·flatten(rel1 / scale)，把归一化后的 6 维锚点几何加到模式特征上。

**初始化等价性：** 上述零初始化保证所有两遍结构的臂在初始化时输出与第一遍完全相同（PF3 检查）。

## 6. 方向二：重排序与终点指标（T-S）

| 臂 | 结构 | 损失 | 检验什么 |
|---|---|---|---|
| **S1 FDE-weight（调参对照）** | B0 | 把 B0 的 WINNER_FDE_WEIGHT 从 0.25 改为 1.0，同时影响赢家选择和软分类目标；其余不变 | "只是更看重终点"的效果。**明确标注为调参，不是方法** |
| **S3 set-2L（对照）** | 在 R2 的基础上，ModeCrossLayer 使用**全连接**的模式间注意力；输入按槽位顺序 | 同 R2，再加 L_rank | 多一层加上模式间交互，但没有排序和因果依赖 |
| **S2 seq-2L（改编版 Parallel ModeSeq）** | 同 S3，但在第二层之前，先按 logits1（detach）从高到低排序；加上可学习的名次嵌入（20 × 64）；模式间注意力使用**因果掩码**（每个模式只看到自己和排名更靠前的模式） | 同 S3 | 排序与因果依赖的作用（S2 对 S3） |
| **S4 seq-2L-EMTA（改编版）** | 同 S2 | 第二层：<br>（a）**EMTA 正样本**：在排序后的序列中，取第一个满足"所有时间步 t 的误差 ≤ 0.5 m × t/12"的模式；没有满足的就退回 B0 的赢家（质量最小）；<br>（b）回归项（reg、endpoint、short）只用于这个正样本；<br>（c）置信度改用二元 focal loss（γ = 2，α = 0.25），正样本为 1，其余为 0；<br>coverage 和 diversity 项不变；第一层仍用 L_B0 | EMTA 训练策略的作用 |

**L_rank**（我们自己定义的轻量排序正则，**不是**论文原样）：对所有满足 q_i + 0.2 m < q_j 的候选对（i 明显好于 j），计算 relu(1.0 − (logit2_i − logit2_j)) 的平均，权重 0.1。

**EMTA 阈值 0.5 m 的理由：** 论文针对车辆使用 2 m。行人的位移尺度小得多；B0 在 dev 上的 minFDE 中位数约 0.3 m，0.5 m 能让大多数窗口存在匹配。敏感性臂用 1.0 m，见 12.2 节。

## 7. 方向一：多生成与分组压缩（T-G）

**60 个模板的初始化**（替换库函数默认的随机补点；库函数在超过 23 个点后，用 N(0, 0.3²) 随机生成补点，会挤在原点附近【已核实：`endpoint_template_initialization`】）：

对 B0 的 20 个基础端点 p_g（g = 0..19），每组生成 3 个成员：

- m₀ = p_g；
- m₁ = 0.85·p_g + (0, +0.08)；
- m₂ = 1.15·p_g + (0, −0.08)。

再按 B0 的方式乘以时间比例，得到 3 个锚点。**第 g 组 = 槽位 3g、3g+1、3g+2，分组在训练中固定。**

| 臂 | 结构 | 损失 | 输出 |
|---|---|---|---|
| **G1 K60-direct** | h3，num_modes = 60，使用上面的初始化 | L_B0（K = 60） | （a）**@60**：上限参考，不与 @20 直接比较；<br>（b）**压缩到 20**：按概率从高到低贪心做 NMS，终点距离阈值 d ∈ {0.1, 0.2, 0.3, 0.5} m，在 fit 上选使 minFDE@20 最小的 d；不足 20 条时按概率补齐；<br>（c）概率加权的 k-medoids（k = 20，作用于终点）；<br>（d）按 logits 取前 20 |
| **G2 group-compress** | 在 G1 之上：<br>① 组内注意力（掩码限定在同组 3 条之内）；<br>② 用可学习查询做注意力池化，得到组 token；<br>③ 组间全连接注意力（20 个组 token）；<br>④ 对记忆做交叉注意力；<br>⑤ 每组输出一条：组锚点 = softmax 权重下 3 个成员锚点的凸组合，再加一个有界修正；组 logit 由组 token 和组锚点给出 | L_B0(20 条组输出) + **1.0 × L_B0(60 条候选)**（辅助项，保持候选有意义） | 20 条 |
| **G2-intra** | 与 G2 相同，但**去掉组间注意力** | 同 G2 | 20 条 |

**对照关系：**

- G1(b/c/d) 对 B0：多生成，加上非学习压缩；
- G2 对 G1(b)：学习式压缩对比非学习压缩；
- G2 对 G2-intra：组间交互的作用；
- G2 对 S3：容量相近（参数量差距需在 PF7 中报告）。

| PF6 | 并发数：分别以 1–6 个 B0 进程各跑 1 轮，选总吞吐最高、且单进程变慢不超过 1.6 倍的并发数（上限 6） | 记录 |

| PF9 | NMS 和 k-medoids 的结果是确定的（同输入重复两次结果相同） | 完全一致 |

## 10. 第二阶段（五折确认）

### 10.1 准入（自动执行）

- 每个方向最多一个臂进入：取该方向 **PASS 标记成立**、且主指标改善最大的臂。
- 某个方向没有 PASS 时，该方向止于 C0。
- **调参类结论**（S-FDE）不进入五折。
- B0 始终进入。

### 10.2 设置

- **五折：** eth、hotel、univ、zara01、zara02，每折用其余四个场景 100% 训练，在该折的测试集上评估。数据管线和 recording-isolation 修正沿用 archive 11。

- **执行顺序：** 按折交错排队：所有准入臂先跑 eth 折，再依次跑 zara01、hotel、zara02、univ。这样即使中途耗尽时间，已完成的折也是配对完整的。

| 标记 | 判据 |

| **F-PASS** | 五折等权平均的主指标（方向一、三为 minFDE；方向二为 Top-1 FDE 或 brier-minFDE）改善 ≥ 1%；5 折中至少 4 折改善；**ETH 折必须改善**；minADE 和 minFDE 都不变差超过 1% |
