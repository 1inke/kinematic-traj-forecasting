## 0. 一页结论

**这轮要回答的问题（按重要性）：**

1. **排序依据（本轮的创新点）**：在多层解码器里，层与层之间按"质量 + 去重"的顺序重排候选，是否比 ModeSeq 那种按置信度重排更好？
   - 质量打分 Q̂ 是你提出的"类损失"打分：由几个子函数相加，只用来排序，不直接当输出。
   - 去重 用"设施选址贪心"（也就是风险顺序）。
   - 判定看 minFDE@20 和 brier。这两个指标与输出顺序无关，所以测的是"排序是否改善了解码器内部的细化"。
2. **EMTA 改进**：
   - E0：把 EMTA 用在多层解码器、并且用新顺序时，能否保住 archive 26 S4 的 Top-1 收益？
   - E1：把匹配阈值改成随观测速度变化，能否改善快速行人（ETH 的弱点）？
3. **五折确认**：把通过的臂拿去做五折，重点看 ETH 和 Top-1。R2 正是在这两项上失败的。

**规模：**
- 第一阶段（C0）11 个臂 × 3 个 seed = 33 次训练。
- 第二阶段（五折）2 个臂，ETH 加 seed。
- 零训练预演 Z0 在 CPU 上做。
- 预计 ≈ 20 小时，留约 3 小时余量给备用臂。

**事先说清楚的预期【推测】：**
- archive 26 里 S2（因果 + 置信度排序）≈ S3（全注意力、不排序），说明"顺序本身"在 1 层时几乎没用。所以本轮最可能的结果是：排序依据对 @20 的影响很小。
- 但零训练已经证实，**输出端**的风险顺序对 top-3/5 有稳定收益。
- 所以本轮也会把每个臂的输出同时按三种顺序评估，作为"输出排序"这条独立结论的多模型证据。

**查重结论：**
- 以前的"重排"都是**事后**做的：外部选择器（159C、S6）、GT-free 打分（STRATEGY_ONE_FACTOR）、集合交互（C2），它们都失败了。
- 唯一和本轮接近的是 S2/S4，但它们只有 1 层，而且只按置信度排序。
- **"预测损失 + 集合边际"作为层间排序依据、多层堆叠、并配合按这个顺序做 EMTA**，这个组合没有做过。
- 本轮的质量头是**解码器内部**、每层都有的头，输入就是解码器自己的表示。这正好对应 S6 报告"应改用内部表示"的建议。

### 1.2 文献（前次调研，未逐字重核）

- **ModeSeq（CVPR 2025）**：多层解码，层间按置信度重排（mode rearrangement），用 EMTA 训练。
  - EMTA 的做法：按顺序取最早满足阈值的模式当正样本，其余匹配的模式当负样本。论文说忽略它们会变差。
  - 没有匹配时退回 WTA。
- **Parallel ModeSeq**：用带因果掩码的并行模式注意力。
- **Mode-as-Sequence（arXiv 2605.24037）**：排序 hinge γ = 0.1；提到多层细化中会出现置信度倒挂。
  - 在 WOMD 上 EMTA 和 WTA 各有胜负：minFDE6 1.1498 vs 1.1851，MR6 0.1502 vs 0.1457。
  - 它提出的 MA-EMTA 细节我没有核实，本轮不实现。
- **类比"预测质量而不是置信度"**：TPCN（预测 FDE）、IoU-Net（用预测 IoU 引导 NMS，并指出迭代回归中质量不单调）、GFL / VarifocalNet（质量感知的分类目标）。
- **集合选择**：
  - Wayformer 的聚合（在半径内贪心覆盖似然）；
  - 2606.26424（合并 vs NMS vs 贪心，没有 Bayes 风险框架）；
  - NLP 的 MBR 解码。

  本轮的风险顺序就是 MBR / k-median 在轨迹候选上的版本。
- **据我所知，没有工作把"预测损失 + 集合边际"用作多层模式序列的层间排序依据。**【推测，需在论文写作时再查一次】

## 2. 方法

### 2.1 结构（所有多层臂相同）

- **第 0 层**：就是 B0 的 h3。它给出 20 条候选 a₀、置信度 logit₀，以及 mode 特征 h₀ = q。
- **第 ℓ = 1…L 层**（默认 L = 3）依次做：
  1. 用上一层的输出算顺序 order_ℓ（不回传梯度）；
  2. x = h + geometric_ℓ(a/scale)，按顺序排好，再加 rank 嵌入（无序臂不加）；
  3. CrossLayer：模式间自注意力（因果掩码或全连接）→ 对记忆做交叉注意力 → FFN。这和 archive 26 的 CrossLayer 完全相同；
  4. 排回原来的位置，然后更新：
     - a ← a + 0.30·scale·tanh(offset_ℓ(y))（零初始化）；
     - logit ← logit + score_ℓ(cat(y, a))（零初始化）；
     - h ← y。
- **记忆**：和 archive 26 相同（自身 8 个时间 token + 所有人的最后 token，投影到 64 维）。
- **质量头**：每层（含第 0 层）一个，共 L+1 个。
  - 输入是 cat(h, a/scale)，**并且先 detach**，所以它不会改变主干，只用来排序。
  - 输出 3 个数：u_ADE、u_FDE、匹配 logit m。
- **初始化**：所有新加的输出层都是零初始化，所以初始时最终输出 = 第 0 层输出 = B0 结构（预检 PF-2 检查）。
- **所有多层臂建立完全相同的模块，顺序也相同**，所以同一个 seed 下的初始权重逐位相同（PF-3 检查）。不用的模块（比如无序臂的 rank 嵌入）闲置。

### 2.2 "类损失"质量打分 Q̂（只用于排序）

Q̂_k = [ADÊ_k + 0.25·FDÊ_k] + 0.5·(1 − σ(m_k)) + 0.10·K_k（单位：米，越小越好）

| 子函数 | 含义 | 怎么得到 |
|---|---|---|
| ADÊ + 0.25·FDÊ | 预测这条候选的 B0 质量 q（q = ADE + 0.25·FDE 正是 B0 损失里选赢家、算 coverage 用的量） | 学习得到：ADÊ = exp(u_ADE) − 0.05，FDÊ 同理；训练目标是 log(真实误差 + 0.05)，smooth-L1，β = 0.1 |
| 0.5·(1 − σ(m)) | 预测"这条候选达不到 EMTA 匹配"的惩罚，最多 0.5 m（等于匹配阈值） | 学习得到：BCE，目标是"每个 t 都满足误差 ≤ 0.5·t/12 m"。所有臂都固定用 0.5 m，E1 臂也一样 |
| 0.10·K | 运动学不合理度。K = 未来 12 步的平均 relu(‖加速度‖ − a_ref)，a_ref = 历史最大加速度 + 1.0 m/s² | GT-free，推理时可算 |

- 质量头对**所有 20 条候选**都监督（不是只监督赢家）。目标只在训练时算，用的是这一层自己的候选。
- 质量头损失的权重是 0.5。因为输入 detach 了，这个权重只影响质量头本身。
- 三个系数（0.25、0.5、0.10）都是事先定的，**不调参**。0.25 与 B0 的 q 定义一致；0.5 等于匹配阈值；0.10 表示 1 m/s² 的超额加速度折合 0.1 m。
- **运动学项可能没有作用**：B0 候选是锚点插值的光滑路径。所以 Z0 先在 B0 的 dev 预测上算"K > 0 的候选比例"。
  - 如果 < 5%，开跑前就从 Q̂ 里删掉 K 项，所有臂一起删（MC5）。
  - 这个统计不用真值，所以不算偷看结果。

### 2.3 层间排序方式

| 名称 | 规则 |
|---|---|
| none | 不排序：全注意力，不加 rank 嵌入 |
| conf | 按上一层 logit 从大到小（ModeSeq 方式）；稳定排序 |
| rand | 训练时每个样本、每层随机排列（专用生成器，seed + 1000）；评估时用固定生成器（seed 12345，每次评估前重置） |
| qual | 按 Q̂ 从小到大：**只看质量，不去重** |
| risk | **质量 + 去重（主臂）**：<br>（1）先把 Q̂ 变成"真值离哪条候选最近"的分布：w = softmax(−Q̂/0.5)。温度 0.5 与 B0 的软分类目标一致；<br>（2）在候选终点两两距离 D 上做设施选址贪心：第 r 步选使 Σ_j w_j·min(已选集合到 j 的距离, D(s,j)) 最小的 s；<br>（3）第 1 步得到加权 medoid，之后每一步都选"边际覆盖最大"的候选；<br>（4）排完全部 20 个，平局取小编号 |
| riskp | 同 risk，但 w = softmax(logit)，即模型自己的概率。这是零训练里验证过的版本 |

- 输出端：每个臂的最终输出都按三种顺序评估：conf（原生）、riskp（事后）、Q̂（如果有质量头）。

### 2.4 EMTA 变体

- 所有 EMTA 都只用于第 ℓ ≥ 1 层，第 0 层始终是 B0 损失。
- "最早匹配"按**该层的输入顺序**来找。
- 其余细节和 archive 26 S4 完全相同：
  - 回归项（reg、endpoint、short）只用于正样本；
  - 二元 focal（γ = 2，α = 0.25）；
  - diversity 和 coverage 0.20 不变；
  - 没有匹配时退回 argmin q。

| 名称 | 终点阈值 θ（中间步按 θ·t/12） | 说明 |
|---|---|---|
| E0 | 0.5 m | 同 S4 |
| E1 | θ(v) = clip(0.10 · v · 4.8 s, 0.5, 1.5) m。v = 观测 8 点相邻位移的平均 / 0.4 s，单位 m/s | 阈值 = 匀速 4.8 秒位移的 10%，下限 0.5。v ≤ 1.04 m/s 时与 E0 完全相同 |
| Ewide（备用） | 1.0 m | 对照："只是阈值变大"还是"按速度变大" |

- 为什么要 E1：D-3 预演显示，0.5 m 下 ETH 最快速度组（v > 1.3 m/s，112/364 窗）几乎没有候选能匹配（3.6%），EMTA 在这些窗基本退化成 WTA。
- 用 E1 后，该组匹配率代理升到 25.9%，慢速组不变（附录 A）。

### 2.5 损失

- 深监督：每一层（含第 0 层）的损失权重都是 1.0。
- 第 ℓ ≥ 1 层：无 EMTA 的臂用 B0 损失，有 EMTA 的臂用上面的 EMTA 损失。
- 每层都加 0.5 × 质量头损失。
- 最终层 logits 加 archive 26 的排序 hinge：0.10 × 平均 relu(1 − (logit_i − logit_j))，只对 q_i + 0.20 < q_j 的对。**所有多层臂都加**（包括 D3-full），所以它不构成臂间差异。
- 代码见 `ref_qrank/ml_rerank_ref.py` 的 `ml_loss`。

### 4.2 指标

- **主指标：minFDE@20**。顺序无关，衡量的是候选质量本身。
- 其余沿用 archive 26 `forecast_metrics`：
  - minADE、Top-1 ADE / FDE（最大 logit）；

  - rank；ES；
  - brier-minFDE = FDE_best + (1 − p_best)²。
- 分组：hard / stationary / steady / other / without_zara02（archive 26 `groups`）。另加**快速组** v > 1.3 m/s：364 窗，67 条轨迹，前 10 条轨迹占 28.0%【已核实：当场计算】。
- **新增指标：**
  - 每层的 minFDE@20、Top-1 FDE、brier（看细化过程）；
  - min@{1,3,5}（FDE 和 ADE）× 三种输出顺序；
  - 操纵检查量（§7.1）；
  - 机制描述量：
    - 缺口填补：最终层按本层顺序，第 6–20 位候选到前面所有候选的最小终点距离，取平均；
    - 救回率：第 0 层 minFDE > 1.0 m 且最终 ≤ 1.0 m 的窗比例；
    - 丢失率：反过来；
    - Top-1 倒挂率：最终 Top-1 FDE 比第 0 层 Top-1 大 0.5 m 以上的窗比例。

### 4.3 统计

- **相对收益**：G(A vs B) = (m_B − m_A) / m_B，正数表示 A 更好；J 用百分点。
- 每个臂取 3 个 seed 的均值。
- **CI**：先对每个窗取 3 个 seed 的平均，再按轨迹（scene|track，248 条）做聚类 bootstrap，2,000 次，配对。
- **多重比较**：主比较族是 O-risk vs {O-conf, O-rand, D3-full} 三个，用 98.3% CI（Bonferroni）。其他比较用 95% CI，标"次要"。
- **种子噪声参考**（B0 C0 dev 5 seed 的 CV）：minFDE 0.72%，Top-1 FDE 0.78%，J 1.34%【已核实：此前 seed 噪声分析】。
  - 3-seed 均值之差的 SD ≈ 0.72% × √(2/3) ≈ 0.59%。
  - 所以 1.5% 门槛 ≈ 2.5 SD，1.0% ≈ 1.7 SD。
- **敏感性**（主比较）：
  - 去掉 zara02（1,240 窗）；
  - 逐录制留一，dev 有 7 个录制：hotel 126、zara01 284、zara02 1,240、zara03 289、students001 1,650、students003 1,046、uni_examples 118【已核实：当场计算】。报告 7 次中同号的次数。
- **五折**：只有行号，没有轨迹 ID，所以用连续 15 行一块的块 bootstrap（与 work/ff.py 相同）。**如果你能从原始数据恢复轨迹 ID，请保存在五折预测里**，那样改用轨迹 bootstrap。

## 13. 局限（写进报告）

1. O-conf、EMTA 臂是 ModeSeq 的**改编版**：3 层、并行因果掩码、K = 20、行人阈值。它们不是原方法的复现，不能用来评价原论文。
2. C0 dev 已被大量以前的实验使用过，存在设计选择上的适应性过拟合。五折里只有 ETH 是干净的。
3. 3 个 seed 只能检测约 1.5% 以上的差异。
4. 多层臂参数量是 B0 的 1.6–1.7 倍，延迟会增加（PF-LAT 记录）。"轻量"的论述要以实测为准。
5. Q̂ 的三个系数是事先定的，没有调。更好的组合可能存在，但调参会引入选择偏差。
6. ETH 的块 bootstrap 不是真正的轨迹聚类。
