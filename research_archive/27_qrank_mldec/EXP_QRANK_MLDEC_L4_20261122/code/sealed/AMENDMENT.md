# EXP-QRANK-ML 执行补充

2026-11-22。C0 保留 11 臂、3 个种子、每组 64 轮和 batch 64。五折保留两项晋级名额、三种子配对及 ETH 额外两种子。单次 Colab 到 23 小时停止接收正式任务并保存可恢复状态，后续从同一输出目录继续原计划。

- `O-conf+QFL`、`O-risk+QFL` 分别占用原来两个 E1 正式名额。E1 自适应阈值下放到可选消融，只保留 `O-risk+E1`，使用原留给 Ewide 的首个备用名额。Ewide 保留实现供另行对照。
- QFL 使用 E0 的固定 0.5 m 线性匹配阈值、最早匹配和同一 WTA 回退。排序、回归、coverage、diversity、深监督和 hinge 沿用对应 E0。唯一被替换的监督项是第 1–3 层的 EMTA 置信度损失。
- 选中候选的连续标签为 `exp(−(ADE+0.25·FDE)/0.5)`，其余为 0。标签使用训练目标下本层实际轨迹误差，并从几何梯度中分离。分类损失为 `|sigmoid(z)−y|² BCEWithLogits(z,y)`。温度沿用原方案的 0.5，推理端直接使用分类头 logits。速度和匀速外推不参与 QFL 的标签或匹配阈值。公式移植自 [Generalized Focal Loss 的 QFL](https://arxiv.org/abs/2006.04388)。
- `M-QFL` 在同排序下对比 QFL 与 E0，沿用原 EMTA 的 Top-1 FDE（≥3%）或 brier-minFDE（≥2%）收益门槛，以及总体 minFDE（≥−1%）、静止组 minFDE（≥−3%）保护。旧 M-E1 仅用于解释可选消融，不参加五折自动准入。
- 五折沿用原判据。输入包的五折窗口是整数行号，区间按连续 15 行分块。保留原始行号。ETH 与 C0 dev 的交集口径沿用原协议。
- 质量头与其余参数分别进行最大范数为 5 的梯度裁剪，确保分离梯度后，质量头的范数也不会改变主干更新。所有多层臂采用相同裁剪口径。
