# 【待执行】EXP-WIDTH-CAUSE-DIAG：B0 候选集合为什么不随情境收紧？

**状态：** 只有设计文档，代码待写。
**类型：** 零训练。只对已训练好的 B0@64 做前向，以及一次反向求梯度。不训练，不改动任何权重。
**数据：** C0 的 fit（21,719 窗）和 dev（4,753 窗）。不碰任何测试折。

## 0. 一句话目标

archive 20 发现，B0 的 20 条候选终点散布约 1.8–2.0 m，与情境无关。近静止行人的真实散布只有约 0.94 m，B0 的集合却同样宽，而且在这个箱里 minFDE 比 K-means 参照还差 8.4%。

本实验不提方法，只回答：**是什么让集合收不紧？** 答案决定下一步应该改训练目标还是改生成结构。

### 1.2 B0 解码器和损失中与"宽度"有关的细节

以下均【已核实：archive 17 `dependencies/022_hierarchical_decoder_models.py`、`020_locked_mode_query_loss.py`、archive 10 `baseline_factory.py`、`042_RESOLVED_CONFIG.json`】。

- **生成方式：** 锚点 rel_k = s ⊙ (T_k + δ_k)，取第 4、8、12 步。
  - s = softplus(Linear(context)) + 0.25，每个窗口一个 2 维尺度，20 条候选共用。
  - T_k 是 20 个全局可学习模板，初始终点的 x 范围为 −0.2 到 2.8，y 范围为 ±1.0。
  - δ_k = 0.75·tanh(Linear(mode_k))，每轴有界。
  - 终点能单独移动的范围只有 s·(T_k ± 0.75)。例如模板 x = 2.8 的候选，在 s ≥ 1 时终点 x 至少为 2.05·s。
- **打分头的输入**是 (mode_k, rel_k)，rel_k 没有 detach。所以分类损失的梯度也会流到几何上。
- **损失：** L = reg + 0.5·cls + 0.25·endpoint + 0.05·diversity + 0.2·short + 0.2·coverage。
  - reg、endpoint、short 只作用于硬赢家。赢家由 q = ADE + 0.25·FDE 选出。
  - coverage = Σ_k r_k·q_k，其中 r = softmax(−q/0.10)，r 已 detach。
  - diversity = 所有 190 对终点的 ReLU(0.4 − 距离) 的平均。
  - cls = 软目标交叉熵 + 0.25·硬交叉熵，软目标温度为 0.5，按 gap 的均值归一化。
- **损失计算在模型内部的朝向归一化坐标系里进行**，x 沿观测朝向。近静止时朝向由噪声或默认值决定。

|---|---|---|

## 3. 实验设置

### 3.1 模型与数据

- **模型：** `qoder_work\NEXT_PHASE_EXEC_20261114\runs\E1C_E64_s{42,43,44,45,46}\final.pt`，取 `ema` 权重。
  - 构建方式与 archive 20 `run_mech.py` 相同：`make_model(device, seed)` 后 `load_state_dict(snapshot["ema"], strict=True)`，**不挂** set refiner。
  - 使用 `model.eval()`，不做数据增强。
- **数据：** `C0\fit.npz` 和 `C0\dev.npz`。
  - 用 `baseline_factory.prediction(model, past, num_valid, future, augment=False)` 得到局部坐标系里的输出和目标。
  - 前置检查：dev 的世界坐标路径与 `E1C_E64_s*/dev/predictions.npz` 逐窗一致，误差 ≤ 1e-5。
- **分组：**
  - 观测分组：沿用 archive 19 的 `observation_masks`，分为 stationary / steady / other。
  - 未来分组：沿用 `maneuver_labels`，仅用于分析。观测为 stationary 的窗口再分为 **remain**（标签 stationary）和 **start**（标签 start）。
- **A 部分的样本：** fit 中全部观测近静止窗口（约 3,216 窗），加上 steady 和 other 各随机抽 3,000 窗（随机种子 20261120，抽样写入输出）。B 至 F 部分用全部相关窗口。

### 3.2 诊断前向（A、B、C 共用）

在诊断脚本里写一个 `h3_forward_diag(decoder, tokens, past, scale_mult=None, cand_mult=None)`，逐行复制 `HierarchicalLearnedAnchorDecoder.forward`（B0 是 h3，`use_refiner=False`），只增加三处：

1. 对 `scale`、`delta`、`relative_anchors` 调用 `retain_grad()`；
2. `scale_mult`：形状为 [B, 1] 的倍数，乘到 scale 上，用于 B 部分；
3. `cand_mult`：形状为 [B, 20] 的倍数，乘到指定候选的 rel_k 上，用于 C 部分。

**前置检查：** 当两个倍数都为 None 时，输出路径和 logits 必须与原 forward 逐元素一致，误差 ≤ 1e-6。

### 3.3 逐窗口的分项损失

把六个损失项写成逐窗口形式。每项都按"全体窗口"作分母，使各窗口贡献之和恰好等于整体损失。

- reg：Σ_t w_t·Huber 之和 / T；
- endpoint：/ 2；
- short：/ 4；
- cls、coverage：逐窗口取值；
- diversity：190 对的平均。

**前置检查：** 每个 batch 上，逐窗口贡献的平均乘以各项权重，必须等于 `baseline_factory.loss_value(...)` 的值，相对误差 ≤ 1e-6。

## 4. 各部分的测量

### A. 梯度从哪里来（主要检验 C1，兼顾 C2 和 C3）

对每个窗口、每个损失项 j 分别求梯度（`torch.autograd.grad`，每项单独做一次）：

- G_j,k = ∂L_j/∂rel_k，每条候选的锚点梯度；
- ∂L_j/∂s，尺度梯度；
- ∂L_j/∂T，全局模板梯度。

**A1. 收缩力。** 定义 S_j = ∂L_j/∂s_x + ∂L_j/∂s_y。正值表示梯度下降会让 s 变小（想收紧），负值表示想变宽。

S_j 可以精确地拆到每条候选：S_j = Σ_k Σ_anchor Σ_c G_j,k·(T_k + δ_k)。再分成赢家部分和非赢家部分。

按 remain / start / steady / other 分组，报告每项 S_j 的均值、|S_j| 的均值，以及总和。

**A2. 非赢家拿到多少信号。**

- 各组的路径梯度范数中，非赢家所占的比例：Σ_{k≠w} ‖G_k‖ / Σ_k ‖G_k‖。分项报告，也报告总和。
- coverage 的有效候选数 exp(H(r)) 的中位数。

**A3. 全局模板被往哪个方向拉。** 对每个模板 k，取外向单位向量 u_k =（T_k − 20 个模板的均值）的方向。计算 R_j = Σ_k ⟨∂L_j/∂T_k, u_k⟩，正值表示梯度下降会把模板往里收。按组分别累加，分项报告。这一项看的是"谁在决定全局模板的大小"。

**A4. δ 的饱和方向。**

- 在近静止窗口里，统计 |tanh| > 0.95 的 δ 分量所占比例。
- 按候选在静止窗口里的获胜率分档统计（见 C 部分的定义）。
- 对饱和分量，按 sign(δ)·sign(T) 区分"向内饱和"和"向外饱和"。
- 解读：很少获胜的候选如果大量向内饱和，说明它们"想收但被上限卡住"（支持 C3）；如果几乎不饱和、S 也接近 0，说明根本没有力（支持 C1）。

### B. 目标函数在"整体缩放"方向上想要多宽？（主要检验 C3）

- 只对观测近静止窗口，令 scale_mult = α，α ∈ {0.5, 0.6, 0.7, 0.8, 0.9, 1.0, 1.1}。δ 不变，logits 随几何重新计算。
- 在 fit 上（这是训练目标本身的视角）报告：
  - remain、start 两组各自的总损失 L(α)，以及六个分项的 L(α)；
  - 观测近静止窗口合并后的 L(α)，和使它最小的 α\*；
  - **去掉 diversity 项**后的 α\*，用于 D 部分。
- 在 dev 上报告：remain、start 和合并组的 minADE/minFDE，以及等权终点散布（定义与 SET-CALIB-DIAG 的 `equal__s` 相同）。

### C. 只移动"几乎不获胜"的候选是否免费？（检验 C3 和 C4，并区分 C1 和 C3）

- **候选的获胜率：** 对每个 seed，在 fit 的观测近静止窗口里，按训练用的赢家定义（q = ADE + 0.25·FDE）统计每个候选编号 k 的获胜率。候选编号由 mode_embedding 和模板固定，所以 k 在不同窗口间含义一致。
- **几乎不获胜的集合 R：** 获胜率 < 1/40（即均匀份额的一半）的候选。敏感性分析另用 1/20 和 1/80 两个阈值。报告每个 seed 的 |R|。
- **反事实：** 在 dev 的观测近静止窗口里，把 R 中候选的整条相对路径乘以 α_c，α_c ∈ {0.25, 0.5, 0.75}，主分析用 0.5。其余候选不变。这等价于把它们往最后观测位置收。获胜率只用 fit 统计；观测分组只用过去轨迹，不用未来信息。
- **报告：**
  - remain、start、合并组的 minADE/minFDE 变化（与 α_c = 1 相比），5 个 seed 分别报告；
  - 散布变化；
  - 与 K-means 参照的差距（`windows/B0_s*.npz` 的 `t12__reference_minFDE`）是否缩小。
- **可达性：** 按 archive 19 的可达框方法，在**当前 s** 下，移动后的锚点是否仍落在 s·(T_k ± 0.75) 内。报告可达的候选比例。
  - 可达却没学到：支持 C1，因为没有力把它们移过去。
  - 不可达：支持 C3，参数化把这条路堵住了。

**注意：** C 部分是诊断用的反事实，不是要提出的方法。即使结果好，也不能直接当作方法使用。

### D. 多样性项是否撑住了宽度（检验 C2）

- 在 α = 1 时，统计各组终点距离 < 0.4 m 的候选对占 190 对的比例。
- 多样性项在 A1 的"变宽力"（S < 0 的部分）中所占份额。
- B 部分中，去掉多样性项后 α\* 的变化。

### E. 坐标系是否让集合必须各向撒开（检验 C5，辅助项）

- 在观测近静止窗口里，统计朝向取默认值（末 3 步位移 ≤ 0.03 m）的比例，以及由噪声定朝向（0.03–0.12 m）的比例。
- 起步窗口在局部坐标系里的起步方向分布：单位向量合成长度 ρ。ρ 接近 0 表示各向均匀。
- 在近静止窗口里，比较 B0 终点协方差的各向异性比（大特征值 / 小特征值）与 fit 同箱真实未来终点的各向异性比。

### F. 已有的训练变体是否改变过宽度（只用已保存的预测，零前向）

用 SET-CALIB-DIAG 的同一套散布计算，在 dev 上按观测分组，报告等权终点散布中位数。对象是 archive 10 已有的这些运行：

- 预算系列：E1B_E8、E1B_E16、E1B_E32、E1B_E64（seed 42、43）；
- 训练方法：T1、T2、T3（seed 42–44）；
- 生成方式：E2_natural、E2_clamped（seed 42–44）；
- 修正：E3_set、E3_set_nobias（seed 42–44）。

读法：

- **预算曲线：** 静止组的散布如果随训练轮数下降，说明有一个缓慢的收紧力，只是训练没跑完；如果从 E8 起就基本不变，说明没有这个力（支持 C1）。
- **T1：** 前半程给了非赢家信号，但后半程又回到硬 WTA。如果它的静止组散布也和 B0 一样，说明"只在前期给信号"不足以改变宽度。这只是弱证据。

## 5. 预注册的描述性标记

所有标记逐 seed 计算。"成立"指 5 个 seed 中至少 4 个满足。阈值在运行前固定，事后不改。这些是描述性标记，不是显著性检验。

| 标记 | 判据 | 支持 |
|---|---|---|
| **M1 NO_FORCE_ON_LOSERS** | 在 remain 组，路径梯度总范数中非赢家占比 ≤ 10%，且 coverage 有效候选数的中位数 ≤ 1.5 | C1 |
| **M2 UNIFORM_WIDTH_ENDORSED** | 在 fit 观测近静止合并组，α ∈ {0.7, 0.8, 0.9} 的 L(α) 全部 ≥ L(1) | 整体缩放方向上，目标函数认可当前宽度（C3 的前半句） |
| **M2′ OBJECTIVE_WANTS_NARROWER** | 存在 α ≤ 0.9，使 L(α) 比 L(1) 低至少 1%（以该组损失计） | 目标函数想更窄，但训练没走到。属于优化或参数耦合问题 |
| **M3 START_PAYS** | 在 B 部分 α = 0.8 时，start 组的 (reg + endpoint + short + coverage) 增加，remain 组的同一和不增加 | 整体缩放的代价由起步窗口承担（C3） |
| **M4 FREE_REALLOCATION** | C 部分主分析（阈值 1/40，α_c = 0.5）：dev 观测近静止合并组 minFDE 改善 ≥ 3%，且 5 个 seed 方向一致；start 组 minFDE 变差 ≤ 5% | 当前分配即使按 best-of-20 也是低效的（再次排除 C4） |
| **M5 BLOCKED_BY_BOUND** | C 部分主分析中，移动后不可达的候选 ≥ 50%；且 A4 中 R 内候选的向内饱和比例 ≥ 30% | C3（参数化约束） |
| **M6 DIVERSITY_HOLDS** | α = 1 时近静止窗口的活跃对比例 ≥ 5%，且多样性项占"变宽力"的 ≥ 30%；或者去掉多样性项后 α\* 下降 ≥ 0.1 | C2 |
| **M7 BUDGET_FLAT** | F 部分：E1B 系列中，静止组散布从 E8 到 E64 的变化 ≤ 5%（两个 seed 都满足） | C1（没有缓慢的收紧力） |

E 部分只做描述，不设标记。原因是 K-means 也用同一坐标系，C5 无法单独定性。

## 6. 结果如何指导下一步（运行前写定）

| 结果组合 | 解读 | 下一步方向（都要先查重、查文献） |
|---|---|---|

| M4 成立，M5 成立 | 更好的分配存在，但被 δ 的上限和共享尺度堵住 | **生成结构**：候选级、随情境变化的径向尺度，或集合层面的分配机制。要与旧协议的 CDA、EXP-146 模板组逐一核对 |
| M4、M1、M5 都成立 | 两个原因同时存在 | 结构和目标都要改。先做结构改动（它是让目标改动能起作用的前提），再加目标改动，分两步验证 |
| M4 不成立 | 在"把少胜候选内收"这一维上没有免费的收益。与 K-means 的差距来自别处，例如形状或方向，见 E | 暂不提方法。根据 E 的结果再设计诊断 |
| M6 成立 | 多样性项是宽度的来源之一 | 这本身不构成方法；调间隔属于调参技巧。之后任何方法实验都要把多样性项作为混杂因素控制或报告 |
| M2′ 成立 | 目标函数想要更窄，但训练没到 | 属于优化或耦合问题。检查 scale 线性层能否区分静止情境（例如对 context 做线性探针），而不是改目标 |

## 8. 局限（写在报告里）

1. **A 部分是在训练结束时的一个快照。** cosine 学习率最后降到 0，又是 EMA 权重、eval 模式、不做增强，与训练时实际收到的梯度不完全相同。所以 A 部分只看方向和比例，不看绝对大小。B 和 C 部分是对损失和指标的直接计算，更稳健。
2. **B 和 C 都只是一维切片。** "切片上没有收益"不等于"重新训练也没有收益"；"切片上有收益"给出的是可得收益的下界，但它不是方法。
3. C 部分的获胜率来自 fit，评估在 dev 上做。但 dev 已经被反复使用，只能当作探索性证据。
4. 起步窗口只有 167 个（dev），start 组的结论噪声较大。所以要求 5 个 seed 方向一致。
5. 本实验只用 ETH 训练池（C0）。结论能否推广到其他折和 SDD，要等方法阶段用五折检验。
