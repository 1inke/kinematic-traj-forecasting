# B0 候选集合宽度诊断

EXP-WIDTH-CAUSE-DIAG 已完成。实验使用 C0 的 21,719 个 fit 窗口、4,753 个 dev 窗口，以及 B0@64 的五个最终 EMA 权重。全程冻结权重。

## 主要结果

**只有 M2 通过。** 五个 seed 中，缩放系数取 0.7、0.8 或 0.9 时，fit 近静止组的原训练损失都比 1.0 时高。五组最低值都出现在网格上沿 1.1。

| 证据 | 五个 seed 的结果 |
| --- | --- |
| 整体缩到 0.8 倍 | dev 近静止组 minFDE 平均改善 7.03%，其中继续静止改善 11.16%，起步改善 4.47%。fit 同组原训练损失上升 1.84%。 |
| 分类与几何损失 | 在 0.8 倍，分类项占各 seed 净损失增量的 77.1%–81.6%。从已计算的曲线上扣除分类项后，五个 seed 的最小值均回到 1.0。 |
| 非赢家梯度 | 继续静止组中，非赢家占总锚点梯度范数的 44.5%–48.9%。软覆盖项的有效候选数中位数为 2.06–2.10。M1 未达到。 |
| 少胜候选内收 | 主方案把 17 条少胜候选的相对路径缩到 0.5 倍，整体散布约减半。近静止组 minFDE 平均恶化 3.20%，起步组恶化 6.72%。缩到 0.75 倍时，近静止组 minFDE 平均改善 1.22%，低于 3% 主门槛。 |
| 参数框与多样性 | 主方案仅 29.3% 的移动后候选落在可达框内。少胜候选全部分量中，向内饱和只占 1.51%–4.78%。近静止组活跃多样性对约占 0.51%，去掉该项时网格最小值仍为 1.1。M5 和 M6 均未达到。 |
| 坐标与预算 | dev 近静止组 73.8% 使用默认朝向，起步方向合成长度为 0.623。两条 fit85 预算曲线从 E8 到 E64 的近静止散布增加 55.2% 和 27.8%。 |

同一次缩放在原训练损失和最佳候选误差上出现相反方向。分类项的变化包含重新计算的分类目标和 logits，现有切片只能定位差异集中在哪些损失项。继续静止与起步两组的 fit 几何损失在 0.8 倍时都增加，M3 未达到。结论限于 C0 和既有模型的一维切片。扣除分类项是对已保存标量的补充分析，模型没有重新训练。

F 中的 T1 在三个 seed 上都使近静止组散布中位数变小（0.24–1.04 m，同 seed B0 约 1.96–2.04 m）。这为训练时的候选责任分配提供线索。这里比较的是完整训练变体，散布差异尚无法归因到单个损失项。E1B 使用独立训练预算，实验观察的是同协议下不同预算的模型。相关 B0 对照见 [Phase 20](../../20_calibration_refinement/EXP_CALIBRATION_REFINEMENT_20261119/)。
