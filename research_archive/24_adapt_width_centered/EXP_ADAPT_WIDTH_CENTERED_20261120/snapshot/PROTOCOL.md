# EXP-ADAPT-WIDTH-CENTERED 执行口径

B0 使用现有 fit 和 dev 预测。留出臂复用两个 fit85 权重，CALIB 预测用于选倍数，补做的 dev 预测用于评估。均以最后观测位置为坐标原点。倍率只作用于相对各步均值的偏差，概率固定。等权中心敏感性仍用原模型概率计算加权 ES 和预测均值终点偏差。

- PF1 比较五个 B0 seed 的全部 dev 窗口，使用 archive 23 的误差、散布及 ES 分项，另核对 archive 20 的 HPD90。PF2–PF4 每个臂、seed、数据集均匀抽取 256 个有序真实窗口，遍历 13 个各向同性倍数，另核对全部 144 个各向异性组合的概率加权均值。PF5 和 PF7 使用完整分组或数据集。优化网格另用 32 个 dev 窗口核对 6 个组合的全部指标。
- HPD90 使用 archive 20 B0 的 A/B 交叉核宽和等权分布。E1B 借用同 seed B0 核宽。fit 和 CALIB 采用相同的轨迹哈希和固定随机种子。dev 使用原档案的每窗 1,000 个随机样本，所有倍数共用。HPD90 计算在终点坐标系复用高斯因子。
- 同一数据集内用逐轨迹聚类的 2,000 次 bootstrap 报告 dev 曲线、配对变化及选定规则的区间。逐录制留一针对 minFDE，固定已经选出的倍数。录制贡献份额用该录制的 minFDE 改善量之和除以全组净改善量，存在互相抵消时可能超过 100%。总体净改善为零或为负时不定义份额。终点散布汇总用中位数，速度高于 2.5 m/s 的步比例包含最后观测点到第一个预测步。
- 选择时先按目标指标，再在完全并列时按离 1.0 最近的倍数（各向异性先比较纵向），最后按数值升序。L1 粗组分开选 minADE、minFDE 和四种 ES，也在等权中心上做这些比较。L2 使用实际未来动作标签，只作为参考上限。
- C1H 分别检查总体与难组，两 seed 都需在同一组上达到正向改善及 B0 改善的一半。C4 的留出方向以同 seed B0 三个粗组中差距最大的组对为准，同时保存全部组对差距。C5 平均五个 seed 各自相对 B0 的退步。C6 分别记录每个移动组的结果，并要求同一个 seed 的两个移动组都满足平坦度条件。
- 正式计算由 Windows 任务计划程序启动，使用 CPU。每个臂和 seed 完成后保存独立检查点。源代码和输入一致时，重启可跳过已完成的臂与 seed。状态文件为 `CURRENT.json`。
