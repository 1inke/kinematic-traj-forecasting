# 逻辑归档与迁移计划（未移动旧目录）

本轮按协议建立 `archive/INDEX.csv` 和旧 README 文本快照，但**不直接将旧目录整体搬入 legacy**。大量旧runner、缓存路径及30k级历史SHA清单引用原位置；直接搬动会破坏复现，也可能影响用户的其他任务。

索引由 `build_index.py` 只读生成，以本轮开始时 Git HEAD 的目录为历史范围。日期取目录名字，不猜测报告修改时间；结论仅引用已发现的报告标题/状态行，缺失写 `NOT_REVIEWED_IN_THIS_MIGRATION`，不冒充复核过全部旧科学结果。

后续若要实体迁移，应先：保存全部旧文件/内容SHA→生成逐路径映射→修复新adapter引用而非静默改旧manifest→在副本验证历史入口→保留旧位置可恢复引用→单独批准移动。本轮只生成计划与索引，不删除、不重训、不移动原成果。
